# 3. コンテナを動かす

## この章でわかること

- イメージをもらい（pull）、コンテナを動かす（run）
- コンテナの一覧・止める・消す・ログ・中に入る
- `docker run` のよく使うオプション（ポート・名前・後ろで動かす）

## Python を1回だけ動かす

```bash
docker run --rm python:3.12-slim python -c "print('コンテナの中から', 1 + 1)"
```

1. 手元に `python:3.12-slim` のイメージがなければ、Docker Hub から自動でもらう（pull）
2. そのイメージからコンテナを作り、`python -c ...` を実行する
3. 終わったらコンテナを消す（`--rm`）

パソコンに Python 3.12 が入っていなくても、3.12 で動きます。

### イメージの名前とタグ

`python:3.12-slim` の `:` の後ろを**タグ**といい、版や種類を表します。

| 例 | 意味 |
| --- | --- |
| `python:3.12` | Python 3.12（ふつうの大きさ） |
| `python:3.12-slim` | 要らないものを省いた小さい版 |
| `ubuntu:24.04` | Ubuntu 24.04 |
| `nginx` | タグなしは `latest`（最新）。中身が変わることがあるので、決まった版を書くほうがよい |

## 対話して使う

```bash
docker run -it --rm python:3.12-slim          # Python の対話モード（exit() で出る）
docker run -it --rm ubuntu:24.04 bash         # Ubuntu の中のシェル（exit で出る）
```

`-it` は、キーボードで入力できるようにするオプションです。Ubuntu のコンテナの中で `apt install` などをしても、手元のパソコンには影響しません。`--rm` なので、出ると全部消えます。

## Web サーバーを後ろで動かす

```bash
docker run -d --name web -p 8080:80 nginx
```

ブラウザで `http://localhost:8080` を開くと、nginx のページが出ます。

| オプション | 意味 |
| --- | --- |
| `-d` | 後ろで動かす（ターミナルがすぐもどる） |
| `--name web` | コンテナに名前を付ける（付けないと、でたらめな名前になる） |
| `-p 8080:80` | パソコンの 8080 番ポートを、コンテナの 80 番につなぐ（`パソコン:コンテナ` の順） |
| `-it` | キーボードで対話する |
| `--rm` | 止まったら自動で消す |
| `-e 名前=値` | 環境変数（5章） |
| `-v 場所:場所` | フォルダやボリュームをつなぐ（5章） |

## コンテナを操作する

| コマンド | すること |
| --- | --- |
| `docker ps` | 動いているコンテナの一覧（`-a` で止まっているものも） |
| `docker logs web` | 出力（ログ）を見る（`-f` で流れ続けるのを見る） |
| `docker exec -it web bash` | 動いているコンテナの中に入る（`exit` で出る。コンテナは止まらない） |
| `docker stop web` | 止める |
| `docker start web` | 止めたものを、もう一度動かす |
| `docker rm web` | 止まっているコンテナを消す（`-f` で動いていても消す） |
| `docker images` | 手元のイメージの一覧 |
| `docker pull 名前:タグ` | イメージをもらう |
| `docker rmi 名前:タグ` | イメージを消す（使っているコンテナがあると消せない） |

VS Code では、左のクジラのアイコンの CONTAINERS に `web` が出ます。右クリックで「View Logs」（ログ）・「Attach Shell」（中に入る）・「Stop」・「Remove」ができ、コマンドを覚えていなくても操作できます。

## コンテナの中の変更は消える

コンテナの中で作ったファイルや変更は、**そのコンテナを消すと消えます**。イメージは変わりません。

- 同じイメージから作り直せば、いつでもまっさらな状態にもどせる（これが便利な点）
- 残したいデータは、ボリュームやパソコンのフォルダに置く（5章）
- 入れたいライブラリは、Dockerfile に書いてイメージにする（4章）

## まとめ

- `docker run イメージ:タグ コマンド` で動かす。なければ自動で pull
- `-d` 後ろで・`--name` 名前・`-p パソコン:コンテナ` ポート・`-it` 対話・`--rm` 自動で消す
- `ps`・`logs`・`exec -it ... bash`・`stop`・`rm`。VS Code のクジラのアイコンからも操作できる
- コンテナを消すと中の変更も消える
