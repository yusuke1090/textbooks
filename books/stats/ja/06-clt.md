# 6. 標本平均・大数の法則・中心極限定理

## 母集団と標本

知りたい全体を**母集団**、そこから取り出して実際に調べた一部を**標本**といいます。母集団の平均 $\mu$ や分散 $\sigma^2$ はふつうわからないので、標本から推し量ります。

| | 母集団 | 標本 |
| --- | --- | --- |
| 例 | 日本の乳牛すべての乳量 | 調べた 100 頭の乳量 |
| 平均 | 母平均 $\mu$（知りたい値） | 標本平均 $\bar{X}$（計算できる） |
| 分散 | 母分散 $\sigma^2$ | 不偏分散 $s^2$ |

## 標本平均の性質

母集団から独立に取り出した $X_1, \dots, X_n$ の標本平均 $\bar{X} = \frac{1}{n}\sum X_i$ も、取り出すたびに値が変わる確率変数です。4章のきまりから、次のことがわかります。

$$E[\bar{X}] = \mu \qquad V[\bar{X}] = \frac{\sigma^2}{n}$$

- 期待値が母平均と一致する（**不偏**）。平均すれば当たっている
- 分散は $n$ に反比例して小さくなる。データを4倍にすると、ばらつき（標準偏差）は半分
- 標本平均の標準偏差 $\sigma/\sqrt{n}$ を**標準誤差**といいます

## 大数の法則

標本の大きさ $n$ を大きくしていくと、標本平均は母平均にいくらでも近づきます。

$$\bar{X} \to \mu \quad (n \to \infty)$$

サイコロを何回も振って平均をとると、3.5 に近づいていきます。たくさん調べれば平均は当たる、という保証です。

## 中心極限定理

もとの分布がどんな形でも（分散が有限なら）、標本平均の分布は $n$ が大きいと正規分布に近づきます。

$$\frac{\bar{X} - \mu}{\sigma / \sqrt{n}} \;\to\; N(0, 1) \quad (n \to \infty)$$

![右にすそを引く分布でも、平均をとる個数が増えると、平均の分布は正規分布に近づく](images/clt.svg)

- もとの分布がゆがんでいても、$n$ が 30 くらいあれば、平均はほぼ正規分布と考えてよいことが多い
- だから、平均について正規分布（5章）を使った推測ができる

## 平均の信頼区間

中心極限定理から、標本平均は 95% の確率で $\mu \pm 1.96\,\sigma/\sqrt{n}$ に入ります。これを裏返したものが、母平均の **95% 信頼区間**です。

$$\bar{x} \pm 1.96 \times \frac{\sigma}{\sqrt{n}}$$

$\sigma$ がわからないときは標本の $s$ を使い、1.96 の代わりに t 分布の値 $t_{0.975}(n-1)$ を使います（5章）。

```python
import numpy as np
from scipy import stats

rng = np.random.default_rng(0)
x = rng.exponential(scale=2.0, size=50)        # 右にすそを引く分布（母平均は 2）
mean, s, n = x.mean(), x.std(ddof=1), len(x)
t = stats.t.ppf(0.975, df=n - 1)
print(f"平均 {mean:.2f}、95%信頼区間 {mean - t*s/np.sqrt(n):.2f} 〜 {mean + t*s/np.sqrt(n):.2f}")
```

## まとめ

- 標本平均は母平均の不偏な推定。ばらつき（標準誤差）は $\sigma/\sqrt{n}$
- 大数の法則: たくさん調べれば標本平均は母平均に近づく
- 中心極限定理: もとの分布によらず、標本平均はほぼ正規分布になる
- 95% 信頼区間は $\bar{x} \pm 1.96\,\sigma/\sqrt{n}$（$\sigma$ がわからなければ $s$ と t 分布）

## 練習問題

```quiz
Q: 母集団の標準偏差 $\sigma=10$、データの数 $n=25$ のとき、標本平均の標準誤差はいくつですか。
A: 2
E: $\sigma/\sqrt{n} = 10/5 = 2$ です。

Q: データの数 $n$ を4倍にすると、標準誤差は何倍になりますか。
A: 0.5 | 1/2 | 半分
E: $\sqrt{4} = 2$ で割られるので、半分になります。

Q: たくさん調べれば、標本平均は母平均に近づく、という法則を何といいますか。
A: 大数の法則 | たいすうのほうそく
E: 標本平均のばらつきは、$n$ が増えると小さくなります。

Q: もとの分布によらず、標本平均がほぼ正規分布になることを何といいますか。
A: 中心極限定理 | ちゅうしんきょくげんていり
E: これが、平均の信頼区間を正規分布で作れる理由です。

Q: $\bar{x}=50$、$\sigma=10$、$n=100$ のとき、95% 信頼区間の下の端はいくつですか。
A: 48.04
E: $50 - 1.96 \times 10/\sqrt{100} = 50 - 1.96 = 48.04$ です。
```
