# 5. よく使う分布（正規・χ²・t・F）

## この章でわかること

- 正規分布と、68%・95%・99.7% の範囲
- χ²（カイ二乗）分布・t 分布・F 分布の作られ方と使い道
- Python での値の求め方

## 正規分布

平均 $\mu$、分散 $\sigma^2$ の**正規分布** $N(\mu, \sigma^2)$ の密度関数は次の形です。

$$f(x) = \frac{1}{\sqrt{2\pi}\,\sigma} \exp\!\left(-\frac{(x - \mu)^2}{2\sigma^2}\right)$$

![標準正規分布と、平均から ±1σ・±2σ に入る割合](images/normal.svg)

- 平均を中心に左右対称の釣り鐘の形
- 平均 ±1σ に約 68%、±2σ に約 95%（正確には ±1.96σ）、±3σ に約 99.7% が入る
- 正規分布に従うものを足したり定数倍したりしても、正規分布になる
- 標準化 $Z = (X-\mu)/\sigma$ で、標準正規分布 $N(0,1)$ になる
- 測定の誤差や、たくさんのものの平均は、正規分布に近くなる（6章の中心極限定理）

## χ²（カイ二乗）分布

標準正規分布に従う独立な $Z_1, \dots, Z_k$ の2乗の和が従う分布です。$k$ を**自由度**といいます。

$$W = Z_1^2 + Z_2^2 + \cdots + Z_k^2 \sim \chi^2(k)$$

![自由度による χ² 分布の形のちがい](images/chi2.svg)

- 0 以上の値だけをとり、右にすそを引く。平均は $k$、分散は $2k$
- 正規分布の標本から計算した不偏分散 $s^2$ について、$\dfrac{(n-1)s^2}{\sigma^2} \sim \chi^2(n-1)$
- 使い道: 分散の検定、適合度の検定、クロス表の独立性の検定

## t 分布

標準正規分布 $Z$ と、それと独立な $\chi^2(k)$ の $W$ から作る分布です。

$$T = \frac{Z}{\sqrt{W / k}} \sim t(k)$$

![t 分布と標準正規分布（自由度が小さいほど、すそが重い）](images/t.svg)

- 0 を中心に左右対称で、正規分布よりすそが重い。自由度が大きくなると標準正規分布に近づく
- 母分散がわからず、標本の標準偏差 $s$ で代わりにするときに使う

$$\frac{\bar{X} - \mu}{s / \sqrt{n}} \sim t(n-1)$$

- 使い道: 平均の検定・信頼区間、回帰係数の t 値（8章）

## F 分布

独立な2つの χ² を、それぞれの自由度で割った比が従う分布です。

$$F = \frac{W_1 / k_1}{W_2 / k_2} \sim F(k_1, k_2)$$

- 0 以上の値をとり、右にすそを引く
- 使い道: 2つの分散の比の検定、回帰分析で「説明変数が全部役に立たないか」を調べる F 検定、分散分析
- t 分布の2乗は F 分布になる: $T^2 \sim F(1, k)$

## 4つの分布の関係

| 分布 | 作り方 | よく使う場面 |
| --- | --- | --- |
| 正規 $N(\mu,\sigma^2)$ | （もと） | 誤差、平均の分布 |
| $\chi^2(k)$ | 標準正規の2乗を $k$ 個足す | 分散、適合度 |
| $t(k)$ | 標準正規 ÷ $\sqrt{\chi^2/k}$ | 平均、回帰係数 |
| $F(k_1,k_2)$ | $(\chi^2/k_1) ÷ (\chi^2/k_2)$ | 分散の比、回帰全体 |

## Python で値を求める

`scipy.stats` の `ppf`（分布関数の逆。下から何%の点か）と `cdf`（分布関数）を使います。

```python
from scipy import stats

print(stats.norm.ppf(0.975))         # 1.959...（両側5%の点）
print(stats.t.ppf(0.975, df=10))     # 2.228...（自由度10の t）
print(stats.chi2.ppf(0.95, df=5))    # 11.07...
print(stats.f.ppf(0.95, 2, 10))      # 4.102...
print(stats.norm.cdf(1) - stats.norm.cdf(-1))   # 0.682...（±1σ に入る割合）
```

## まとめ

- 正規分布は ±1σ に 68%、±1.96σ に 95%
- χ² は標準正規の2乗の和、t は標準正規を χ² で割ったもの、F は χ² どうしの比
- t 分布は自由度が大きいと正規分布に近づく。$s$ を使うときは t 分布で考える
