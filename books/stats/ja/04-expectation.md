# 4. 期待値と分散

1章・2章は手元のデータの計算でした。この章では、同じことを確率変数（分布）について考えます。

## 期待値

確率変数の「平均」を**期待値**といい、$E[X]$ や $\mu$ と書きます。

$$E[X] = \sum_x x\,P(X = x) \qquad E[X] = \int x\,f(x)\,dx$$

サイコロなら $E[X] = (1+2+3+4+5+6) \times \frac{1}{6} = 3.5$ です。

| きまり | 意味 |
| --- | --- |
| $E[aX + b] = aE[X] + b$ | 何倍かして足すと、期待値も同じように変わる |
| $E[X + Y] = E[X] + E[Y]$ | 足し算はいつでも分けられる |
| $E[XY] = E[X]\,E[Y]$ | $X$ と $Y$ が独立のときだけ |

## 分散と標準偏差

期待値からのずれの2乗の期待値が**分散**です。

$$V[X] = E\big[(X - \mu)^2\big] = E[X^2] - (E[X])^2$$

サイコロなら $E[X^2] = 91/6$ なので、$V[X] = 91/6 - 3.5^2 = 35/12 \approx 2.92$、標準偏差は $\sqrt{35/12} \approx 1.71$ です。

| きまり | 意味 |
| --- | --- |
| $V[aX + b] = a^2 V[X]$ | 足した定数は分散に影響しない。何倍かすると2乗で効く |
| $V[X + Y] = V[X] + V[Y] + 2\,\mathrm{Cov}(X, Y)$ | 独立なら共分散が 0 なので、分散も足し算になる |

## 標準化・歪度・尖度

平均を引いて標準偏差で割ることを**標準化**といいます。標準化した $Z$ は平均 0、分散 1 になり、単位のちがうものどうしを比べられます（偏差値も、標準化した値を 10 倍して 50 を足したもの）。

$$Z = \frac{X - \mu}{\sigma}$$

| 指標 | 式 | わかること |
| --- | --- | --- |
| 歪度（わいど） | $E[Z^3]$ | 左右の偏り。右に長くすそを引くとプラス（所得の分布など） |
| 尖度（せんど） | $E[Z^4]$ | すその重さ・とがり方。正規分布では 3 |

> 尖度は、正規分布を 0 にそろえるため 3 を引いた値（超過尖度）で表すことも多いです。`scipy.stats.kurtosis` は標準で 3 を引いた値を返します。

## 共分散と相関係数

$$\mathrm{Cov}(X, Y) = E\big[(X - \mu_X)(Y - \mu_Y)\big] = E[XY] - E[X]\,E[Y]$$

$$\rho = \frac{\mathrm{Cov}(X, Y)}{\sigma_X\,\sigma_Y}$$

- 独立なら $\mathrm{Cov}(X, Y) = 0$。ただし、共分散が 0 でも独立とは限らない（直線でない関係があるかもしれない）
- 相関係数 $\rho$ は −1 から 1。2章の $r$ は、これをデータから計算したもの

## 条件付き期待値

条件付き分布（3章）の期待値を**条件付き期待値**といいます。

$$E[Y \mid X = x] = \sum_y y\,P(Y = y \mid X = x)$$

- 「身長が 170 cm の人の、体重の平均」のように、$x$ ごとの $Y$ の平均
- $x$ を動かすと、$E[Y \mid X = x]$ は $x$ の関数になる。これを直線で表すのが回帰分析（7章）
- **繰り返し期待値の法則**: $E\big[E[Y \mid X]\big] = E[Y]$（$x$ ごとの平均を、$x$ の出やすさで平均すると、全体の平均になる）

## 母集団と標本の記号

| | 母集団（分布） | 標本（データから計算） |
| --- | --- | --- |
| 平均 | $\mu = E[X]$ | $\bar{x}$ |
| 分散 | $\sigma^2 = V[X]$ | $s^2$ |
| 共分散 | $\mathrm{Cov}(X, Y)$ | $s_{xy}$ |
| 相関係数 | $\rho$ | $r$ |

## まとめ

- 期待値は確率で重みを付けた平均。足し算はいつでも分けられる
- 分散は $E[X^2]-(E[X])^2$。定数倍は2乗で効き、独立なら和の分散は分散の和
- 標準化すると平均 0・分散 1。歪度は偏り、尖度はすその重さ
- 条件付き期待値 $E[Y\mid X=x]$ を $x$ の関数として表したものが、回帰の考え方につながる

## 練習問題

```quiz
Q: サイコロの目の期待値はいくつですか。
A: 3.5
E: (1 + 2 + 3 + 4 + 5 + 6) ÷ 6 = 3.5 です。

Q: $E[X]=2$、$E[X^2]=7$ のとき、$V[X]$ はいくつですか。
A: 3
E: $V[X] = E[X^2] - (E[X])^2 = 7 - 4 = 3$ です。

Q: $V[X]=4$ のとき、$V[3X]$ はいくつですか。
A: 36
E: 定数倍は2乗で効くので、$9 \times 4 = 36$ です。

Q: $X$ と $Y$ が独立で、$V[X]=2$、$V[Y]=3$ のとき、$V[X+Y]$ はいくつですか。
A: 5
E: 独立なら、和の分散は分散の和です。

Q: 標準化した確率変数の分散はいくつですか。
A: 1
E: 標準化すると、平均 0・分散 1 になります。
```
