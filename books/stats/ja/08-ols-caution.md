## 母集団と標本での OLS の考え方

母集団には、本当の関係 $y = \beta_0 + \beta_1 x + u$ がある（**母集団回帰**）と考えます。手元の標本から OLS で計算した $\hat\beta_0, \hat\beta_1$ は、その推定値です。標本を取り直すと $\hat\beta_1$ も変わるので、$\hat\beta_1$ も確率変数です。

$\hat\beta_1$ が平均して本当の $\beta_1$ に当たる（**不偏**）ためには、次の仮定が要ります。

| 仮定 | 意味 |
| --- | --- |
| 線形 | 母集団の関係が $\beta_0 + \beta_1 x + u$ の形 |
| ランダムに取り出す | 標本が母集団から無作為に選ばれている |
| $x$ にばらつきがある | 全部同じ $x$ では傾きが決まらない |
| **$E[u \mid x] = 0$** | 誤差項（$x$ 以外の要因）が、$x$ と関係しない。いちばん大事で、破れやすい |

さらに誤差の分散が $x$ によらず一定（**均一分散**）なら、OLS は不偏な推定量の中でばらつきが一番小さい（ガウス＝マルコフの定理）。

### 係数の標準誤差と t 値

$$V[\hat\beta_1] = \frac{\sigma^2}{\sum (x_i - \bar{x})^2}$$

- $x$ のばらつきが大きいほど、データが多いほど、傾きは正確に推定できる
- $\sigma^2$ を残差から推定し、平方根をとったものが**標準誤差** $\mathrm{se}(\hat\beta_1)$
- **t 値** $= \hat\beta_1 / \mathrm{se}(\hat\beta_1)$。絶対値がおおよそ 2 より大きいと、「$\beta_1 = 0$（効果がない）」とは言いにくい（5章の t 分布）

## 多重共線性

重回帰で、説明変数どうしの相関がとても高いことを**多重共線性**といいます。

- 例: 牛の「体重」と「体高」を両方入れる、気温の「最高」と「平均」を両方入れる
- 係数の標準誤差が大きくなり、係数の値や符号がデータで大きく変わる（どちらの変数の効果か区別できない）
- 予測の当たり具合（$R^2$）はあまり悪くならないので、気づきにくい
- 完全に一直線の関係（例: 「合計」と「その内訳全部」、ダミー変数を全カテゴリー入れる）があると、計算できない

| 確かめ方 | 内容 |
| --- | --- |
| 相関行列 | 説明変数どうしの相関係数を見る（2章） |
| VIF | $\mathrm{VIF}_j = 1 / (1 - R_j^2)$。$R_j^2$ は $x_j$ をほかの説明変数で回帰した決定係数。10 を超えると要注意 |

対処: 似た変数を1つにする・まとめる（主成分など）、正則化（Ridge。機械学習の教科書）、データを増やす。

```python
from statsmodels.stats.outliers_influence import variance_inflation_factor
# X は切片の列を含む説明変数の行列（DataFrame）
vif = [variance_inflation_factor(X.values, j) for j in range(X.shape[1])]
```

## 欠落変数バイアス

本当は $y$ に効いている変数をモデルに入れ忘れると、残した変数の係数がずれます。これを**欠落変数バイアス**（OVB: Omitted Variable Bias）といいます。

本当のモデルが $y = \beta_0 + \beta_1 x_1 + \beta_2 x_2 + u$ なのに、$x_2$ を入れずに $y$ を $x_1$ だけで回帰すると、その傾き $\tilde\beta_1$ は次のようにずれます。

$$E[\tilde\beta_1] = \beta_1 + \beta_2\,\delta_1$$

$\delta_1$ は、$x_2$ を $x_1$ で回帰したときの傾き（$x_1$ と $x_2$ の関係）です。

| | $x_1$ と $x_2$ が正の相関 | 負の相関 |
| --- | --- | --- |
| $\beta_2 > 0$ | 上にずれる（過大） | 下にずれる（過小） |
| $\beta_2 < 0$ | 下にずれる | 上にずれる |

- 例: 賃金を教育年数で回帰し、「能力」を入れないと、能力は教育年数とも賃金とも正の関係があるので、教育の効果が大きく出すぎる
- 例: 牛の乳量を「餌の量」で回帰し、「体の大きさ」を入れないと、大きい牛はよく食べ乳も多いので、餌の効果が大きく出すぎる
- 入れ忘れた変数が $x_1$ と関係しない（$\delta_1 = 0$）か、$y$ に効かない（$\beta_2 = 0$）ときは、ずれない
- 欠落変数があると、仮定 $E[u \mid x] = 0$ が破れている（入れ忘れた変数が誤差項に入り、$x$ と関係するため）

対処: その変数を入れる、近い代わりの変数（代理変数）を入れる、同じ個体を何度も測ったデータ（パネルデータ）で個体の差を取り除く、操作変数法を使う。

## まとめ

- 標本の OLS は母集団の回帰の推定。$E[u\mid x]=0$ が成り立てば不偏
- t 値 $= \hat\beta/\mathrm{se}$。$x$ のばらつきとデータの数が、推定の正確さを決める
- 多重共線性: 説明変数どうしの相関が高いと係数が不安定。相関行列と VIF で確かめる
- 欠落変数バイアス: 効いている変数を入れ忘れると、ずれは $\beta_2\delta_1$。向きは表で判断できる
