# 3. 確率変数と分布

## この章でわかること

- 確率変数と、離散・連続のちがい
- 確率関数・確率密度関数・分布関数
- 同時分布・周辺分布・条件付き分布
- 統計的独立

## 確率変数

サイコロの目のように、試すたびに値が決まり、それぞれの値の出やすさ（確率）が決まっているものを**確率変数**といいます。大文字 $X$ で書き、実際に出た値を小文字 $x$ で書きます。

| 種類 | 値 | 例 | 確率の表し方 |
| --- | --- | --- | --- |
| 離散 | とびとびの値 | サイコロの目、1日の来客数 | 確率関数 $P(X = x)$ |
| 連続 | 区間の中のどんな値も | 身長、気温、牛の体重 | 確率密度関数 $f(x)$ |

連続の確率変数では、ちょうど1つの値になる確率は 0 です。確率は区間で考え、密度関数の面積で表します。

$$P(a \le X \le b) = \int_a^b f(x)\,dx$$

## 分布関数

「$x$ 以下になる確率」を**分布関数**（累積分布関数）といいます。

$$F(x) = P(X \le x)$$

- $x$ が大きくなると増えていき（減ることはない）、0 から 1 までの値をとる
- 連続なら、$F(x)$ を微分すると密度関数 $f(x)$ になる
- $P(a < X \le b) = F(b) - F(a)$

## 標準正規分布

平均 0、分散 1 の正規分布を**標準正規分布** $N(0, 1)$ といいます。密度関数は次の釣り鐘の形です。

$$\phi(z) = \frac{1}{\sqrt{2\pi}}\, e^{-z^2/2}$$

分布関数は $\Phi(z)$ と書きます。よく使う値は $\Phi(1.96) \approx 0.975$ で、$-1.96 \le Z \le 1.96$ に 95% が入ります（5章）。

## 同時分布と周辺分布

2つの確率変数 $X, Y$ の組の出やすさを**同時分布**といいます。天気 $X$ と、傘を持つか $Y$ の例です。

| | 傘を持つ | 持たない | 合計（$X$ の周辺分布） |
| --- | --- | --- | --- |
| 晴れ | 0.1 | 0.5 | 0.6 |
| 雨 | 0.3 | 0.1 | 0.4 |
| 合計（$Y$ の周辺分布） | 0.4 | 0.6 | 1.0 |

片方だけの分布を**周辺分布**といい、もう片方について足し合わせて求めます。

$$P(X = x) = \sum_{y} P(X = x, Y = y)$$

## 条件付き分布

「$X = x$ だとわかったときの $Y$ の分布」を**条件付き分布**といいます。

$$P(Y = y \mid X = x) = \frac{P(X = x, Y = y)}{P(X = x)}$$

- 雨の日に傘を持つ確率: $0.3 / 0.4 = 0.75$
- 晴れの日に傘を持つ確率: $0.1 / 0.6 \approx 0.17$

## 統計的独立

どの組でも同時確率が周辺確率の積になるとき、$X$ と $Y$ は**独立**といいます。

$$P(X = x, Y = y) = P(X = x)\,P(Y = y)$$

独立なら、$X$ がわかっても $Y$ の分布は変わりません（$P(Y \mid X) = P(Y)$）。
上の例では $P(\text{雨}, \text{持つ}) = 0.3$ ですが、$P(\text{雨})P(\text{持つ}) = 0.4 \times 0.4 = 0.16$ なので、独立ではありません（天気で傘を持つかが変わる）。

## まとめ

- 確率変数には離散（確率関数）と連続（確率密度関数。確率は面積）がある
- 分布関数 $F(x)=P(X\le x)$ は 0 から 1 へ増えていく
- 同時分布を足し合わせると周辺分布、同時確率を周辺確率で割ると条件付き分布
- 同時確率がいつも周辺確率の積になるとき、独立

## 練習問題

```quiz
Q: 分布関数 $F(x)=P(X\le x)$ は、$x$ を大きくしていくと最後はいくつに近づきますか。
A: 1
E: 0 から 1 へ増えていきます。

Q: サイコロを1回ふって、出た目を $X$ とします。$P(X\le 2)$ はいくつですか（分数か、小数第2位まで）。
A: 1/3 | 0.33
E: 1 か 2 の、6通りのうち2通りです。

Q: 連続の確率変数では、確率は確率密度関数のグラフの何で表されますか。
A: 面積 | めんせき
E: ある1点ちょうどになる確率は 0 です。

Q: $X$ と $Y$ が独立のとき、同時確率 $P(X=a, Y=b)$ は、周辺確率 $P(X=a)$ と $P(Y=b)$ の何になりますか。
A: 積 | かけ算 | 掛け算 | せき
E: いつも周辺確率の積になるとき、独立といいます。
```
