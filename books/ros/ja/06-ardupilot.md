# 6. ArduPilot のしくみ

- フライトコントローラーと、つなぐ部品

## フライトコントローラー

![Pixhawk（初代）。ArduPilot と PX4 の両方で使われてきた、代表的なフライトコントローラー](images/pixhawk.jpg)

- **フライトコントローラー**（FC、オートパイロットの基板）は、マイコン（STM32 の ARM）・センサー・たくさんのコネクターをのせた小さな基板です
- 代表的なもの

| 製品 | ひとこと |
| --- | --- |
| Pixhawk（6C、6X など） | 公開された設計（Pixhawk の規格）に沿って、Holybro などが作る。いちばん情報が多い |
| CubePilot（Cube Orange など） | 振動対策の箱入り。産業・農業のドローンで多い |
| Matek、SpeedyBee など | 小さく安い。ホビー・小型の機体 |

![Cube Orange。オレンジの箱の中に、振動から守られたセンサーが入っている](images/cubepilot.jpg)

- ROS 2 と直接つなぐ **AP_DDS** は、メモリの大きい **H7**（STM32H7）の CPU の基板で使います（F4・F7 では非推奨）
- ファームウェアは、地上局（Mission Planner・QGroundControl）から書き込みます。決まった機能を足したファームウェアは、ArduPilot の **Custom Firmware Builder**（ウェブで選んでビルドしてもらえる）で作れます

### つなぐ部品（マルチコプターの例）

![開発用のクアッドコプター（Holybro X500）。フレーム・モーター・FC・GPS をまとめた組み立てキット](images/holybro-x500.jpg)

| 部品 | 役目 |
| --- | --- |
| フレーム・モーター・プロペラ | 機体。モーターは**ブラシレスモーター** |
| **ESC** | モーターの回転を、FC の指令どおりに制御する |
| **GPS（GNSS）とコンパス** | 位置と方角。磁気の乱れが少ないよう、マストの上に付ける。RTK の GPS なら cm 単位 |
| 電源モジュール | 電池の電圧と電流を測り、FC に安定した電気を送る |
| **LiPo 電池** | リチウムポリマー電池。軽く大電流が出るが、扱いを誤ると火が出る（12章） |
| **RC の送信機と受信機**（プロポ） | 人が手で操縦する。自動で飛ぶ機体でも、**いつでも手で取り戻せる**ように必ず付ける |
| **テレメトリ無線** | 地上局と MAVLink で話す（8章）。日本で使える周波数に注意（12章） |
| コンパニオンコンピューター | Jetson・ラズパイ。ROS 2 を動かす（11章） |

## センサーと EKF

- FC の中・外のセンサー
  - **IMU**（加速度センサーとジャイロ）: 1秒に数千回、傾きと回転を測る
  - **気圧センサー**: 高さ
  - **コンパス**（磁気センサー）: 北の方角
  - **GPS**: 地球の上の位置と速度
  - ほかに、距離センサー（地面までの高さ）、オプティカルフロー（下向きのカメラで横の動き）、外部の位置（モーションキャプチャ、Visual Odometry）
- どのセンサーも、誤差やノイズがあります。**EKF**（拡張カルマンフィルタ。ArduPilot は **EKF3**）は、全部のセンサーを組み合わせて、いちばん確からしい「位置・速度・向き」を毎回 推定します
- 飛ぶ前に、EKF の推定が落ち着くまで（GPS がつかまり、ばらつきが小さくなるまで）待つ必要があります。地上局に「EKF3 IMU0 is using GPS」のように出ます

## パラメータ

- ArduPilot には、**1,000以上のパラメータ**（設定値）があります。機体の形・センサー・フライトモードの割り当て・フェイルセーフ・PID（制御の強さ）など
- 地上局で見る・変える・ファイルに保存できます。ROS 2 からも読み書きできます（9章）
- 名前は、`グループ名_項目` の形です

| パラメータ | 意味 |
| --- | --- |
| `FRAME_CLASS`・`FRAME_TYPE` | 機体の形（クアッド・X 型など） |
| `FLTMODE1`〜`FLTMODE6` | 送信機のスイッチに割り当てるフライトモード |
| `BATT_LOW_VOLT`・`BATT_FS_LOW_ACT` | 電池が減ったときの電圧と、そのときの動き |
| `FENCE_ENABLE`・`FENCE_ALT_MAX`・`FENCE_RADIUS` | ジオフェンス（見えない柵） |
| `SERIAL2_PROTOCOL`・`SERIAL2_BAUD` | シリアルの口（TELEM2 など）を何に使うか、速さ |
| `DDS_ENABLE` | ROS 2（DDS）を使うか（9章） |
| `GUID_TIMEOUT` | GUIDED モードで速度の指令が来なくなったら止まるまでの秒数（初期値 3 秒） |

- 設定を変えたら、どのパラメータを何にしたか、記録しておきます。機体ごとにファイルに保存して、git で管理すると安心です

## フライトモード

ArduPilot の動き方は、**フライトモード**で切りかえます。番号は、ROS 2 や MAVLink からモードを変えるときに使います。

### Copter

| 番号 | モード | 動き |
| --- | --- | --- |
| 0 | STABILIZE | 傾きだけを自動で保つ。高さと位置は人が操作 |
| 2 | ALT_HOLD | 高さも保つ |
| 3 | **AUTO** | 地上局で作ったミッション（ウェイポイントの列）を自動で飛ぶ |
| 4 | **GUIDED** | 外から（地上局・コンパニオンコンピューター・ROS 2）指示された所へ飛ぶ。**ROS 2 から動かすときはこれ** |
| 5 | LOITER | GPS で、その場に止まる。手を離すと止まる |
| 6 | **RTL** | 離陸した所（ホーム）へ戻って着陸する |
| 9 | LAND | その場で着陸する |
| 16 | POSHOLD | LOITER に近い。操作の感じが少しちがう |
| 21 | SMART_RTL | 来た道を戻る |

### Rover

| 番号 | モード | 動き |
| --- | --- | --- |
| 0 | MANUAL | 人が送信機で操作 |
| 4 | HOLD | 止まる |
| 5 | LOITER | その場（ボートなら、その場の近く）にとどまる |
| 10 | AUTO | ミッションを走る |
| 11 | RTL | ホームへ戻る |
| 15 | **GUIDED** | 外からの指示で走る |

- 送信機のスイッチには、すぐ人に戻せるモード（STABILIZE・LOITER・MANUAL）と、**RTL** を必ず入れておきます

## アームとプリアームチェック

- **アーム**（arm）: モーターが回せる状態にすること。**ディスアーム**（disarm）: 止めること。アームしたらプロペラが回るので、人は離れます
- アームする前に、ArduPilot は自分で**プリアームチェック**をします。問題があるとアームできません
  - センサーのキャリブレーション（加速度・コンパス）ができていない
  - GPS の衛星が足りない、EKF が落ち着いていない
  - 電池の電圧が低い
  - RC の送信機がつながっていない
  - パラメータの矛盾
- 地上局のメッセージに「PreArm: 〜」と原因が出ます。チェックを止める（`ARMING_CHECK = 0`）ことはできますが、**実機では絶対にしません**

## フェイルセーフとジオフェンス

- **フェイルセーフ**: 何かおかしくなったときに、自動で安全な動きをするしくみ

| 何が起きたら | 例えば |
| --- | --- |
| RC の電波が切れた | RTL か LAND |
| 地上局（テレメトリ）が切れた | RTL か、そのまま続ける |
| 電池が少ない（2段階） | RTL → LAND |
| EKF がおかしい（位置がわからない） | LAND |
| GCS からの指令（GUIDED の速度）が来なくなった | その場で止まる（`GUID_TIMEOUT`） |

- **ジオフェンス**: 見えない柵。最大の高さ（`FENCE_ALT_MAX`）・ホームからの距離（`FENCE_RADIUS`）・多角形の範囲をこえそうになると、RTL などで戻ります。ROS 2 のプログラムが間違った指令を出しても、柵の外には出ないようにする、大事な保険です

## 練習問題

```quiz
Q: 全部のセンサーを組み合わせて、位置・速度・向きを推定するしくみ（拡張カルマンフィルタ）をアルファベット3文字で何といいますか。
A: EKF | EKF3
E: ArduPilot は EKF3 を使います。

Q: ROS 2 から機体を動かすときに使うフライトモードは何ですか。
A: GUIDED | ガイデッド
E: 外から指示された所へ飛びます。

Q: 離陸した所（ホーム）へ戻って着陸するフライトモードは何ですか。
A: RTL
E: 送信機のスイッチに必ず入れておきます。

Q: モーターが回せる状態にすることを何といいますか。
A: アーム | arm
E: 止めるのはディスアームです。アームする前にプリアームチェックがあります。

Q: 決めた高さや範囲をこえそうになると戻る「見えない柵」を何といいますか。
A: ジオフェンス | geofence | フェンス
E: ROS 2 のプログラムが間違えても、柵の外には出ないようにする保険です。
```
