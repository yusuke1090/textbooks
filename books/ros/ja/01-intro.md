# 1. ROS 2 と ArduPilot とは

## ROS 2

- **ROS**（Robot Operating System、ロス）は、ロボットのプログラムを作るための**道具と部品のセット**です。名前に OS と付いていますが、Windows や Linux のような OS ではなく、Linux（Ubuntu）の上で動くライブラリとツールの集まりです
- ロボットのプログラムを、小さなプログラム（**ノード**）に分け、ノードどうしがメッセージをやりとりして動きます
  - カメラのノード、障害物を見つけるノード、道を決めるノード、モーターを動かすノード…
  - それぞれを別の人が作っても、メッセージの形さえ合わせればつながる
- 世界中の研究者・会社が作ったノード（LiDAR のドライバー、地図づくり、自動走行のナビゲーション Nav2、ロボットアームの MoveIt など）を、そのまま使えるのが最大の強みです
- **ROS 2** は、ROS 1 を作り直したものです。通信に **DDS**（工場や軍で使われてきた、リアルタイムの通信の規格）を使い、製品に使える信頼性と、複数のロボット・Windows/macOS への対応を目指しています。ROS 1 は2025年5月にサポートが終わったので、いまから学ぶなら ROS 2 です

![TurtleBot3。ROS を学ぶための小さな移動ロボット](images/turtlebot3.jpg)

### ディストリビューション

ROS 2 は、毎年5月に新しい版（**ディストリビューション**）が出ます。名前は亀の名前で、アルファベット順です。偶数年に出るものは5年間サポートされる **LTS** です。

| 名前 | 出た年 | 対応する Ubuntu | サポート |
| --- | --- | --- | --- |
| Humble Hawksbill | 2022年5月 | 22.04 | 2027年5月まで（LTS） |
| **Jazzy Jalisco** | 2024年5月 | **24.04** | 2029年5月まで（LTS） |
| Kilted Kaiju | 2025年5月 | 24.04 | 2026年11月まで |
| Lyrical Luth | 2026年5月 | 26.04 | 2031年5月まで（LTS） |

- この教科書は、**Ubuntu 24.04 ＋ ROS 2 Jazzy** で進めます。ArduPilot の ROS 2 の部品が、Humble と Jazzy に対応しているためです（いちばん新しい Lyrical には、まだ正式には対応していません）
- Jetson（JetPack 6 は Ubuntu 22.04）では Humble を使うことになります。コマンドの `jazzy` を `humble` に読みかえれば、ほぼ同じです（11章）

## ArduPilot

![ArduPilot のロゴ。Plane（飛行機）・Copter（マルチコプター）・Rover（車・ボート）・Sub（水中）](images/ardu-logos.jpg)

- **ArduPilot**（アルデュパイロット）は、ドローン・飛行機・車・ボート・水中ロボットを、自動で動かすための**オープンソースのソフトウェア**（オートパイロット）です
- **フライトコントローラー**（小さな基板のコンピューター）の上で動き、センサー（加速度・角速度・コンパス・気圧・GPS）を読んで、1秒に数百回 モーターを調整して、機体を安定させます
- 2009年ごろ、Arduino を使った趣味のプロジェクト（ArduPilot Mega、APM）から始まり、いまは農業・測量・物流・研究で世界中で使われています。製品のドローンの中身が ArduPilot であることも多い
- 同じ1つのソースコードから、乗り物の種類ごとのファームウェアを作ります

| ファームウェア | 乗り物 |
| --- | --- |
| **ArduCopter** | マルチコプター（4〜8枚のプロペラ）、ヘリコプター |
| ArduPlane | 飛行機、垂直に離着陸できる飛行機（QuadPlane） |
| **ArduRover** | 車・ボート・芝刈り機・トラクター |
| ArduSub | 水中ロボット |

![初期のフライトコントローラー（ArduPilot Mega 2.5）](images/apm25.jpg)

- 地上のパソコンやタブレットの**地上局**（GCS。Mission Planner、QGroundControl）から、設定・飛行の計画（ウェイポイント）・機体の様子の確認ができます。機体と地上局は **MAVLink** という通信の決まりで話します（8章）
- よく比べられるものに **PX4**（別のオープンソースのオートパイロット）があります。同じフライトコントローラーで動き、ROS 2 との組み合わせもできます。ArduPilot は乗り物の種類が多く、農業や Rover の実績が多いのが特徴です

## 2つを組み合わせると

![ArduPilot と ROS 2 のつながり](images/ardupilot-ros2.svg)

- 役割を分けます
  - **フライトコントローラー（ArduPilot）**: 機体を安定させる・決められた所へ飛ぶ・電池が減ったら戻る、などの「**飛ぶための計算**」。止まると落ちるので、小さく確実に
  - **コンパニオンコンピューター**（Jetson・ラズパイ、ROS 2）: カメラで作物を見つける・障害物をよける・地図を作る・自分で次の行き先を決める、などの「**考える仕事**」。重い計算ができる
- 2つをつなぐ方法は2つあります
  - **AP_DDS**（ArduPilot 4.5 から）: ArduPilot が直接 ROS 2 の話し方（DDS）で話す。この教科書のおもなやり方（9章）
  - **MAVROS**: MAVLink と ROS をつなぐ中継のノード。昔からある方法
- できることの例
  - 農業用のローバーが、カメラで畝を見つけて、まっすぐ走る
  - ドローンが、カメラで生育の悪い所を見つけ、そこだけに肥料をまく
  - 牛舎や畑を自動で見回り、データを集める

## この教科書の進め方

| 部 | 章 | 中身 |
| --- | --- | --- |
| 第1部 ROS 2 | 2〜5章 | 入れ方、ノード・トピック・サービス・launch、メッセージと座標 |
| 第2部 ArduPilot | 6〜8章 | しくみ、パソコンの中で飛ばす（SITL）、MAVLink |
| 第3部 つなげる | 9〜12章 | ROS 2 から ArduPilot を動かす、Gazebo、実機（Jetson・ラズパイ）、安全と法律 |

- 必要なもの: **Ubuntu 24.04** のパソコン（ほかの OS なら仮想マシンか Docker）。メモリ 16 GB 以上、Gazebo を使うならグラフィックが速いほうがよい
- 実機は最後（11章）です。それまでは**全部パソコンの中のシミュレーション**で試せます。機体を壊さず、法律の手続きもいらないので、まずシミュレーションで慣れましょう
- Linux のコマンド・ssh・systemd、Python の基本（「Python の教科書」）、Docker（「Docker の教科書」）、git（「GitHub の教科書」）を知っていると楽に進めます
