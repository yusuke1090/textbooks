## 大豆

### 使いみちと数字

- 日本で使う大豆は年に約350万トン。そのほとんどは輸入で、**油**（大豆油）と、油をしぼったかす（**大豆かす**、牛や豚のエサ）になります
- 食べる大豆（豆腐・納豆・みそ・しょうゆ・煮豆）は約100万トンで、その2〜3割が国産です
- 国産大豆は約26万トン（2025年産、14万 ha）。北海道が約半分、ほかに宮城・秋田・佐賀・福岡・滋賀など
- 国産の大豆は、遺伝子組み換えでないこと、味の良さで、豆腐や納豆に人気があります

### 大豆の1年（本州の例）

| 時期 | 作業・育ち |
| --- | --- |
| 6月（麦のあとは6月下旬〜7月上旬） | **種まき**。畝を立ててまく。10a に 5〜7 kg |
| 6〜7月 | 芽が出る（子葉 → 初生葉 → 本葉）。**中耕・培土**（畝の間を耕し、株もとに土を寄せる）を1〜2回 |
| 7月下旬〜8月 | **開花**。花は小さく、ほとんど自家受粉 |
| 8〜9月 | 莢（さや）ができ、豆が太る。いちばん水と養分が要る時期 |
| 10月 | 葉が黄色くなって落ちる |
| 10月下旬〜11月 | **収穫**（豆用のコンバイン）。莢がカラカラになり、豆が莢の中で音をたてるころ |

- 大豆は、昼が短くなるのを感じて花を咲かせる植物です（**短日植物**）。北の品種を南で作ると早く咲きすぎ、南の品種を北で作ると咲く前に冬になってしまいます。地域に合った品種を選びます

### 根粒菌

![大豆の根の根粒。この中に根粒菌がすみ、空気の窒素を植物が使える形に変える](images/root-nodules.jpg)

- 大豆などマメ科の植物の根には、**根粒**（こんりゅう）という粒が付きます。中に**根粒菌**という細菌がすんでいます
- 根粒菌は、空気中の窒素（N₂）を、植物が使えるアンモニアに変えます（**窒素固定**）。かわりに、植物から糖をもらいます
- このおかげで、大豆は窒素肥料が少なくても育ち、大豆のあとの畑には窒素が残ります。輪作に豆を入れる大きな理由です
- 根粒は、土に酸素が必要です。水につかると働けなくなります（湿害が大豆に強くひびく理由のひとつ）
- 窒素肥料をやりすぎると、根粒が付かなくなります。大豆の元肥の窒素は少しだけ（10a に 2〜3 kg）

### 難しいところ

- **湿害**: 田んぼのあとの畑は水はけが悪く、種まきのあとに大雨が降ると、種が腐ったり芽が出なかったりします。排水対策（7章）と、畝を高くしてまくのが大事
- **雑草**: 大豆は育ちはじめが遅く、夏の雑草に負けやすい。除草剤（まいたあと・芽が出たあと）と中耕で抑えます。外来の**アサガオ類**などの、大豆の中で使える除草剤が少ない雑草が増えています
- **虫**: 葉を食べるハスモンヨトウ（西日本）、莢と豆を吸う**カメムシ**（豆がしわしわになる）、マメシンクイガ（北海道）
- **病気**: 紫斑病（豆に紫のしみ）、茎疫病（湿った畑）、ダイズシストセンチュウ
- **収穫**: 雨が多いと、豆がしわになったり、カビたりして、等級が下がります。刈りおくれると、莢がはじけて豆が落ちます

## 小豆といんげん

![小豆。あんこ・和菓子・赤飯に使う](images/adzuki.jpg)

- **小豆**（あずき）: 国産の約9割が北海道（十勝）。あんこ・和菓子・赤飯・ぜんざい。寒さに弱く、霜の前に刈る必要があります
- **いんげん**（金時豆・手亡・大福豆など）: 煮豆・白あん。ほとんど北海道
- 小豆といんげんは、天気で収穫が大きく変わり、値段も上下しやすい作物です。輸入（中国・カナダなど）の豆には高い関税がかかっています

## そば

![そばの花畑。夏の終わりに白い花が一面に咲く](images/buckwheat.jpg)

- そばは、タデ科の植物で、麦や稲の仲間ではありません
- 種をまいてから **70〜80日**ほどで収穫できます。やせた土地や寒い所でも育つので、昔から山の村で作られてきました
  - 夏そば（春にまく）と、**秋そば**（7〜8月にまき、10月に刈る。こちらが多い）
- 産地は北海道（幌加内町など）が約4割で、長野・山形・福島・茨城・栃木など
- 花は虫（ミツバチなど）で受粉するので、ハチがいないと実の入りが悪くなります
- 雨や台風で倒れやすく、霜にも弱い。収量は 10a に 50〜100 kg ほどと少なく、天気で大きく変わります
- 国産そばは消費の2〜3割で、残りは中国・アメリカなどから輸入しています。転作の作物として、田んぼのあとで作ることも多い
