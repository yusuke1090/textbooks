# 12. スマート農業

## なぜいま

- 農業をする人は、この20年で半分ほどに減り、平均年齢は70歳ほどです。やめる農家の田んぼと畑を、残った農家が引き受けて、1戸あたりの面積がどんどん大きくなっています
- 人を増やせないので、**1人で広い面積を見る**ための技術が欠かせません
- 2024年10月に**スマート農業技術活用促進法**ができました。スマート農業に合わせて作り方を変える計画（**生産方式革新実施計画**）を国が認めると、低い金利の融資や税の優遇を受けられます。認められた計画は、稲作がいちばん多くなっています

## 米づくり

### ドローン

![青森県の田んぼで使われる農業用ドローン](images/drone-paddy.jpg)

- いちばん広く使われているスマート農業の機械です。農薬・肥料（追肥）を空からまきます。10a を1〜2分ほどでまけます
- 以前は、ラジコンヘリ（大きくて高い）か、人が動力噴霧機を背負ってまいていました。ドローンで、とくに夏の暑い時期の重労働が大きく減りました
- **直播**の種まきにも使われます（3章）
- 使うときの決まり（くわしくは「ROS 2 と ArduPilot の教科書」の安全と法律の章）
  - 100 g 以上のドローンは国に**登録**し、リモート ID を付ける
  - 農薬をまくことは、航空法の「**危険物の輸送**」と「**物の投下**」にあたるので、国の**承認**が必要
  - 農薬は、ドローンでまいてよいと登録された薬だけを、決められた濃さで使う
- 自分で持たずに、散布を請け負う会社（**農業支援サービス**）に頼む農家も多い

![農業用ドローンの散布の実演。プロペラの下の風で、薬が稲の株もとまで届く](images/drone-irri.jpg)

### 水管理システム

- 4章のとおり、水の深さの調整は毎日の大仕事です。田んぼが何十か所にも散らばる大きな農家では、見回りだけで1日が終わります
- **自動給水栓**（水口に付けて、水位を見ながら自動で開け閉めする）と**水位センサー**を田んぼに置き、スマートフォンで水位を見て、遠くから操作できます
- 製品の例: WATARAS（クボタケミックス）、水田ファーモ（farmo）、paditch（笑農和）など。見回りの時間が大きく減ったという報告が多い
- 通信は、携帯の電波（LTE）や、少ない電気で遠くまで届く無線（**LPWA**、920 MHz の LoRa など）を使います。電池と太陽電池で動きます
- 中干しの延長（J-クレジット、4章）の記録にも使えます。中干しの日付を記録して、クレジットの申請をまとめて代行するスタートアップのサービスも出ています

### 自動で走る機械

- **自動直進**の田植え機: GNSS（GPS など）で位置を測り、まっすぐ植える。人はハンドルを持たず、苗の補給と曲がる所だけに集中できる
- **ロボットトラクター**・ロボット田植え機: 人が乗らずに走る。いまは、人が近く（見える所）で監視するのが条件です。遠くから監視するだけで走らせる仕組みも試されています
- 位置を cm 単位で測るには、**RTK**（基地局の補正の情報を使う方法）が必要です。JA・自治体の基地局や、携帯の会社のネットワーク型の RTK サービスを使います

### 収量コンバインと営農管理のアプリ

- **食味・収量センサー**付きのコンバイン: 刈りながら、田んぼ1枚ごとの収量と、米の水分・たんぱく質を測る
- データは、メーカーの営農管理のクラウド（クボタの KSAS、ヤンマーの SMARTASSIST など）に送られ、田んぼごとの肥料・作業・収量の記録と合わせて見られます
- 「この田んぼは収量が低く、たんぱく質が高い → 来年は肥料を減らす」のように、次の年の作り方に生かします

### 衛星とリモートセンシング

- 人工衛星やドローンのカメラで、田んぼと畑の**生育のむら**を見ます。葉の色（植物の元気さ）を数字にした **NDVI** などを使います
- 稲の刈りどきの予測、穂肥の量の決め方、倒伏の場所の確認に使われます
- 衛星の画像（例: ヨーロッパの Sentinel-2 は無料で5日ごと）を使った、農家向けのサービスもあります

## 畑作

### GNSS 自動操舵

![自動で走るトラクター（ブドウ畑での実験）。GNSS とセンサーで、決めた道筋をたどる](images/robot-tractor.jpg)

- いまあるトラクターに、ハンドルを自動で回す装置を後から付けて、GNSS の位置に合わせてまっすぐ走らせます（**自動操舵**）
- 北海道の大きな畑作農家で、急速に広がりました
  - 種まき・肥料まき・防除で、重なりと抜けが減り、種・肥料・農薬が節約できる
  - 夜や、目印の見えない所でも作業できる
  - 長時間の運転の疲れが大きく減る
- 最近は、海外製の安い装置も増え、本州の田んぼや畑でも使う人が増えています

### 可変施肥

- 衛星やドローンで見た生育のむら、土壌診断、前の年の収量マップから、**場所ごとの肥料の量を決めた地図**（施肥マップ）を作ります
- GNSS と連動する肥料まき機（ブロードキャスター）が、地図に合わせて、走りながらまく量を変えます
- 育ちの悪い所には多く、良い所には少なく。肥料を減らしながら、収量と品質をそろえることができます。小麦の追肥（タンパク質をそろえる）、てんさい・ばれいしょの元肥などで使われています

### 病気の予測

- 天気のデータから、病気の出やすさを計算して知らせる仕組みがあります
  - 稲の**いもち病**: 葉が濡れている時間と気温から感染しやすい日を推定（BLASTAM など）
  - 小麦の**赤かび病**: 開花の日の予測と、その前後の雨から、殺菌剤をまく日を決める
- 県の発生予察と組み合わせて、むだな農薬を減らします

## 費用と課題

| 技術 | 費用の目安 |
| --- | --- |
| 農業用ドローン | 100〜300万円（散布を頼むなら 10a あたり 千数百円〜） |
| 自動給水栓 | 1か所 数万〜10万円ほど ＋ 通信料 |
| 後付けの自動操舵 | 数十万〜数百万円 |
| ロボットトラクター | 1,000万円以上 |

- **費用**: 小さな農家には高い。機械を共同で使う、作業を頼む（農業支援サービス）、リースが広がっています
- **田んぼの形**: 日本の田んぼは小さく、形がばらばらで、散らばっている。大きな機械と自動運転が力を出しにくい。田んぼの区画を大きく整える工事（基盤整備）と組み合わせることが大事
- **電波**: 山の田んぼでは、携帯の電波や RTK の補正の情報が届かないことがある
- **データのつながり**: メーカーごとにアプリが分かれていて、データを一緒に見にくい。国は農業データの連携の基盤（WAGRI）を作っています
- **使いこなし**: 機械を入れても、データを読んで作り方を変えないと、効果は小さい。若い人や、地域で教え合う仕組みが大切です
