## 畑作とは

- **畑作**は、水を張らない畑で作物を作ることです。この教科書では、野菜や果物（園芸）ではなく、広い畑で機械を使って作る**麦・豆・いも・てんさい・とうもろこし・そば**などの話をします
- 日本は、これらの多くを外国から買っています

| 作物 | 国内の生産（おおよそ） | 自給率（おおよそ） | 北海道の割合 |
| --- | --- | --- | --- |
| 小麦 | 約100万トン | 約15% | 約6〜7割 |
| 大麦・はだか麦 | 約20万トン | 約10% | 少ない（佐賀・福岡・栃木など） |
| 大豆 | 約26万トン（2025年産） | 約7%（食べる大豆だけなら約25%） | 約5割 |
| ばれいしょ（じゃがいも） | 約220万トン | 約70% | 約8割 |
| てんさい | 約350万トン（根の重さ） | 砂糖の自給率は約35%（さとうきびを含む） | 全部 |
| そば | 約3〜4万トン | 約2〜3割 | 約4割 |

- 小麦と大豆の多くは、アメリカ・カナダ・オーストラリア・ブラジルから輸入しています。輸入の小麦は国がまとめて買い、製粉会社に売っています

## 北海道の畑作

![十勝平野（帯広の近く）を空から。防風林で区切られた、大きな四角い畑が並ぶ](images/tokachi-aerial.jpg)

- 北海道、とくに**十勝**（帯広のまわり）と**オホーツク**（網走・北見のまわり）は、日本の畑作の中心です
- 1戸の畑は平均 40〜50 ha ほど。本州の米農家の10倍以上です。大きなトラクターや収穫機を使い、ヨーロッパに近い農業をしています
- 夏は涼しく、梅雨がほとんどない。冬は寒くて雪や凍結で土が凍るので、冬の間は作物を作れません（秋まき小麦を除く）
- 畑の間には、強い風から土と作物を守る**防風林**が並びます

### 4つの作物の輪作

- 北海道の畑作の基本は、**畑作4品目**（小麦・てんさい・ばれいしょ・豆類）を、毎年 畑を替えて順番に作る**輪作**です

| 年 | 作物（例） |
| --- | --- |
| 1年目 | 秋まき小麦 |
| 2年目 | てんさい |
| 3年目 | 豆類（大豆・小豆・いんげん） |
| 4年目 | ばれいしょ |
| 5年目 | また小麦へ |

- 輪作のよいところ
  - 同じ作物の病気や害虫が増えない（**連作障害**を防ぐ）
  - 根の深さや吸う養分がちがうので、土を偏りなく使える
  - 豆は、空気中の窒素を土に入れてくれる（9章）
  - 小麦のあとは夏に畑があくので、緑肥（11章）や堆肥を入れられる
  - 作業の時期がずれるので、人と機械を1年中むだなく使える
- 最近は、手間のかかるてんさいとばれいしょが減り、小麦と豆ばかりになる「輪作のくずれ」が問題になっています

## 連作障害

同じ畑で同じ作物（または同じ仲間の作物）を続けて作ると、だんだん育ちが悪くなります。これを**連作障害**といいます。

| 原因 | 例 |
| --- | --- |
| 土の中の病原菌が増える | てんさいの根腐病、小麦の立枯病、大豆の茎疫病 |
| 土の中の害虫（センチュウ）が増える | ばれいしょの**シストセンチュウ**（1度入ると何十年も残る。国が検疫で広がりを防いでいる） |
| 特定の養分だけが減る | 同じ養分ばかり吸われる |
| 根から出る物質がたまる | 次の同じ作物の育ちをじゃまする |

- 田んぼ（水稲）は、水が病原菌や害虫を減らすので、連作障害がほとんどありません（1章）。畑作では、**輪作**がいちばんの対策です

## 本州の畑作: 田んぼで作る麦と大豆

- 本州・四国・九州では、麦と大豆の多くを、米を作らない**田んぼ**（転作田）で作っています
- 代表的な組み合わせ
  - **米 → 麦 → 大豆**の「**2年3作**」（関東・北陸・東海・九州など）: 1年目に米、秋に麦をまいて翌年の初夏に刈り、そのあとに大豆をまく
  - **田畑輪換**（でんぱたりんかん）: 何年か畑として麦・大豆を作り、また田んぼに戻して米を作る。畑の連作障害も、田んぼの雑草も減らせる
- 田んぼは、もともと水がたまるように作ってあるので、畑として使うときは**水はけ**が大きな課題です。麦も大豆も、根が水につかると育たなくなります（**湿害**）
  - **明渠**（めいきょ）: 田んぼのまわりや中に溝を掘り、水を排水口へ流す
  - **暗渠**（あんきょ）: 地下に管を埋めて、水を抜く。**弾丸暗渠**（土の中に丸い穴をあける機械）で、安く作ることもできる
  - **畝立て**（うねたて）: 畝を作って、その上に種をまく

## 畑作の補助金

- 日本の麦・大豆・てんさいなどは、外国の安いものと比べると、作るのにお金がかかります。そこで国は、その差をうめる**交付金**を払っています
  - **畑作物の直接支払交付金**（ゲタ対策）: 麦・大豆・てんさい・でんぷん用ばれいしょ・そば・なたねを作った量と品質に応じて払う
  - **収入減少影響緩和対策**（ナラシ対策）: 米・麦・大豆などの収入が、ふつうの年より大きく減ったとき、その一部を補う
- 2027年度からは、田んぼの転作の交付金（6章）を見直し、「田んぼか畑かにかかわらず、麦・大豆・飼料作物の収量を上げる農家」を支えるしくみに変える予定です。平均より多くとるほど交付金が増える形が考えられていて、北海道では地域による差が開くのではないかという心配も出ています
