# 付録A. 用語集（日本語・英語）

本文に出てくる言葉と、英語での言い方です。かっこの中の数字は、くわしく書いている章です。

## 全体

| 日本語 | 読み | 英語 | 意味 |
| --- | --- | --- | --- |
| ネットワーク | | network | コンピューターどうしをつないで、データをやりとりできるようにしたもの（1章） |
| インターネット | | internet | 世界中のネットワークを、同じプロトコルでつないだもの（1章） |
| プロトコル | | protocol | つなぐための約束ごと（1章） |
| パケット | | packet | データを小分けにして、ヘッダーを付けたもの（1章） |
| ヘッダー | | header | データの前に付ける、あて先などを書いた部分（1章） |
| 階層 | かいそう | layer | ネットワークの仕事を役割ごとに分けたもの。レイヤー（1章） |
| カプセル化 | かぷせるか | encapsulation | 上の階層から順にヘッダーを付けて包むこと（1章） |
| OSI 参照モデル | おーえすあいさんしょうもでる | OSI reference model | ネットワークの仕事を7つの階層に分けた見方（1章） |

## Web と DNS

| 日本語 | 読み | 英語 | 意味 |
| --- | --- | --- | --- |
| リクエスト | | request | ブラウザなどがサーバーに送るお願い（2章） |
| レスポンス | | response | サーバーが返す答え（2章） |
| メソッド | | method | リクエストの種類。GET・POST など（2章） |
| ステータスコード | | status code | レスポンスの結果を表す3けたの数。200・404 など（2章） |
| Cookie | くっきー | cookie | サーバーがブラウザに覚えさせ、毎回返してもらう値（2章） |
| Web API | うぇぶえーぴーあい | web API | アプリどうしが HTTP で機能を使い合うための入り口（2章） |
| ドメイン名 | どめいんめい | domain name | `example.com` のような、IP アドレスの代わりの名前（3章） |
| リゾルバー | | resolver | 名前をたどって調べてくれる DNS サーバー（3章） |
| 権威 DNS サーバー | けんいでぃーえぬえすさーばー | authoritative DNS server | その名前の本当の答えを持っている DNS サーバー（3章） |
| ルートサーバー | | root server | DNS の木の一番上を受け持つサーバー（3章） |
| キャッシュ | | cache | 一度もらった答えを、しばらく手元に取っておくこと（3章） |
| レコード | | record | DNS に置く情報。A・AAAA・CNAME・MX など（3章） |

## TCP/IP

| 日本語 | 読み | 英語 | 意味 |
| --- | --- | --- | --- |
| ポート番号 | ぽーとばんごう | port number | 1台の中のアプリを区別する番号（4章） |
| ウェルノウンポート | | well-known port | サーバーが待つ、決まった番号。0〜1023（4章） |
| コネクション | | connection | TCP で作る、2台の間のつながり（4章） |
| 3ウェイハンドシェイク | すりーうぇいはんどしぇいく | three-way handshake | TCP の、SYN・SYN+ACK・ACK の3回のあいさつ（4章） |
| 再送 | さいそう | retransmission | なくなったデータを送り直すこと（4章） |
| 輻輳制御 | ふくそうせいぎょ | congestion control | ネットワークの混み具合に合わせて、送る速さを落とすこと（4章） |
| IP アドレス | あいぴーあどれす | IP address | ネットワークの中の住所（5章） |
| サブネット | | subnet | ネットワーク部が同じ IP アドレスのまとまり（5章） |
| サブネットマスク | | subnet mask | ネットワーク部とホスト部の分け目を表す数（5章） |
| プライベート IP アドレス | ぷらいべーとあいぴーあどれす | private IP address | 家や会社の中で自由に使えるアドレス（5章） |
| グローバル IP アドレス | ぐろーばるあいぴーあどれす | global IP address / public IP address | 世界で1つだけの、インターネットで使うアドレス（5章） |
| ルーター | | router | パケットのあて先を見て、次へ渡す機械（5章） |
| ルーティングテーブル | | routing table | ルーターが持つ、あて先ごとの行き先の表（5章） |
| デフォルトゲートウェイ | | default gateway | 自分のネットワークの外へ出るとき、まず渡すルーター（5章） |
| ループバック | | loopback | 自分自身を表すアドレス。127.0.0.1（5章） |

## LAN と回線

| 日本語 | 読み | 英語 | 意味 |
| --- | --- | --- | --- |
| イーサネット | | Ethernet | LAN ケーブルでつなぐ有線の LAN（6章） |
| MAC アドレス | まっくあどれす | MAC address | LAN の中で機械を見分ける 48ビットのアドレス（6章） |
| フレーム | | frame | イーサネットで送る1つのまとまり（6章） |
| スイッチ | | switch | MAC アドレスを覚えて、必要な口にだけ送る機械（6章） |
| ブロードキャスト | | broadcast | 同じネットワークの全員に送ること（6章） |
| アクセスポイント | | access point | Wi-Fi の電波を出す親機（6章） |
| 光回線 | ひかりかいせん | fiber-optic line / FTTH | 家まで光ファイバーを引いた回線（7章） |
| 光ファイバー | ひかりふぁいばー | optical fiber | 中を光が進む、細いガラスの線（7章） |
| プロバイダ | | internet service provider / ISP | インターネットにつなぐサービスを売る会社（7章） |
| 基地局 | きちきょく | base station / cell tower | 携帯電話の電波を出すアンテナと機械（7章） |
| 海底ケーブル | かいていけーぶる | submarine cable / undersea cable | 海の底に敷いた、国と国を結ぶ光ファイバー（7章） |

| 帯域 | たいいき | bandwidth | 1秒に運べるデータの量（7章） |
| 遅延 | ちえん | latency | 行って帰るまでの時間（7章） |
| ポートフォワーディング | | port forwarding | 外のポートに来た通信を、中の機械へ渡す設定（7章） |

## サーバーと安全

| 日本語 | 読み | 英語 | 意味 |
| --- | --- | --- | --- |
| データセンター | | data center | サーバーを何千台も置く建物（8章） |
| ファイアウォール | | firewall | 決まりに合う通信だけを通す関所（8章） |
| ロードバランサー | | load balancer | 何台ものサーバーに仕事を分ける機械（8章） |
| ヘルスチェック | | health check | サーバーが動いているかを、定期的に確かめること（8章） |
| エッジ | | edge | CDN の、利用者の近くに置いたサーバー（8章） |
| オリジン | | origin | CDN の後ろにある、元のサーバー（8章） |
| エニーキャスト | | anycast | 同じ IP アドレスを何か所でも使い、近い所に届けるやり方（8章） |
| 暗号 | あんごう | encryption | 中身を、鍵がないと読めないようにすること（9章） |
| 公開鍵 | こうかいかぎ | public key | だれに見せてもよい鍵（9章） |
| 秘密鍵 | ひみつかぎ | private key | 自分だけが持つ鍵（9章） |
| 電子署名 | でんししょめい | digital signature | 本物で、書きかえられていないことを示す印（9章） |
| 証明書 | しょうめいしょ | certificate | サイトの公開鍵が本物だと、認証局が保証したもの（9章） |
| 認証局 | にんしょうきょく | certificate authority / CA | 証明書を出す機関（9章） |
| 鍵交換 | かぎこうかん | key exchange | 2人だけが知る共通鍵を、安全に作ること（9章） |
| 二要素認証 | にようそにんしょう | two-factor authentication | パスワードに加えて、別の方法でも本人か確かめること（9章） |

## クラウドと IoT

| 日本語 | 読み | 英語 | 意味 |
| --- | --- | --- | --- |
| クラウド | | cloud | データセンターのコンピューターを、インターネット越しに借りるしくみ（10章） |
| オンプレミス | | on-premises | サーバーを自分で持って、自分の所に置くこと（10章） |
| リージョン | | region | クラウドの会社のデータセンターがある地域（10章） |
| アベイラビリティゾーン | | availability zone | リージョンの中の、電気や回線が別々のデータセンターのまとまり（10章） |
| エグレス | | egress | クラウドから外へ出すデータの転送（10章） |
| 責任共有モデル | せきにんきょうゆうもでる | shared responsibility model | クラウドの会社と借りる人で、守る範囲を分ける考え方（10章） |
| セキュリティグループ | | security group | クラウドの、サーバーごとのファイアウォール（11章） |
| サーバーレス | | serverless | サーバーを用意せず、仕事の単位で頼む使い方（11章） |
| コールドスタート | | cold start | しばらく使われていない関数の、最初の起動の遅れ（11章） |
| ゲートウェイ | | gateway | ネットワークの出入り口になる機械。IoT では、センサーのデータをインターネットへ取り次ぐ機械（12章） |
| ブローカー | | broker | MQTT のメッセージを配る、真ん中のサーバー（12章） |
| トピック | | topic | MQTT のメッセージに付ける、`/` で区切った名前（12章） |
| パブリッシュ | | publish | MQTT でトピックにメッセージを送ること（12章） |
| サブスクライブ | | subscribe | MQTT で、トピックのメッセージを受け取ると申しこむこと（12章） |
| エッジコンピューティング | | edge computing | データをクラウドに送る前に、その場で処理すること（12章） |

## 略語

| 日本語 | 読み | 英語 | 意味 |
| --- | --- | --- | --- |
| LAN | らん | LAN (local area network) | 家や会社の中のネットワーク |
| WAN | わん | WAN (wide area network) | 遠くの場所どうしをつなぐネットワーク |
| HTTP | えいちてぃーてぃーぴー | HTTP (HyperText Transfer Protocol) | Web のやりとりの決まり（2章） |
| URL | ゆーあーるえる | URL (Uniform Resource Locator) | データのある場所を表す文字（2章） |
| DNS | でぃーえぬえす | DNS (Domain Name System) | 名前を IP アドレスに変えるしくみ（3章） |
| TTL | てぃーてぃーえる | TTL (time to live) | DNS では覚えてよい時間、IP では通れるルーターの数（3・5章） |
| TCP | てぃーしーぴー | TCP (Transmission Control Protocol) | 確実に順番どおりに届けるプロトコル（4章） |
| UDP | ゆーでぃーぴー | UDP (User Datagram Protocol) | 送りっぱなしの軽いプロトコル（4章） |
| QUIC | くいっく | QUIC | UDP の上で動く、HTTP/3 のプロトコル（4章） |
| ICMP | あいしーえむぴー | ICMP (Internet Control Message Protocol) | ping などで使う、IP の連絡用のプロトコル（5章） |
| ARP | あーぷ | ARP (Address Resolution Protocol) | IP アドレスから MAC アドレスを調べるプロトコル（6章） |
| MTU | えむてぃーゆー | MTU (maximum transmission unit) | 1回に送れるデータの大きさ（6章） |
| DHCP | でぃーえいちしーぴー | DHCP (Dynamic Host Configuration Protocol) | IP アドレスなどを自動で配るしくみ（7章） |
| NAT | なっと | NAT (network address translation) | アドレスとポートを付けかえて、1つのアドレスを分け合うしくみ（7章） |
| CGNAT | しーじーなっと | CGNAT (carrier-grade NAT) | 回線の会社が、たくさんの家で1つのアドレスを分ける NAT（7章） |
| AS | えーえす | AS (autonomous system) | 1つの組織が持つ、ネットワークのまとまり（7章） |
| BGP | びーじーぴー | BGP (Border Gateway Protocol) | AS どうしが道を教え合うプロトコル（7章） |
| IX | あいえっくす | IX (internet exchange) | たくさんの AS が集まってつながる所（7章） |
| CDN | しーでぃーえぬ | CDN (content delivery network) | 利用者の近くから写しを返すしくみ（8章） |
| TLS | てぃーえるえす | TLS (Transport Layer Security) | 通信を暗号にするプロトコル（9章） |
| SSH | えすえすえいち | SSH (Secure Shell) | ほかのコンピューターを安全に操作するプロトコル（9章） |
| VPN | ぶいぴーえぬ | VPN (virtual private network) | インターネットの上に作る、自分だけのネットワーク（9章） |
| IaaS | いあーす | IaaS (infrastructure as a service) | 仮想のサーバーなどを借りる形（10章） |
| PaaS | ぱーす | PaaS (platform as a service) | アプリを動かす場所を借りる形（10章） |
| SaaS | さーす | SaaS (software as a service) | できあがったアプリを使う形（10章） |
| VPC | ぶいぴーしー | VPC (virtual private cloud) | クラウドの中の、自分だけのネットワーク（11章） |
| IoT | あいおーてぃー | IoT (Internet of Things) | センサーや機械をインターネットにつなぐこと（12章） |
| MQTT | えむきゅーてぃーてぃー | MQTT | IoT のための、パブリッシュとサブスクライブのプロトコル（12章） |
