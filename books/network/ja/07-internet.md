# 7. 家からインターネットへ（NAT・プロバイダ・海底ケーブル）

パケットは家のルーターまで届きました。ここから先は、光ファイバーで**プロバイダ**へ、プロバイダどうしがつながる所を通って、ときには**海底ケーブル**で海をわたり、サーバーのあるデータセンターへ向かいます。

## DHCP: つないだら IP アドレスが自動で付く

Wi-Fi につないだだけで通信できるのは、ルーターの **DHCP サーバー**が、必要な設定を配ってくれるからです。

1. パソコン:「だれか IP アドレスをください」（全員あて）
2. ルーター:「`192.168.3.123` はどうですか」
3. パソコン:「それをください」
4. ルーター:「どうぞ。24時間使えます」

もらうのは、IP アドレス・サブネット（`/24`）・デフォルトゲートウェイ・DNS サーバー・使える時間（**リース**）です。ラズパイや Jetson をサーバーにするなら、ルーターの設定で「この MAC アドレスにはいつも同じ IP アドレス」と決めておくと（**DHCP の予約**）、毎回同じアドレスでつなげます。

## NAT: 1つのグローバル IP アドレスを、みんなで使う

![NAT がアドレスとポートを付けかえる](images/nat.svg)

プロバイダから家にもらえるグローバル IP アドレスは、ふつう1つです。家の中のスマホ・パソコン・テレビは、プライベート IP アドレス（`192.168.3.x`）のままでは、インターネットで返事を受け取れません。

そこでルーターは、外へ出るパケットの送り元を、自分のグローバル IP アドレスとポートに書きかえ、その対応を表に覚えておきます（**NAT**。ポートも使うので NAPT・IP マスカレードともいう）。返事が来たら、表を見て元の機械へ戻します。

| 家の中 | ルーターの外側 | 相手 |
| --- | --- | --- |
| `192.168.3.123:50001`（パソコン） | `203.0.113.45:40001` | `104.20.23.154:443` |
| `192.168.3.45:50001`（スマホ） | `203.0.113.45:40002` | `104.20.23.154:443` |

自分のグローバル IP アドレスは、外のサーバーに聞くとわかります。

```bash
curl https://api.ipify.org
```

### 外からは入ってこられない

NAT の表は、中から外へ出たときに作られます。だから、外から家の中の機械に、いきなりつなぐことはできません。これは守りにもなりますが、家のラズパイを外から使いたいときには困ります。

- ルーターで「外の 8080番に来たら、ラズパイの 80番へ」と決める（**ポートフォワーディング**）。外に公開することになるので、守りに注意する
- 携帯電話の回線（4G・5G）や一部のプロバイダは、たくさんの家で1つのグローバル IP アドレスを分けている（**CGNAT**）。この場合はポートフォワーディングもできない
- そこで、機械のほうから外のサーバーにつないでおく方法がよく使われる。VPN（9章）や、IoT の MQTT（12章）

## 家からプロバイダまで: アクセス回線

| 回線 | しくみ | 特ちょう |
| --- | --- | --- |
| **光回線**（FTTH） | 家まで光ファイバーを引く。家の **ONU** が光と電気を変える | 速くて安定。1〜10 Gbps |
| **携帯電話の回線**（4G・5G） | 近くの**基地局**と電波でつなぐ | 工事がいらない。牛舎や畑でも使える |
| ケーブルテレビ | テレビの同軸ケーブル | 地域による |
| **衛星**（Starlink など） | 低い軌道を回るたくさんの衛星と電波でつなぐ | 線が届かない山や海でも使える |

![5G の基地局のアンテナ](images/5g-antenna.jpg)

![Starlink のアンテナ](images/starlink.jpg)

**光ファイバー**は、髪の毛くらいの細いガラスの線で、中を光が反射しながら進みます。電気より遠くまで弱まらずに届き、雷などの電気のノイズも受けません。

![光ファイバーの中を進む光](images/optical-fiber.jpg)

![電柱を通る光ファイバーのケーブル](images/fiber-pole.jpg)

### 日本の光回線: PPPoE と IPoE

日本の光回線（NTT のフレッツ光と、それを借りて売る「光コラボ」）には、プロバイダへのつなぎ方が2つあります。

| つなぎ方 | しくみ | 夜の混み方 |
| --- | --- | --- |
| **PPPoE**（IPv4） | ID とパスワードでログインして、プロバイダの入り口の機械を通る | 入り口の機械が混んで、夜に遅くなりやすい |
| **IPoE**（IPv6） | ログインなしで、太い入り口を通る。IPv4 も IPv6 の中に入れて運ぶ（**IPv4 over IPv6**。「v6プラス」など） | 混みにくい |

夜だけ遅いなら、プロバイダやルーターが IPoE に対応しているかを確かめます。

## プロバイダとプロバイダのつながり

![家からサーバーまで、ネットワークのネットワーク](images/internet.svg)

インターネットは、何万ものネットワークのつながりです。プロバイダ・大きな会社・大学などが、それぞれ1つのまとまり（**AS**、自律システム）として、自分のネットワークを持っています。

- AS どうしは、**BGP** というプロトコルで「このアドレスのまとまりには、うちを通れば届きます」と教え合う。ルーターのルーティングテーブルは、これで作られる
- たくさんの AS が1か所に集まって、まとめてつなぐ場所を **IX**（インターネットエクスチェンジ）という。東京と大阪に JPIX・JPNAP・BBIX などがある
- 小さいプロバイダは、大きいプロバイダにお金をはらって、世界中へ運んでもらう（**トランジット**）。同じくらいの大きさどうしは、おたがいの分をただで交換することが多い（**ピアリング**）

![インターネットエクスチェンジ（DE-CIX）の機械](images/ix.jpg)

ドイツのフランクフルトの DE-CIX は、世界でも最大級の IX です。

## 海底ケーブル: 海をわたる

![海底ケーブルの断面](images/submarine-cable.jpg)

国と国の間のデータは、ほとんど（99%ほど）が衛星ではなく**海底ケーブル**で運ばれます。世界の海に 500本をこえるケーブルが敷かれています。

- 深い海ではホースくらいの太さ（2cm ほど）。中心の光ファイバーを、鉄の線・銅・プラスチックで包んでいる。浅い所は、いかりや漁の網から守るため、太くよろいを付ける
- 50〜100 km ほどごとに、弱まった光を強くする**中継器**が入っている。電気はケーブルの中の銅で、陸から送る
- 新しいケーブルは、1本で毎秒数十〜数百テラビット（Tbps）を運べる
- 専用の**ケーブル船**で敷き、こわれたら引き上げて直す

![日本のケーブル船（KDDI ケーブルインフィニティ）](images/cable-ship.jpg)

海底ケーブルが陸に上がる所を**陸揚げ局**といいます。日本は太平洋とアジアを結ぶ通り道で、千葉の房総半島や三重の志摩などに陸揚げ局があります。

![千葉の KDDI 千倉の陸揚げ局](images/landing-station.jpg)

## 速さには2つある: 帯域と遅延

「回線が速い」には、2つの意味があります。

| | 意味 | 単位 | 大事なとき |
| --- | --- | --- | --- |
| **帯域**（スループット） | 1秒にどれだけ運べるか。道路の車線の数 | Mbps・Gbps | 動画・大きなファイル |
| **遅延**（レイテンシ） | 行って帰るまでの時間（RTT）。道路の長さ | ms（ミリ秒） | ゲーム・通話・Web の1回1回のやりとり |

光ファイバーの中の光は、1秒に約20万 km 進みます。光の速さより速くはできないので、遠い相手ほど遅延は大きくなります。

| 相手 | RTT のめやす |
| --- | --- |
| 同じ LAN の中 | 1 ms 未満 |
| 国内のサーバー（家が東京・大阪から遠くても） | 5〜30 ms |
| アメリカの西海岸 | 100 ms ほど |
| ヨーロッパ | 200〜250 ms |
| 静止衛星の回線 | 600 ms ほど |
| Starlink（低い軌道の衛星） | 30〜60 ms ほど |

Web のページは、DNS・TCP・暗号のあいさつ・たくさんのリクエストで何度も行き来するので、帯域より遅延がきくことがよくあります。だから、サーバーを利用者の近くに置く CDN（8章）やクラウドのリージョン（10章）が大事になります。

## まとめ

- DHCP が、IP アドレス・ゲートウェイ・DNS サーバーを自動で配る
- NAT で、家の中のプライベート IP アドレスを1つのグローバル IP アドレスにまとめる。外からは入ってこられない
- 家からプロバイダへは、光回線・携帯電話・衛星など。日本の光回線は IPoE（IPv6）が混みにくい
- プロバイダ（AS）どうしは BGP で道を教え合い、IX でつながる。国と国は海底ケーブル
- 速さには帯域（Mbps）と遅延（ms）がある。遅延は距離で決まる

## 練習問題

```quiz
Q: つないだ機械に、IP アドレスやデフォルトゲートウェイを自動で配るしくみは何ですか。
A: DHCP
E: 使える時間（リース）を決めて貸します。

Q: 家の中のプライベート IP アドレスを、1つのグローバル IP アドレスにまとめるしくみを何といいますか。
A: NAT | NAPT | IP マスカレード | IPマスカレード
E: アドレスとポートの対応を表に覚えておき、返事を元の機械に戻します。

Q: AS どうしが「このアドレスにはうちを通れば届く」と教え合うプロトコルは何ですか。
A: BGP
E: インターネットのルーティングテーブルは BGP で作られます。

Q: 国と国の間のデータのほとんどを運んでいるものは何ですか。
A: 海底ケーブル | 海底光ケーブル | submarine cable | undersea cable
E: 衛星ではなく、海の底の光ファイバーで運ばれています。

Q: 「行って帰るまでの時間」で表す、回線の速さのことを何といいますか（漢字2文字）。
A: 遅延 | レイテンシ | latency
E: 1秒に運べる量は帯域（スループット）です。
```
