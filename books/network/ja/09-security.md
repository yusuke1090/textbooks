# 9. 安全につなぐ（HTTPS・SSH・VPN）

パケットは、カフェの Wi-Fi・プロバイダ・IX・海底ケーブルと、他人の機械をたくさん通ります。そのままでは、途中で中身を読まれたり、書きかえられたり、にせのサーバーに答えられたりするかもしれません。それを防ぐのが暗号です。

## 守りたい3つのこと

| 心配 | 守り方 | しくみ |
| --- | --- | --- |
| 途中で**盗み見**られる | 中身を暗号にする | 共通鍵暗号 |
| 途中で**書きかえ**られる | 書きかえたらわかる印を付ける | メッセージ認証コード |
| **にせもの**の相手とつながる | 相手が本物か確かめる | 証明書と電子署名 |

## 鍵は2種類

- **共通鍵暗号**: 同じ鍵で、暗号にしたり、元に戻したりする。速いので、データそのものはこれで暗号にする（AES など）。ただし、鍵を相手にどうやって安全に渡すかが問題
- **公開鍵暗号**: 2つで1組の鍵（**公開鍵**と**秘密鍵**）を使う。公開鍵はだれに見せてもよい。秘密鍵で作った**電子署名**は、公開鍵で本物か確かめられる

TLS（下）では、公開鍵のしくみで相手を確かめながら、その場かぎりの共通鍵を2人で作り（**鍵交換**）、あとは速い共通鍵暗号でやりとりします。

## HTTPS と TLS

**HTTPS** は、HTTP を **TLS** で暗号にしたものです。いまは Web のほとんどが HTTPS です。

![TLS のあいさつ（TLS 1.3）](images/tls.svg)

1. ブラウザ:「つなぎたいです。使える暗号はこれとこれ。鍵交換の材料はこれ」
2. サーバー:「この暗号にしましょう。鍵交換の材料はこれ。私の**証明書**と、署名はこれ」
3. ブラウザは証明書が本物で、名前が開いた URL と合うかを確かめる。両方の材料から同じ共通鍵ができる
4. ここからは全部暗号で、HTTP のやりとりをする

TLS 1.3 では、このあいさつが1往復で終わります。

### 証明書と認証局

**証明書**は、「`example.com` の公開鍵はこれです」と、**認証局**（CA）が署名して保証したものです。

- 認証局の証明書（**ルート証明書**）は、OS やブラウザに最初から入っている。そこから「ルート → 中間の認証局 → サイト」と署名をたどって確かめる
- **Let's Encrypt** は、無料で証明書を出す認証局。いまの有効期限は 90日で、自動で更新する。GitHub Pages も使っている
- 期限が切れると、ブラウザに大きな警告が出る

`curl -v` で、証明書の中身とあいさつの結果を見られます。

```bash
curl -v -o /dev/null https://yusuke1090.github.io/textbooks/
```

```text
* SSL connection using TLSv1.3 / TLS_AES_128_GCM_SHA256 / X25519MLKEM768 / RSASSA-PSS
* ALPN: server accepted h2
* Server certificate:
*   subject: CN=*.github.io
*   start date: Sep 30 23:44:46 2026 GMT
*   expire date: Dec 29 23:44:45 2026 GMT
*   issuer: C=US; O=Let's Encrypt; CN=YR1
*   subjectAltName: "yusuke1090.github.io" matches cert's "*.github.io"
```

- `TLSv1.3` で、データは `AES_128_GCM`（共通鍵暗号）で暗号にしている。鍵交換の `X25519MLKEM768` は、将来の量子コンピューターでも解けないように強めたもの
- 証明書は `*.github.io`（github.io のどの名前でもよい）用で、Let's Encrypt が出した、90日のもの
- `h2` は HTTP/2 で話すと決まったこと

### 鍵のマークは「安全なサイト」ではない

アドレスバーの鍵のマークは、「通り道で読まれない」「このドメインの本物のサーバーとつながっている」ということだけを表します。にせのサイト（フィッシング）も、自分のドメインで証明書をとれば鍵のマークが出ます。ドメイン名が正しいかを自分で見ることが大事です。

## SSH: ほかのコンピューターを安全に操作する

**SSH** は、ネットワークの先のコンピューターに入って、コマンドを打つためのプロトコルです（ポート 22）。ラズパイや Jetson、クラウドのサーバーの操作に使います。やりとりは全部暗号になります。

```bash
ssh pi@raspberrypi.local
```

- 初めてつなぐと「このサーバーの鍵の指紋は ○○ です。続けますか」と聞かれる。答えると `~/.ssh/known_hosts` に覚え、次から鍵が変わったら警告する（にせのサーバーを見つけるため）
- パスワードより、**公開鍵認証**（`ssh-keygen` で作った鍵）を使う。作り方は [GitHub の教科書](https://yusuke1090.github.io/textbooks/?b=github) の3章と同じ
- 外から見える所に置くなら、パスワードでのログインを止める（`/etc/ssh/sshd_config` の `PasswordAuthentication no`）

### ポートフォワーディング: SSH のトンネル

SSH のつながりの中に、別の通信を通すこともできます。たとえば、ラズパイの中だけで動いている Web の画面（80番）を、手元のブラウザで見られます。

```bash
ssh -L 8080:localhost:80 pi@raspberrypi.local
# 手元のブラウザで http://localhost:8080 を開くと、ラズパイの 80番が見える
```

## VPN: インターネットの上に、自分だけのネットワークを作る

**VPN**（Virtual Private Network）は、インターネットの上に暗号のトンネルを作り、離れた機械どうしを、同じ LAN にいるようにつなぐしくみです。

| 使い道 | 例 |
| --- | --- |
| 会社のネットワークに家から入る | 社内のサーバーやファイルを使う |
| 外の Wi-Fi で守る | カフェの Wi-Fi を、家や会社のネットワーク経由で使う |
| 離れた機械を自分のネットワークに入れる | 牧場の Jetson、家のラズパイに、どこからでも SSH |

- **WireGuard** は、新しくて速く、設定の短い VPN。Linux に入っている
- **Tailscale** は、WireGuard を使って、自分の機械どうしを自動でつなぐサービス。NAT や携帯電話の回線（CGNAT、7章）の後ろにある機械にも、ポートフォワーディングなしでつなげる。機械には `100.x.y.z` のアドレスが付く

## 守りの基本

- OS とルーターのソフトを新しくしておく（`sudo apt update && sudo apt upgrade`）
- 初めから入っているパスワード（ルーター・カメラ・ラズパイ）を必ず変える
- 外に開くポートは最小にする（8章のファイアウォール）。SSH は公開鍵だけにするか、VPN の中からだけにする
- 大事なサービスは、パスワードに加えてスマホのアプリなどで確かめる（**二要素認証**）

## まとめ

- 暗号で、盗み見・書きかえ・にせものを防ぐ。データは共通鍵、相手の確認と鍵交換は公開鍵のしくみ
- HTTPS は HTTP を TLS で暗号にしたもの。証明書は認証局が保証する。鍵のマークは「サイトが安全」の意味ではない
- SSH で、ほかのコンピューターを安全に操作する。`-L` でトンネルも作れる
- VPN で、離れた機械を自分のネットワークに入れる（WireGuard・Tailscale）

## 練習問題

```quiz
Q: HTTP を暗号にするために使うプロトコルは何ですか（アルファベット3文字）。
A: TLS | SSL | SSL/TLS
E: HTTPS は HTTP over TLS です。前の名前は SSL でした。

Q: サイトの公開鍵が本物だと、署名して保証する機関を何といいますか。
A: 認証局 | CA | Certificate Authority
E: 認証局のルート証明書は、OS やブラウザに最初から入っています。

Q: 無料で証明書を出す、有名な認証局の名前は何ですか。
A: Let's Encrypt | Lets Encrypt | レッツエンクリプト
E: 有効期限は 90日で、自動で更新します。

Q: SSH で、手元の 8080番を、つないだ先の 80番につなぐトンネルを作るオプションは何ですか。
| ssh ??? 8080:localhost:80 pi@raspberrypi.local
A: -L
E: ローカルのポートを転送するので -L です。

Q: インターネットの上に暗号のトンネルを作り、離れた機械を同じ LAN にいるようにつなぐしくみは何ですか。
A: VPN | Virtual Private Network
E: WireGuard や Tailscale などがあります。
```
