# 1. 単語帳

## この章でわかること

- IELTS とバンドスコアのしくみ、バンド7 で求められる語彙
- 言葉の覚え方（コロケーション・言いかえ・品詞の仲間）
- よく出る話題ごとの言葉（教育・環境・テクノロジー・健康・仕事と経済・社会と都市・農業と食）
- グラフの説明、つなぎの言葉、言いかえ、まちがえやすい言葉

この教科書は、IELTS（アカデミック）で**バンド7**をとるための本です。1章で言葉をそろえ、2〜5章で Writing・Reading・Speaking・Listening のやり方を学びます。例文と模範解答は英語、説明は日本語です（English に切り替えると、説明も英語になります）。

## IELTS とバンドスコア

| 技能 | 時間 | 中身 |
| --- | --- | --- |
| Listening | 約30分 | 4つのパート、40問（4章） |
| Reading | 60分 | 3つの長文、40問（3章） |
| Writing | 60分 | Task 1（150語以上）と Task 2（250語以上）（2章） |
| Speaking | 11〜14分 | 試験官と1対1、3つのパート（4章） |

- 技能ごとに **0〜9 のバンド**（0.5 きざみ）が付き、4つの平均を 0.5 きざみに丸めたものが**総合のバンド**です。平均の端数が .25 なら .5 に、.75 なら次の整数に上げます
  - 例: Listening 7.5・Reading 7.0・Writing 6.5・Speaking 7.0 → 平均 7.0 → 総合 **7.0**
  - 例: 7.0・7.0・6.5・6.5 → 平均 6.75 → 総合 **7.0**
- バンド7 は「**良い使い手**」（good user）。ときどき誤りや不自然さはあっても、複雑な言葉を使いこなし、細かい理屈もわかる、という段階です。多くの大学院・海外の大学の入学や、仕事のビザで求められる目安です
- Listening と Reading は、40問のうち **およそ30問**の正解でバンド7 です（試験ごとに少し変わります）

## バンド7 の語彙とは

Writing と Speaking では、語彙（**Lexical Resource**）が採点の4分の1を占めます。バンド7 の目安は次のとおりです。

- 言いたいことを、**ある程度 柔軟に、正確に**言える語彙の幅がある
- **あまり一般的でない言葉**（less common words）を使い、言葉の組み合わせ（**コロケーション**）や、書き言葉・話し言葉の違いにも気を配っている
- 言葉の選び方やつづりのまちがいが、ときどきある程度

むずかしい単語をたくさん並べる必要はありません。**ふつうの言葉を、正しい組み合わせで、くり返さずに使える**ことが大事です。

## 言葉の覚え方

- **コロケーションで覚える**: `problem` だけでなく `tackle a problem`（問題に取り組む）、`a growing problem`（大きくなっている問題）のように、いっしょに使う言葉ごと覚えます
- **言いかえを3つ持つ**: 同じ言葉をくり返すと、語彙の点が上がりません。`important` なら `crucial`・`vital`・`essential` のように言いかえを持っておきます（下の「言いかえの組」）
- **品詞の仲間で覚える**: `economy`（名詞）・`economic`（形容詞）・`economically`（副詞）・`economise`（動詞）のように、形を変えて文を作れるようにします
- **自分の文を作る**: 覚えた言葉で、自分のこと（仕事・地元・興味のある分野）の文を1つ作ると、Speaking ですぐ使えます
- **つづりも覚える**: Listening と Reading の答えは、つづりがまちがうと不正解です。`environment`・`government`・`accommodation`・`necessary` はよく出るのに、まちがえやすい言葉です

## グラフの説明の言葉

Writing Task 1（2章）で、数の変化を表す言葉です。動詞と名詞の両方の形で使えるようにします。

| 動き | 動詞 | 名詞 |
| --- | --- | --- |
| 上がる | rise, increase, grow, climb | a rise, an increase, growth |
| 急に上がる | soar, surge, rocket | a surge |
| 下がる | fall, decrease, decline, drop | a fall, a decrease, a decline, a drop |
| 急に下がる | plummet, plunge | a plunge |
| 上がり下がりする | fluctuate | a fluctuation |
| 横ばいになる | level off, stabilise, plateau | a plateau |
| 最も高くなる | peak (at …) | a peak |
| 最も低くなる | hit a low, bottom out | a low |

| 程度 | 形容詞 | 副詞 |
| --- | --- | --- |
| 大きく | significant, substantial, dramatic | significantly, substantially, dramatically |
| ゆるやかに | gradual, steady, moderate | gradually, steadily, moderately |
| 少し | slight, marginal | slightly, marginally |

- 動詞の文: Milk consumption **rose sharply** from 2010 to 2015.
- 名詞の文: There was **a sharp rise** in milk consumption from 2010 to 2015.
- 数の言い方: **roughly / approximately** 40%、**just over / just under** half、**a quarter**、**two-thirds**、**the vast majority**

## つなぎの言葉

| 働き | 言葉 | 例 |
| --- | --- | --- |
| 付け足す | moreover, furthermore, in addition | **Moreover**, robots can work at night. |
| 反対のこと | however, nevertheless, on the other hand | **However**, the cost remains high. |
| 対比 | whereas, while | Sales rose in Asia, **whereas** they fell in Europe. |
| 結果 | therefore, consequently, as a result | **Consequently**, many farmers left the industry. |
| 理由 | due to, owing to（後ろは名詞） | **Due to** the drought, yields fell. |
| 例 | for instance, for example, such as | **For instance**, Denmark taxes sugary drinks. |
| 譲歩 | although, even though, despite（名詞） | **Despite** the cost, the system is popular. |
| まとめ | in conclusion, overall | **Overall**, the benefits outweigh the drawbacks. |

- `however` は文の頭か途中に置き、**カンマ**で区切ります。2つの文を `however` だけでつなぐのはまちがいです（× It is cheap, however it is slow.）
- `despite` と `due to` の後ろは**名詞**、`although` と `because` の後ろは**文**です（despite **the rain** / although **it rained**）
- つなぎの言葉を毎文に付けると、かえって点が下がります（使いすぎ）。段落の初めと、話の向きが変わる所だけに使います

## 言いかえの組

Reading と Listening の問題は、本文と**ちがう言葉で言いかえて**出ます。Writing では、問題文をそのまま写さずに言いかえます。

| ふつうの言葉 | 言いかえ |
| --- | --- |
| important | crucial, vital, essential, significant |
| big | substantial, considerable, major |
| show | indicate, illustrate, demonstrate, reveal |
| help | assist, support, contribute to |
| problem | issue, challenge, concern |
| increase | rise, growth, an upward trend |
| people | individuals, citizens, the public |
| think | believe, argue, maintain, claim |
| because of | due to, owing to, as a result of |
| a lot of | a large number of（数えられる）, a great deal of（数えられない） |

## よく使うコロケーション

| コロケーション | 意味 |
| --- | --- |
| **pose** a threat to | 〜に脅威をもたらす |
| **raise** awareness of | 〜への関心を高める |
| **have** an impact on | 〜に影響を与える |
| **take** measures / steps | 対策をとる |
| **play** a key role in | 〜で大きな役割を果たす |
| **meet** the demand for | 〜の需要を満たす |
| **address** an issue | 問題に取り組む |
| **reach** a consensus | 意見をまとめる |
| a **heavy** reliance on | 〜への強い依存 |
| a **widespread** belief | 広く信じられている考え |

## まちがえやすい言葉

| 組 | 使い分け |
| --- | --- |
| affect / effect | affect は動詞（影響する）、effect はふつう名詞（影響）。The drought **affected** yields. / It **had an effect on** yields. |
| economic / economical | economic は「経済の」、economical は「節約になる」。**economic** growth / an **economical** car |
| rise / raise | rise は自分が上がる（目的語なし）、raise は何かを上げる。Prices **rose**. / They **raised** prices. |
| fewer / less | fewer は数えられる名詞、less は数えられない名詞。**fewer** farms / **less** milk |
| advice / advise | advice は名詞（数えられない）、advise は動詞。some **advice** / I **advise** you to … |
| lose / loose | lose は失う、loose はゆるい。 |
| percent / percentage | 数の後ろは percent（20 **percent**）、数のないときは percentage（a large **percentage**） |
| information / research / equipment | 数えられない名詞。× informations、× researches、× equipments |

## 練習問題

```quiz
Q: Listening 7.5・Reading 7.0・Writing 6.0・Speaking 6.5 のとき、総合のバンドはいくつですか。
A: 7 | 7.0
E: 平均は 6.75 で、.75 は次の整数に上げるので 7.0 です。

Q: 「影響する」という意味の**動詞**は、affect と effect のどちらですか。
A: affect
E: effect はふつう名詞（影響）です。The drought affected yields.

Q: 次の文の空所に入る1語は何ですか。There were ___ farms in the region than ten years ago.（fewer か less）
A: fewer
E: farms は数えられる名詞なので fewer。数えられない名詞（milk など）には less を使います。

Q: 「問題に取り組む」は ___ an issue。空所に入る1語は何ですか（a で始まる動詞）。
A: address | addresses | addressing
E: address an issue / tackle a problem は、Writing でよく使うコロケーションです。

Q: 数の変化で「急に下がる」を表す、p で始まる動詞は何ですか。
A: plummet | plunge | plummeted | plunged
E: plummet / plunge。急に上がるのは soar / surge です。
```
