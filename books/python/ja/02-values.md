# 2. 値・変数・文字列

## 画面に出す・コメント

```python
print("乳量", 32.5, "kg")     # 乳量 32.5 kg（, で区切ると空白が入る）
print("A", "B", sep="-")      # A-B
# ここはコメント（Python に読まれない）
```

## 値の型

| 型 | 意味 | 例 |
| --- | --- | --- |
| `int` | 整数 | `3`、`-10`、`1_000_000`（`_` で区切れる） |
| `float` | 小数 | `3.14`、`1.5e3`（1500.0） |
| `str` | 文字列 | `"Hello"`、`'牛'` |
| `bool` | 真偽 | `True`、`False` |
| `None` | 何もない | `None` |

`type(値)` で型がわかります。

```python
print(type(3), type(3.0), type("3"))    # <class 'int'> <class 'float'> <class 'str'>
```

## 計算

| 演算子 | 意味 | 例 | 結果 |
| --- | --- | --- | --- |
| `+` `-` `*` | 足す・引く・かける | `7 * 2` | 14 |
| `/` | 割る（いつも小数） | `7 / 2` | 3.5 |
| `//` | 割って切り捨て | `7 // 2` | 3 |
| `%` | 余り | `7 % 2` | 1 |
| `**` | べき乗 | `2 ** 10` | 1024 |

> 小数は2進数で近い値を持つので、`0.1 + 0.2` は `0.30000000000000004` になります。比べるときは `round(x, 2)` や `math.isclose` を使います。

## 変数

```python
milk = 32.5          # 作る（代入）。型は書かない
milk = milk + 1.5    # 34.0
milk += 1.5          # 35.5（milk = milk + 1.5 と同じ）
a, b = 1, 2          # 2つまとめて
a, b = b, a          # 入れかえ（a は 2、b は 1）
```

- 名前に使えるのは、英字・数字・`_`（数字で始めない）。日本語も使えるが、英字がふつう
- 単語は `_` でつなぐ（`milk_per_day`）。変えない値は大文字（`MAX_COWS = 100`）
- 大文字と小文字は区別する

## 文字列

```python
s = "Holstein"
print(len(s))         # 8（長さ）
print(s[0], s[-1])    # H n（0 から数える。-1 は最後）
print(s[0:4])         # Hols（0 から 4 の手前まで。スライス）
print(s[4:])          # tein
print("牛" * 3)       # 牛牛牛
print("Hol" + "stein")
```

文字列は、あとから1文字だけ変えることはできません（`s[0] = "h"` はエラー）。変えたものは新しく作ります。

| メソッド | すること | 例 → 結果 |
| --- | --- | --- |
| `upper()` / `lower()` | 大文字・小文字 | `"abc".upper()` → `"ABC"` |
| `strip()` | 前後の空白・改行を消す | `" a \n".strip()` → `"a"` |
| `split(区切り)` | 分けてリストにする | `"a,b,c".split(",")` → `["a", "b", "c"]` |
| `区切り.join(リスト)` | つなぐ | `"-".join(["a", "b"])` → `"a-b"` |
| `replace(古, 新)` | 置きかえ | `"2026/11".replace("/", "-")` → `"2026-11"` |
| `startswith(文字)` | で始まるか | `"cow01".startswith("cow")` → `True` |
| `in` | ふくむか | `"st" in "Holstein"` → `True` |

### f 文字列

`f"..."` の中の `{ }` に、変数や式を入れられます。

```python
name, milk = "Hanako", 32.456
print(f"{name}の乳量は{milk}kg")         # Hanakoの乳量は32.456kg
print(f"{milk:.1f}")                     # 32.5（小数点以下 1 けた）
print(f"{1234567:,}")                    # 1,234,567
print(f"{0.123:.1%}")                    # 12.3%
print(f"{milk=}")                        # milk=32.456（確かめるときに便利）
```

## 入力と型の変換

`input()` で入力した値は、いつも**文字列**です。計算するときは変換します。

```python
age = input("年齢は？ ")       # "5" のような文字列
age = int(age)                  # 整数にする
print(age + 1)
```

| 関数 | 変換 | 例 |
| --- | --- | --- |
| `int()` | 整数に | `int("5")` → 5、`int(3.9)` → 3 |
| `float()` | 小数に | `float("3.5")` → 3.5 |
| `str()` | 文字列に | `str(10)` → `"10"` |

`int("abc")` のように変えられないと、`ValueError` になります（6章で受け止め方を説明します）。

## 比較と論理

```python
milk = 32
print(milk >= 30)                    # True
print(25 <= milk < 35)               # True（つなげて書ける）
print(milk > 30 and milk < 40)       # かつ
print(milk < 10 or milk > 50)        # または
print(not milk > 30)                 # でない
```

等しいは `==`、等しくないは `!=` です。

## まとめ

- 整数 `int`・小数 `float`・文字列 `str`・真偽 `bool`。`/` はいつも小数、`//` は切り捨て
- 変数は型を書かずに作る。名前は `snake_case`
- 文字列は `[0]`・`[1:3]` で取り出し、`split`・`join`・`strip` などで操作する
- 値の埋めこみは f 文字列（`f"{x:.1f}"`）。`input()` は文字列なので `int()` などで変える
