# 3. データの入れ物（リスト・タプル・辞書・集合）

## この章でわかること

- リスト・タプル・辞書・集合の使い方とちがい
- コピーと「同じものを指す」ことのちがい
- 内包表記

## 4つの入れ物

| 入れ物 | 書き方 | 順番 | あとから変える | 主な使い道 |
| --- | --- | --- | --- | --- |
| リスト `list` | `[1, 2, 3]` | ある | できる | 並んだデータ |
| タプル `tuple` | `(1, 2, 3)` | ある | できない | 変えない組（座標、関数から複数の値を返す） |
| 辞書 `dict` | `{"a": 1, "b": 2}` | 入れた順 | できる | 名前（キー）で値を引く |
| 集合 `set` | `{1, 2, 3}` | ない | できる | 重なりを消す、ふくむかを速く調べる |

## リスト

```python
milk = [32.5, 28.0, 35.2]
milk.append(25.8)        # 後ろに足す → [32.5, 28.0, 35.2, 25.8]
milk.insert(0, 30.0)     # 0 番目に入れる
x = milk.pop()           # 最後を取り出す（25.8）
milk.remove(28.0)        # その値を消す
print(len(milk), milk[0], milk[-1], milk[1:3])
print(35.2 in milk)      # True
print(sum(milk), max(milk), min(milk))
```

- 番号（インデックス）は 0 から。`[-1]` は最後
- `[開始:終わり]` のスライスは、終わりの**手前まで**。`[::2]` は1つおき、`[::-1]` は逆順
- 並べかえ: `milk.sort()` はそのリストを並べかえる。`sorted(milk)` は新しいリストを返す。大きい順は `reverse=True`
- リストの中にリストも入れられる（`table = [[1, 2], [3, 4]]`、`table[1][0]` は 3）

### 同じものを指す、に注意

```python
a = [1, 2, 3]
b = a            # b は a と「同じリスト」を指す（コピーではない）
b.append(4)
print(a)         # [1, 2, 3, 4]（a も変わる）

c = a.copy()     # 別のリストを作る（a[:] や list(a) でも同じ）
c.append(5)
print(a)         # [1, 2, 3, 4]（a は変わらない）
```

## タプル

```python
point = (35.6, 139.7)     # 緯度・経度
lat, lon = point          # 分けて受け取る（アンパック）
print(lat)
```

一度作ったら変えられません。変えないものはタプルにしておくと、まちがって変えることがありません。

## 辞書

キー（名前）と値の組です。

```python
cow = {"name": "Hanako", "parity": 2, "milk": 32.5}
print(cow["name"])               # Hanako
cow["milk"] = 33.0               # 変える
cow["barn"] = "A"                # 足す
del cow["parity"]                # 消す
print(cow.get("weight"))         # None（キーがなくてもエラーにならない）
print(cow.get("weight", 0))      # 0（なかったときの値を決められる）
print("name" in cow)             # True（キーがあるか）

for key, value in cow.items():   # キーと値を順に
    print(key, value)
```

- `cow["weight"]` のように、ないキーを `[ ]` で引くと `KeyError`
- `cow.keys()`・`cow.values()`・`cow.items()` で、キー・値・組の一覧
- 牛の一覧のように、辞書のリスト（`[{"name": ...}, {"name": ...}]`）もよく使う。表のデータが大きくなったら pandas（9章）

## 集合

```python
a = {"A", "B", "C"}
b = {"B", "C", "D"}
print(a | b)       # 和: {'A', 'B', 'C', 'D'}
print(a & b)       # 共通: {'B', 'C'}
print(a - b)       # 差: {'A'}
print(set([1, 1, 2, 3, 3]))   # {1, 2, 3}（重なりを消す）
```

空の集合は `set()` です（`{}` は空の辞書）。

## 内包表記

リストを作る `for` を1行で書けます。

```python
milk = [32.5, 28.0, 35.2, 25.8]
high = [m for m in milk if m >= 30]        # [32.5, 35.2]
lb = [round(m * 2.2046, 1) for m in milk]  # ポンドに直す
squares = {n: n ** 2 for n in range(4)}    # 辞書も: {0: 0, 1: 1, 2: 4, 3: 9}
```

`[式 for 変数 in 入れ物 if 条件]` の形です。長く複雑になったら、ふつうの `for`（4章）で書きます。

## まとめ

- 変えるならリスト、変えないならタプル、名前で引くなら辞書、重なりを消すなら集合
- `b = a` はコピーではなく同じものを指す。別にしたいなら `a.copy()`
- 辞書のないキーは `get` で安全に引く
- `[m for m in milk if m >= 30]` のような内包表記で、短く書ける

## 練習問題

```quiz
Q: 次のコードは何を表示しますか。
| a = [1, 2, 3]
| b = a
| b.append(4)
| print(len(a))
A: 4
E: `b = a` はコピーではなく、同じリストを指します。別にしたいなら `a.copy()` です。

Q: 次のコードは何を表示しますか。
| milk = [28, 31, 25, 33]
| print([m for m in milk if m >= 30])
A: [31, 33] | 31, 33
E: 内包表記で、30 以上だけを取り出しています。

Q: 次のコードは何を表示しますか。
| print(len({3, 1, 3, 2, 1}))
A: 3
E: 集合は重なりを消すので、{1, 2, 3} の3つです。

Q: 辞書にないキーを、エラーにせずに安全に引くメソッドは何ですか。
A: get | .get | get()
E: `d.get("key", 0)` のように、ないときの値も決められます。
```
