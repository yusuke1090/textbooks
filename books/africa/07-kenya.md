# 7. ケニア

## 国のあらまし

| 項目 | 内容 |
| --- | --- |
| 首都 | ナイロビ（約440万人、2019年）。港の町はモンバサ |
| 人口 | 約4,760万人（2019年の国勢調査）。いまは5,000万人をこえる |
| 言葉 | 英語とスワヒリ語（どちらも公用語）。ナイロビの若者は、2つを混ぜたスラング「シェン」を話す |
| お金 | ケニア・シリング（KES） |
| 大統領 | ウィリアム・ルト（2022年〜）。次の選挙は2027年8月 |
| 通信会社 | Safaricom（M-Pesa。いちばん大きい）、Airtel |
| 入っている集まり | EAC、COMESA |

- 東アフリカの経済・交通・金融の中心です。国連の機関や外国の会社の、アフリカ東部の本部がナイロビに多くあります
- 「**シリコン・サバンナ**」とよばれるほどスタートアップが多く、2025年にスタートアップが集めたお金はアフリカで1位（約10億ドル）でした
- 大人の **82%** がモバイルマネーを使い（2024年）、銀行などの金融サービスを使う人は **84.8%** です
- 電気の約9割は、地熱・水力・風力などの再生可能エネルギーです
- 国は47の郡（カウンティ）に分かれていて、**農業は郡の仕事**です。補助や決まりが郡によってちがいます
- 2024年6月、増税の法案に反対する若者のデモが国会に入りこみ、法案は取り下げられました。そのあとも、デモと取りしまりが続いています

## 農業

| 項目 | 内容 |
| --- | --- |
| GDP に占める割合 | 約22%（2024年） |
| いちばん稼ぐ輸出 | 園芸（花・野菜・果物）約2,036億シリング（2024年） |
| 2番目の輸出 | 紅茶 約1,891億シリング（2024年）。世界有数の紅茶の輸出国 |
| ほかの作物 | コーヒー、アボカド、マカダミア、トウモロコシ（主食。足りない分は輸入） |

- 花（バラなど）は、ナイバシャ湖のまわりの大きな温室で作り、毎晩飛行機でヨーロッパへ送ります
- 紅茶は、ケリチョやニエリの高地で、小さな農家が摘んだ葉を、農家が株を持つ工場（KTDA が管理）が加工します
- 政府は2022年から、登録した農家に肥料を安く売る補助をしています（登録と引きかえはスマホで）
- 北部の乾いた地域は、牛・ヤギ・ラクダを連れた牧畜の地域です。2020〜23年の大干ばつで、家畜が大量に死にました

## 酪農

ケニアの酪農は、東アフリカでいちばん商業化が進んでいます。牛乳は毎日の飲み物で、1人あたりの量も東アフリカで多いほうです。

### 数字

| 項目 | 数字 |
| --- | --- |
| 乳の量 | 約52億 L／年（ケニア酪農委員会 KDB の推計。工場を通らない分も含む） |
| 工場が農家から買った乳 | 約9.1億 L（2024年。過去最高、前の年より12%増） |
| 工場を通らない乳 | 8割ほど（インフォーマルの市場） |
| 小規模の酪農家 | 180万戸以上 |
| 1頭が1日に出す乳 | 平均約10 L（2024年。2021年は6〜7 L） |
| 牛の数（2019年の国勢調査） | 乳牛 約220万頭、在来の牛 約1,300万頭 |
| 農家が売る値段 | 1 L 45〜55シリングほど（2025年）。作るのにかかる費用は1 L 30〜37シリング（KDB） |

### 牛と農家

- 中央の高地（キアンブ・ニャンダルア・ニエリ・ムランガ）、リフトバレー（ナクル・ウアシンギシュ・ナンディ・ボメット）、メルが産地です
- 多くは1〜3頭を飼う家族の農家です。ホルスタイン（フリージアン）・エアシャー・ジャージーと、その交雑種
- 土地が狭いので、牛を小屋で飼い、刈った草（ネピアグラスなど）を運んで食べさせる「**ゼロ・グレージング**」（放牧しない飼い方）が多い
- 人工授精が広まっていて、政府や郡が料金を補助しています
- 町には、量り売りの牛乳の自動販売機（**ミルク ATM**）があり、容器を持って買いに来ます

### 乳業と協同組合

- 農家の乳は、**協同組合**の集乳所に集められ、冷やされて工場に運ばれます
- 大きな乳業: Brookside（民間でいちばん大きい）、New KCC（国の会社）、Githunguri（協同組合。「Fresha」のブランド）、Bio Food、Daima など
- メル・ムランガなどの協同組合は、自分たちで工場やエサの工場を持っています

### 困っていること

- **値段の上下**: 雨季は乳が余って値段が下がり、乾季は足りなくなって値段が上がる
- **エサ**: 配合飼料が高い。乾季の草が足りない。サイレージ作りを請け負う業者も出てきています
- **品質**: 工場を通らない乳は、検査されずに売られる。水を混ぜる、抗生物質が残る、などの問題
- **病気**: 東海岸熱（ECF）、乳房炎
- **周りの国との取引**: ウガンダの安い乳製品との競争、タンザニアのケニア産の乳への課税（2025年）

## IoT・アグリテックの会社

### 酪農

| 会社 | 何をしている |
| --- | --- |
| **Savanna Circuit Technologies** | バイクにのせる太陽光の牛乳冷却器（140 L を15時間冷やす）。売らずに貸して、運んだ1 L ごとに料金をもらう（「サービスとしての冷却」）。26の郡で1,000台以上（会社の発表） |
| **FRESH Networks** | IoT で温度を管理する冷蔵の配送と、低所得の地域向けのミルク ATM |
| **DigiCow** | 酪農家向けの記録アプリ・研修・ローン。ネットがない所でも記録でき、ショートメッセージでも使える |
| **Dairy Sense** | 農家の庭先や集乳所で使える、持ち運べる乳の検査機。品質で値段を決める仕組みを作る |
| **SpaceAI** | 小さな酪農家の乳のデータを、集乳から工場まで AI で管理する |

| 会社 | 何をしている |
| --- | --- |
| **SunCulture** | 太陽光のかんがいポンプを、分割払いで売る。ポンプの状態を遠くから見る |
| **UjuziKilimo** | 土のセンサーで、土の状態を調べて肥料や作業をすすめる |
| **Synnefa** | 温室・畑のセンサーと、農家向けのクラウド |

- ケニアには、援助の団体や会社が無料で配るアプリが多くあります。農家は「無料がふつう」と思っていることが多く、農家から直接お金をとるのは難しい
- 物流の Twiga Foods の失敗（5章）のように、お金を集めても続かない会社もあります

### 日本とのつながり

- JICA の **SHEP**（小さな園芸農家が「売るために作る」ように変える取り組み）はケニアで生まれ、アフリカ中に広がりました
- 2025年の TICAD 9 では、トヨタ・モビリティ基金・New KCC・JICA が、乗り物で小さな酪農家と若者を助ける話し合いを開きました
- JICA の **Project NINJA** は、ケニアのスタートアップを日本の投資家とつないでいます
- 日本人がケニアで始めた会社もあります（たとえば、配車アプリの運転手に車を貸す **HAKKI AFRICA**）

## 参入するなら

### ねらい目

- **協同組合と乳業向けの集乳データ**: 農家ごとの量・品質・温度を記録し、M-Pesa で払う。協同組合と乳業は、お金を払ってくれる相手です
- **品質で値段を決める**: 水を混ぜた乳や、乳房炎の乳を見分けるセンサー。乳業はきれいな乳に高く払いたい
- **中くらいの牧場**（10〜100頭）: 発情を見つける首輪、乳量・反芻のセンサー、エサの管理。数は少ないが、払える力がある。日本の牛の技術がそのまま使える（[牛の教科書](https://yusuke1090.github.io/textbooks/?b=cow) の12章）
- **冷却をサービスとして**: 冷却器を売らずに貸し、運んだ量で料金をもらう（Savanna Circuit の形）
- **エサとサイレージ**: サイレージの発酵の温度・水分の見張り。サイレージ作りを請け負う業者向け

### 強み

- 酪農の仕組み（協同組合・工場・人工授精・モバイルマネー）が、すでにできている
- 英語で仕事ができる。技術者・データの人材がいる
- 投資家が多い。日本の会社・ファンドも来ている
- ナイロビを拠点に、ウガンダ・タンザニア・ルワンダへ広げやすい

### 注意すること

- **競争が多い**: 同じようなアプリやセンサーの会社がすでに多い。無料の援助のアプリとも競う
- **安くないと売れない**: 小さな農家は、1か月に払える額がとても少ない
- **税金がよく変わる**: 毎年の予算の法律で、税金が変わる
- **個人データの法律**（2019年）: データを扱う会社は、データ保護委員会（ODPC）に登録する
- **電波の機械の認証**: 通信庁（CA）の型式の認証がいる
- **郡ごとにちがう**: 補助・手数料・担当者が郡によってちがう

### 入り方の例

- ナイロビに小さな拠点を置き、1つの協同組合（キアンブ・ニャンダルア・メルなど）と3〜6か月試す
- Safaricom の M-Pesa の API（Daraja）で支払いをつなぐ
- JICA（Project NINJA、SHEP）や TICAD のつながりで、乳業や協同組合を紹介してもらう
- 現地のスタートアップ（Savanna Circuit、DigiCow など）と組み、センサー・機械の部分を受け持つ
