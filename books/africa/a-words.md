# 付録A. スワヒリ語・チェワ語と用語

## スワヒリ語（タンザニア・ケニア）

### あいさつ

| スワヒリ語 | 読み | 意味 |
| --- | --- | --- |
| Habari? | ハバリ | 元気？（こんにちは）。返事は **Nzuri**（ンズーリ、元気です） |
| Jambo | ジャンボ | こんにちは（観光客向けの、くだけた言い方） |
| Mambo? | マンボ | よう、どう？（若者どうし）。返事は **Poa**（ポア、いいよ） |
| Shikamoo | シカモー | 目上の人へのあいさつ。返事は **Marahaba**（マラハバ） |
| Asante (sana) | アサンテ（サーナ） | ありがとう（とても） |
| Karibu | カリブ | ようこそ／どういたしまして |
| Pole | ポレ | お気の毒に、大変でしたね |
| Pole pole | ポレポレ | ゆっくり、ゆっくり |
| Hakuna matata | ハクナ・マタタ | 問題ない |
| Sawa | サワ | OK、わかった |
| Ndiyo / Hapana | ンディヨ／ハパナ | はい／いいえ |
| Bei gani? | ベイ・ガニ | いくら？ |
| Kwaheri | クワヘリ | さようなら |

## 用語

| 用語 | 意味 |
| --- | --- |
| AU | アフリカ連合 |
| AfCFTA | アフリカ大陸自由貿易圏 |
| EAC | 東アフリカ共同体（ケニア・タンザニアなど） |
| SADC | 南部アフリカ開発共同体（タンザニア・マラウイなど） |
| COMESA | 東南部アフリカ市場共同体（ケニア・マラウイなど） |
| TICAD | アフリカ開発会議（日本が開く） |
| JICA | 国際協力機構 |
| M-Pesa | 携帯電話でお金を送る・払う仕組み（ケニア・タンザニアなど） |
| USSD | `*150*00#` のように番号を打って使うメニュー。ガラケーでも使える |
| PAYGo | 分割払い。毎日・毎週少しずつ払い、払わないと機械が止まる |
| インフォーマル | 登録や検査をしない商売。工場を通らない乳など |
| ボダボダ | バイクタクシー |
| ゼロ・グレージング | 牛を放牧せず小屋で飼い、刈った草を運ぶ飼い方 |
| ゼブ牛 | 背中にこぶのある在来の牛。暑さと病気に強い |
| 東海岸熱（ECF） | ダニがうつす牛の病気。東アフリカで多い |
| 集乳所 | 農家が乳を持ち寄って、冷やして工場に送る場所 |
| MBG | 集乳グループ（Milk Bulking Group、マラウイ） |
| KDB／TDB | ケニア酪農委員会／タンザニア酪農委員会 |
| サービスとしての冷却 | 冷却器を売らずに貸し、使った分や運んだ量で料金をもらう形 |
| IPC | 食料の危機の度合いを5段階で表す国際的な決まり。3以上が「危機」 |
| 天水農業 | かんがいをせず、雨だけで作る農業 |
