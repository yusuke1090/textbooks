# 6. タンザニア

## この章でわかること

## 国のあらまし

| 項目 | 内容 |
| --- | --- |
| 正式な名前 | タンザニア連合共和国（本土のタンガニーカ ＋ ザンジバル） |
| 首都 | ドドマ（政府が移ってきている）。経済の中心はダルエスサラーム |
| 人口 | 約6,170万人（2022年の国勢調査）。いまは6,500万人ほど |
| 言葉 | **スワヒリ語**（国じゅうで通じる）、英語（法律・大きな会社・大学） |
| お金 | タンザニア・シリング（TZS） |
| 大統領 | サミア・スルフ・ハッサン（2021年〜。初めての女性の大統領） |
| 通信会社 | Vodacom（M-Pesa）、Yas（モバイルマネーは Mixx by Yas）、Airtel、Halotel |
| 入っている集まり | EAC（東アフリカ）と SADC（南部アフリカ）の両方 |

- 独立のときから同じ政党（CCM、革命党）が政権を続けています
- 2025年10月の選挙では、サミア大統領が97.66%で勝ったと発表されました。おもな野党の候補は出られず、ネットが止められ、デモの取りしまりで多くの死者が出たと報告されています。欧米の国々は懸念を表明しました
- 経済は年5〜6%で伸びています。金、観光（サファリ・ザンジバル・キリマンジャロ）、農業が柱です
- 大きなダム（ジュリアス・ニエレレ水力発電所）ができて、電気は増えてきました。それでも、地方では毎日何時間も停電する所があります

## 農業

| 項目 | 内容 |
| --- | --- |
| 国の経済（GDP）に占める割合 | 約26%（2024年、政府の数字。世界銀行の数字では約23%） |
| 働く人に占める割合 | 5〜6割 |
| 主食の作物 | トウモロコシ、キャッサバ、米、豆 |
| 輸出する作物 | カシューナッツ、ゴマ、コーヒー、茶、たばこ、綿、サイザル麻、クローブ（ザンジバル）、アボカド |

- ほとんどが、1〜2 ha ほどの小さな畑の家族農家です。雨だけで育てる畑が多く、かんがい（水を引く）はまだ少ない
- トウモロコシや米は、近くの国に売るほど作れる年もあります。ただし、国内の値段が上がると、政府が急に輸出を止めることがあります
- 政府は、農業を年10%伸ばす目標（Agenda 10/30）を立て、農業省の予算を大きく増やしました
- **BBT**（Building a Better Tomorrow、2022〜2030年）: 若者に土地とかんがいをそろえた農場を用意して、農業ビジネスを始めてもらう政府の計画
- 南部の高地（イリンガ・ムベヤ・ンジョンベ）は雨が多く涼しく、アボカド・じゃがいも・茶・乳牛の産地です

## 酪農

### 数字

| 項目 | 数字 |
| --- | --- |
| 牛の数 | 約3,920万頭（2024/25年度）。アフリカでエチオピアに次いで2番目 |
| そのうち乳用の改良された牛 | 約141万頭 |
| 乳の量 | 約40億 L（2024/25年度）、約42億 L（2025/26年度） |
| 工場で加工された乳 | 約1億 L（2025/26年度）。全体の **2〜3%** だけ |
| 加工工場 | 187か所。合わせて1日100万 L 以上を加工できるが、実際は1日約29万 L |

### 牛と農家

- 牛のほとんどは、在来の**ゼブ牛**（背中にこぶのある牛）です。暑さと病気に強いかわりに、乳は1日1〜2 L ほど
- 乳用の改良された牛（ホルスタインなどとの交雑種）は、1日5〜10 L ほど出します。キリマンジャロやアルーシャの北部、タンガ、南部の高地に多い
- マサイやスクマなどの牧畜の人たちは、牛の群れを連れて、草と水を求めて移動します。乳は家族で飲み、余りを売ります
- 乳の多くは、農家が自転車やバイクで町に運び、家や食堂に直接売ります。買った人はわかして飲みます

### 乳業

| 会社 | 場所 | 特徴 |
| --- | --- | --- |
| Tanga Fresh | タンガ（北東の海岸） | 国でいちばん大きな乳業。約6,000の小さな農家から集める。1日12万 L 加工できるが、乳が集まらず約15%しか動いていない |
| ASAS | イリンガ（南部の高地） | 1日10万 L 加工できる |
| Kilimanjaro Fresh、Milkcom など | 北部・ダルエスサラーム | |

### 困っていること

- **冷やせない**: 集乳所に冷却タンクがあっても、停電や故障で動いていないことが多い。乳は暑さの中、数時間で悪くなります
- **集まらない**: 工場は余っているのに、冷やして運ぶ道がないので、乳が工場まで届かない
- **乾季のエサ**: 雨季は草があっても、乾季は草が枯れて乳が減ります。サイレージや乾草を作る農家はまだ少ない
- **病気**: ダニがうつす東海岸熱（ECF）、ツェツェバエがうつす病気、乳房炎
- **品質**: 水を混ぜる、抗生物質が残る、などの問題があり、品質で値段を決める仕組みがまだ弱い

### 政府の動き

- 乳製品の輸入にかける費用を上げ、国産を増やそうとしています。輸入は年に約1,000万 L まで減りました（2024/25年度）
- 2025〜2035年の10年で約2億ドルの酪農の計画（品種改良・エサ・冷却・加工）
- 学校で牛乳を飲む取り組み（タンザニア酪農委員会、TDB）

## IoT・アグリテックの会社

| 会社・取り組み | 何をしている |
| --- | --- |
| **MazaoHub** | 太陽光で動く土のセンサー（養分・水分・pH）と AI で、肥料や作業をすすめる。3.5万をこえる農家が使う。2025年に200万ドルを集めた |
| **Kilimo Fresh** | 小さな農家の野菜・果物を集めて、ダルエスサラームの店やレストランに卸す |
| **WASSHA**（日本の会社） | 村の小さな店を通して、IoT のソーラーランタンを貸し出す。料金はモバイルマネー。JICA も出資。ダルエスサラームに拠点 |
| Tetra Pak と乳業の Jambo | シニャンガ州で、太陽光の冷却装置をのせた移動式の集乳所を5台動かす |
| Solidaridad と Tanga Fresh | 農家の近くに、乳を集めて冷やす拠点を作る試み |
| Vodacom（M-Pesa）ほか | 農家への支払い、ローン、保険の土台になる |

- 2024年の調べでは、タンザニアのスタートアップ約1,000社のうち、約17%がアグリテックです
- 若い起業家の大会（Heifer International の AYuTe Africa など）で、牛のエサや飼料の会社が賞をとっています
- ただし、ケニアにくらべると、アグリテックに入ってくるお金はまだ少なく、多くの会社が資金不足です

## 参入するなら

### ねらい目

- **集乳所の冷却を見える化する**: 冷却タンクの温度・停電・発電機や太陽光の状態を、遠くから見て、止まったらすぐ知らせる。「工場は空いているのに乳が届かない」という一番の問題に効きます
- **集乳の記録と支払い**: 農家ごとの乳の量・品質を記録して、M-Pesa などで払う。品質で値段を変えられれば、水を混ぜる問題も減ります
- **乾季のエサ**: サイレージや乾草の作り方と、保存の管理（温度・水分のセンサー）
- **かんがい農場の水の管理**: BBT の農場や、南部の高地のアボカド・野菜の畑で、土の水分のセンサーとポンプの制御

### 強み

- 牛の数はアフリカで2番目。乳の量も毎年増えていて、政府も酪農を後押ししている
- 工場の設備は余っているので、集乳と冷却が良くなれば、すぐに売上につながる
- スワヒリ語1つで国じゅうに届く

### 注意すること

- **政治とネット**: 2025年の選挙のあとのように、ネットが止まることがある。機械はデータをためておき、つながったら送る作りにする
- **決まりが急に変わる**: 輸出の禁止、税金、許可の取り消しなどが、予告なしにあることも
- **個人データの法律**（2022年）: 外国の会社も、データを扱うなら個人データ保護委員会（PDPC）に登録が必要
- **電波の機械の認証**: 無線を使う機械は、通信の役所（TCRA）の型式の認証がいる
- **Starlink はまだ使えない**（2026年時点）
- 農家に見せる画面・音声は**スワヒリ語**で

### 入り方の例

- 乳業（Tanga Fresh、ASAS など）か、集乳所を持つ協同組合と組んで、1か所で試す
- 援助の団体（Solidaridad、Heifer International など）の酪農の事業に、技術の担当として加わる
- 現地のスタートアップ（MazaoHub など）と組む
- 日本の先例は WASSHA。村の店を通して機械を貸し、モバイルマネーで払ってもらう形は、冷却器やセンサーにも使えます
