# 9. 3か国を比べて、参入を考える

## 3か国の比べ

| 項目 | タンザニア | ケニア | マラウイ |
| --- | --- | --- | --- |
| 人口（国勢調査） | 約6,170万（2022年） | 約4,760万（2019年） | 約1,760万（2018年） |
| 仕事の言葉 | スワヒリ語・英語 | 英語・スワヒリ語 | 英語・チェワ語 |
| 牛 | 約3,920万頭（乳用 約141万） | 乳牛 約220万・在来 約1,300万（2019年） | 乳牛 約5万5千 |
| 乳の量（年） | 約40億 L | 約52億 L | 推計しかない（数千万 L） |
| 工場を通る乳 | 2〜3% | 2割ほど | 売る乳の半分ほどが集乳所を通る |
| モバイルマネー | M-Pesa・Mixx by Yas・Airtel | M-Pesa（大人の82%） | Airtel Money・Mpamba |
| Starlink | まだ使えない | 使える | 使える |
| 個人データの法律 | 2022年（外国の会社も登録） | 2019年（ODPC に登録） | 2024年（MACRA） |
| 政治 | 2025年の選挙で混乱。ネットを止めた | デモが多い。2027年に選挙 | 2025年に平和に政権交代 |
| ひとことで | 牛は多いが、工場まで乳が届かない | いちばん進んでいて、競争も多い | 小さく難しい。援助の事業で入る |

### どこから始めるか

- **最初の1か国はケニア**が無難です。酪農の仕組み・お金の払い方・人材・投資家がそろっていて、英語で試せます
- **大きく伸ばすならタンザニア**です。牛と乳の量が多く、冷却と集乳はまだこれから。ケニアで作った仕組みを、スワヒリ語のまま持って行けます
- **マラウイ**は、援助の事業と組んで、安くて丈夫な機械を試す場として考えます

## 機械と仕組みの条件

日本の牧場向けの機械を、そのまま持って行っても動きません。次の条件に合わせます。

| 条件 | 現地の様子 | どう作るか |
| --- | --- | --- |
| 電気 | 停電が毎日ある。電気が来ていない所も多い | 太陽光パネルと電池で動く。停電を記録して知らせる |
| 通信 | 地方は 2G だけ、または電波がない。ネットが止められることも | 2G でも送れる小さなデータにする。つながらない間はためておき、つながったら送る |
| 暑さ・ほこり・雨 | 日中は40℃近く。赤い土のほこり。雨季は大雨 | 防水・防じんの箱。日かげに付ける |
| 盗難と故障 | 太陽光パネルや電池は盗まれやすい。部品が手に入りにくい | 外から見えにくく付ける。現地で手に入る部品を使い、現地の人が直せるようにする |
| 値段 | 小さな農家が払えるのは1か月に数百円ほど | 農家ではなく、協同組合・乳業に買ってもらう。または貸す |
| 画面 | スマホを持たない人も多い。字を読むのが苦手な人も | ショートメッセージ・USSD・WhatsApp・音声。スワヒリ語・チェワ語 |
| 支払い | 銀行よりモバイルマネー | M-Pesa などの API で、料金の受け取りと、農家への支払いをする |

- LoRa などの無線を使うときは、その国で使ってよい周波数と、型式の認証（ケニアは CA、タンザニアは TCRA、マラウイは MACRA）を確かめます
- 携帯電話の回線を使うときは、その国の SIM（Safaricom・Vodacom・Airtel など）か、複数の国で使える IoT 用の SIM を使います

## お金をもらう形

| 形 | 例 | 向いている相手 |
| --- | --- | --- |
| 機械を売る | センサー・冷却器を売る | 中くらい以上の牧場、乳業 |
| 月の利用料（サブスク） | 集乳データの画面、牛の見張り | 協同組合、乳業 |
| 使った量で払う | 冷やして運んだ1 L ごとに料金（Savanna Circuit） | 協同組合、農家のグループ |
| 分割払い（PAYGo） | 毎日・毎週モバイルマネーで払い、払わないと止める | 農家（太陽光ポンプ、冷蔵庫） |
| 援助の事業から払ってもらう | 世界銀行・JICA・NGO の事業の機械とデータを受け持つ | マラウイなど、市場が小さい所 |

- 小さな農家から直接お金をとるのは、とても難しい。**乳が増えた・品質が上がったことで得をする人**（協同組合・乳業・エサや薬の会社・銀行・保険）に払ってもらう形を考えます
- 「乳が何 L 増えた」「捨てる乳が何 L 減った」と、数字で示せるようにしておくと、売りやすい

## 参入までの順番

1. **問題を1つに決める**: 「集乳所で乳が傷む」「発情を見逃す」など。現地の人が困っていて、解決すると誰かがお金を得するもの
2. **現地で見る**: 協同組合・集乳所・牧場を回る。乳業の人、獣医、人工授精の技術者、農家に話を聞く。JICA・JETRO の現地の事務所にも相談できる
3. **組む相手を決める**: 協同組合か乳業（お金を払う人）、現地のスタートアップや技術者（直す人）
4. **小さく試す**: 1か所で3〜6か月。機械が現地の暑さ・停電・電波で動くか、人が使い続けるかを見る
5. **数字で示す**: 試す前と後で、乳の量・捨てた量・収入をくらべる
6. **会社と手続き**: 現地の会社を作るか、代理店と組むか。電波の認証、個人データの登録、輸入の関税（ケニアとタンザニアは EAC の共通関税）、働く許可
7. **広げる**: 同じ協同組合のほかの集乳所 → 同じ乳業のほかの地域 → 隣の国

## 日本の支援の使い方

| 制度 | 何をしてくれる |
| --- | --- |
| JICA の民間連携事業（中小企業・SDGs ビジネス支援） | 途上国で製品を試す調査や実証のお金と、現地の役所との調整 |
| JICA Project NINJA | アフリカのスタートアップと日本の会社・投資家をつなぐ |
| JETRO（ナイロビ・ヨハネスブルグなどの事務所） | 市場の情報、現地の会社の紹介、展示会 |
| TICAD | 3年ごとの首脳会議と、そのまわりの商談・展示 |

- 応募の時期や条件は毎年変わるので、それぞれのサイトで確かめます
