# 1. アフリカのあらまし

この教科書の前半（1〜5章）はアフリカ全体の話、後半（6〜9章）はタンザニア・ケニア・マラウイの農業と酪農、IoT の会社、参入するならどうするか、の話です。

## 数字で見るアフリカ

| 項目 | 数字 | くらべると |
| --- | --- | --- |
| 面積 | 約3,000万 km² | 日本の約80倍。世界の陸地の約2割 |
| 国の数 | 54（国連に入っている国） | アフリカ連合（AU）には西サハラを入れて55 |
| 人口 | 約15.5億人（2025年） | 世界の約5人に1人 |
| 2050年の人口 | 約25億人（国連の推計） | 世界の約4人に1人 |
| 人口のまん中の年齢 | 約19歳 | 日本は約49歳 |

- 地図ではアフリカが小さく見えることが多いですが（メルカトル図法のため）、アメリカ・中国・インド・ヨーロッパの大部分を合わせたほどの広さがあります
- 人口がいちばん多いのはナイジェリア（2億人をこえる）、次がエチオピア・エジプト・コンゴ民主共和国です

## 地域の分け方

| 地域 | おもな国 | 特徴 |
| --- | --- | --- |
| 北アフリカ | エジプト、モロッコ、アルジェリア | アラビア語とイスラム教。地中海・中東とのつながりが強い |
| 西アフリカ | ナイジェリア、ガーナ、セネガル、コートジボワール | 人口が多い。カカオ・石油。フランス語の国が多い |
| 中部アフリカ | コンゴ民主共和国、カメルーン | 熱帯雨林。鉱物資源（コバルト・銅） |
| 東アフリカ | **ケニア、タンザニア**、エチオピア、ウガンダ、ルワンダ | 高原と大地溝帯。スワヒリ語。茶・コーヒー・酪農 |
| 南部アフリカ | 南アフリカ、**マラウイ**、ザンビア、ジンバブエ、モザンビーク | 鉱山と大きな農場。南アフリカが経済の中心 |

- サハラ砂漠より南をまとめて「サブサハラ・アフリカ」とよびます。統計ではよく北アフリカと分けます
- マラウイは南部アフリカに入れることも、東アフリカに入れることもあります

## 大きな地形

- **サハラ砂漠**: 北アフリカの大部分。世界でいちばん大きな暑い砂漠
- **サヘル**: サハラの南のふち。雨が少なく、干ばつと紛争が多い
- **ナイル川**: 世界でいちばん長い川のひとつ（約6,650 km）。ビクトリア湖とエチオピア高原から地中海へ
- **コンゴ川と熱帯雨林**: アマゾンに次ぐ大きな熱帯雨林
- **大地溝帯**（グレート・リフト・バレー）: 大地が東西に引っぱられてできた、長い谷。エチオピアからケニア・タンザニアを通り、マラウイ湖まで続く。人類の祖先の化石が多く見つかる
- **キリマンジャロ**（タンザニア）: アフリカでいちばん高い山（5,895 m）
- **ビクトリア湖**（タンザニア・ケニア・ウガンダ）: アフリカでいちばん大きな湖
- **マラウイ湖**（マラウイ・モザンビーク・タンザニア）: 魚の種類が世界でいちばん多い湖のひとつ。マラウイの面積の約5分の1

## 気候

- 赤道に近い国でも、高原は涼しい。ケニアのナイロビ（標高 約1,700 m）は、1年中 日本の春〜初夏くらい
- 季節は「暑い・寒い」より「**雨季**と**乾季**」で分けます
  - ケニア・タンザニア北部: 雨季が2回（大雨季 3〜5月、小雨季 10〜12月）
  - マラウイ・タンザニア南部: 雨季が1回（11〜4月）
- ほとんどの畑は雨だけで育てる（天水農業）ので、雨が少ない年は、すぐに不作と食料不足になります

## 言葉

- アフリカには **2,000ほど** の言葉があるといわれます。1つの国に何十もの言葉があるのはふつうです
- 植民地の時代の言葉（英語・フランス語・ポルトガル語）が、いまも公用語として使われています
- 広い地域で使われる言葉

| 言葉 | 使われる所 |
| --- | --- |
| アラビア語 | 北アフリカ |
| **スワヒリ語** | 東アフリカ（タンザニア・ケニアでは公用語）。話す人は1億人をこえる |
| ハウサ語 | 西アフリカ（ナイジェリア北部など） |
| アムハラ語 | エチオピア |
| ヨルバ語・イボ語 | ナイジェリア |
| ズールー語など | 南アフリカ |
| **チェワ語**（チチェワ） | マラウイ、ザンビア東部、モザンビーク |

## 宗教

- サハラより北はイスラム教、南はキリスト教が多い
- 東アフリカの海岸（タンザニアのザンジバル、ケニアのモンバサ）は、昔からのイスラム教の地域です
- キリスト教とイスラム教を信じながら、祖先を大切にする昔からの考え方も残っています
- 日曜の教会、金曜のモスクは、地域の人が集まる場所です。仕事の予定もこれに合わせます

## 国どうしの集まり

| 名前 | 日本語 | 入っている国（この本の3か国） |
| --- | --- | --- |
| AU | アフリカ連合（本部はエチオピアのアディスアベバ） | 全部 |
| AfCFTA | アフリカ大陸自由貿易圏。2021年から取引が始まった | 全部 |
| EAC | 東アフリカ共同体。関税をそろえている（共通対外関税） | ケニア、タンザニア |
| SADC | 南部アフリカ開発共同体 | タンザニア、マラウイ |
| COMESA | 東南部アフリカ市場共同体 | ケニア、マラウイ |

- タンザニアは EAC と SADC の両方に入っていて、東アフリカと南部アフリカをつなぐ位置にあります
- 同じ集まりの中では関税が安くなるので、どの国に拠点を置くかを決めるときに関係します
