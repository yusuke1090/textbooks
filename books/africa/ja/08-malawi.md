## 国のあらまし

![マラウイの場所](images/malawi-map.jpg)

| 項目 | 内容 |
| --- | --- |
| 首都 | リロングウェ。商業の中心はブランタイヤ、北部の中心はムズズ |
| 人口 | 約1,760万人（2018年の国勢調査）。いまは2,000万人をこえる |
| 面積 | 約11.8万 km²（日本の約3分の1）。約5分の1がマラウイ湖。海のない国 |
| 言葉 | 英語（公用語）、**チェワ語**（チチェワ。いちばん広く話される）。北部ではトゥンブカ語 |
| お金 | マラウイ・クワチャ（MWK） |
| 大統領 | ピーター・ムタリカ（2025年9月の選挙で56.8%を得て、2度目の大統領に） |
| 通信会社 | Airtel（Airtel Money）、TNM（モバイルマネーは Mpamba） |
| 入っている集まり | SADC、COMESA |

- 「**アフリカの温かい心**」とよばれ、人がおだやかで、治安も周りの国よりよいといわれます
- 世界で最も貧しい国の1つです。2025年の経済の伸びは約1.9%（世界銀行）でした
- **外貨が足りない**: 外国のお金（ドル）が不足していて、輸入の支払いが難しい。中央銀行の外貨は、輸入の0.4か月分しかありませんでした（2026年3月）。2023年11月にクワチャを44%切り下げ、そのあとは公式には1ドル＝約1,750クワチャですが、町の両替ではもっと高い値段で取引されています
- 物価の上がり方が大きく、燃料が足りなくなることもあります。停電も多い
- 2025年5月に国際通貨基金（IMF）の支援が終わり、2026年10月の時点で新しい支援の話し合いが続いています
- 2023年からは Starlink が使えます

## 農業

| 項目 | 内容 |
| --- | --- |
| GDP に占める割合 | 約4分の1〜3分の1 |
| 働く人 | 大部分が農業 |
| 輸出に占める農産物 | 約8割 |
| いちばんの輸出 | **たばこ**（輸出の半分〜6割ほど） |
| ほかの輸出 | 茶、砂糖、大豆、落花生、マカダミア、キマメ（インドへ） |
| 主食 | トウモロコシ（シマ） |

- ほとんどの農家は1 ha に満たない畑で、トウモロコシを中心に作ります
- 雨季は11〜4月の1回だけで、雨に頼ります。乾季には、川や湿地のそばで野菜を作る畑（「ディンバ」）もあります
- たばこの値段が下がり、世界でたばこを減らす流れもあるので、ほかの作物を増やすことが国の課題です。2020年には、産業用の大麻（ヘンプ）の栽培も認めました

![収穫したトウモロコシの皮をむく（カスング県）](images/maize-dehusk.jpg)

### 天気の災害と食料不足

- 2023年: サイクロン・フレディ。6日間で半年分の雨が降り、洪水と土砂崩れで1,000人以上が亡くなったり行方不明になったりした
- 2024年: エルニーニョによる干ばつ。28の県のうち23で「災害」を宣言した
- 2025年: トウモロコシの取れ高は、5年の平均より約22%少なかった。2025年10月〜2026年3月に、約400万人が食料の危機の状態になると見込まれた
- 国が1年に必要なトウモロコシは約350万トンです

### 肥料の補助

- 小さな農家に、肥料と種を安く売る国の補助があります（2020年から「AIP」。2025年の政権交代のあと、前の名前「FISP」に戻った）
- 国の予算を多く使うのに、肥料が届くのが遅れることがよくあります。2025年12月には、肥料をまく時期なのに、受け取れた農家は35%だけでした

## 酪農

### 数字

| 項目 | 数字 |
| --- | --- |
| 乳牛 | 約5万5千頭（マラウイ乳生産者協会）。牛の登録の仕組みがないので、どの数字も推計 |
| 1頭が1日に出す乳 | 8〜15 L |
| 1人が1年に飲む乳 | 5〜8 L ほど。アフリカの平均（約20 L）よりずっと少ない |
| 国内で足りている割合 | 需要の約65%（国連食糧農業機関 FAO）。残りは粉乳などの輸入 |
| 農家が売る値段 | 1 L 725〜900クワチャ（2025年12月）。作る費用は1 L 約890クワチャ |

### 産地と集乳

- 産地は3つ: 南部のシレ高地（ブランタイヤのまわり）、中部（リロングウェ・ドーワ・ムチンジ）、北部（ムズズ）
- **集乳グループ**（MBG、Milk Bulking Group）: 1960年代から、農家がグループを作り、冷却タンクのある集乳所に乳を持ち寄って、工場に売っています。家で飲む分を除いた乳の半分ほどが、集乳所を通ります。残りは、町の人や業者に直接売ります
- 乳牛は、援助の事業で配られた交雑種が多く、子牛をほかの農家に渡して広げる仕組みもあります

![牛小屋から顔を出す乳牛（マラウイ中部の村）](images/malawi-dairy-cow.jpg)

### 乳業

- 加工工場は7つほどで、設備の約4割しか使われていません
- 2019年に、大手の Dairibord Malawi が赤字で撤退しました
- 2023年に、中部の大きな買い手だった Malawi Dairy Industries が止まり、5,000をこえる農家が乳の売り先を失いました。原因の1つは、停電で工場が動かせないことでした
- ほかに Lilongwe Dairy、Suncrest Creameries（ブランタイヤ）などがあります。粉乳の工場を作る計画もあります
- 政府は2025年3月、生乳などの輸入を禁止し、2025年4月に農家から買う最低の値段（1 L 800クワチャ）を決めました

### 困っていること

- **停電**: 集乳所の冷却タンクや工場が止まる
- **エサ代**: エサのトウモロコシのぬかは、トウモロコシが高い年に値段が上がる
- **外貨**: 機械・薬・精液（人工授精用）の輸入が難しい
- **人**: 人工授精や獣医の人が少ない
- **値段**: 農家が売る値段が、作る費用を下回ることがある

## IoT・アグリテックの会社

マラウイのアグリテックは、まだ小さな会社が多く、情報も少ない段階です。

| 会社・取り組み | 何をしている |
| --- | --- |
| **Seedgro** | 畑に埋めた土のセンサーのデータを、IoT・クラウドで集め、ショートメッセージ・音声・USSD で農家に伝える |
| **Mechro Limited** | ブランタイヤの会社。小さな農家向けの安い土の水分のセンサー（Chameleon）と、AI で作物や作業をすすめる仕組み。2025年にアフリカ電気通信連合の発明の大会で上位10に入った |
| [**Nuru Solutions**](https://nuru.solutions/) | 農業のデータを、農家の判断の道具にする（2024年に始まった。創業者は保険の Pula の出身） |
| [**Noble Agriculture Technologies**](https://nobleagritech.com/) | リロングウェの、IoT の農業の会社。2019年に気候への適応の賞（SEED）を受けた |
| **Mbora** | 小さな農家への少額のローン |
| **Ulangizi**（[Opportunity International](https://opportunity.org/)） | WhatsApp で、英語かチェワ語で農業の質問に答える AI。写真で作物の病気を見分ける。スマホのない農家には、相談員が代わりに使う |
| **Inyosi Tech Hub** | スタートアップを育て、若者にデジタルの技術を教える |

- 2017年、ユニセフとマラウイ政府は、アフリカで初めての「人道支援のドローンの試験空域」をカスング県に作りました。ドローンで検体や薬を運ぶ試験が行われ、ドローンの技術者が育っています
- 農家の多くはスマホを持っていないので、ラジオ・ショートメッセージ・USSD・音声で情報を届けるのがふつうです

## 日本とのつながり

- 青年海外協力隊が長く、多く派遣されてきた国です
- 大分県の「一村一品運動」をもとにした取り組み（OVOP）が、2003年から国の事業として続いています
- 2025年の TICAD 9 では、モザンビーク・マラウイ・ザンビアをまとめて開発する構想が出されました

## 参入するなら

### 正直に言うと

- 市場が小さく、外貨不足・停電・物価の上がり方が大きいので、**ふつうの商売として入るのは、3か国でいちばん難しい**です
- 機械を輸入する外貨が手に入りにくく、売上をクワチャで受け取ると、その価値が下がりやすい
- 入りやすいのは、**援助の事業**（世界銀行・EU・イギリス・JICA・NGO）の一部として、技術を届ける形です

### ねらい目

- **集乳所の冷却の見張りと、停電への備え**: 太陽光と電池で冷却を続け、温度と停電を知らせる。工場が止まった原因（停電）にそのまま効きます
- **乳の検査**: 品質で値段を決めて、農家の収入を上げる
- **トウモロコシの保存**: 倉庫や家の穀物の温度・湿度・虫のセンサー。取ったあとに傷んで捨てる量を減らす
- **乾季の畑（ディンバ）の水の管理**: 安い土の水分のセンサーと、ポンプ
- **低い値段で作る試験の場**: マラウイで動く安さと丈夫さなら、ほかの国でも使える

### 注意すること

- **外貨とお金**: 部品の輸入、利益を国外に送ること、どちらも難しい。値段はドルで決めるか、援助の予算で払ってもらう
- **停電**: 機械は太陽光・電池で動く作りに
- **個人データの法律**（2024年）: 大きくデータを扱う会社は、通信規制庁（MACRA）への登録がいる
- **電波の機械の認証**: MACRA の型式の認証
- **画面より声**: スマホが少ないので、チェワ語の音声・ショートメッセージ・USSD で

### 入り方の例

- JICA の事業や協力隊の人とつながり、現場の集乳グループを紹介してもらう
- 援助の団体の酪農・農業の事業に、センサーと見える化の担当として加わる
- 現地の若い起業家（Seedgro、Mechro など）と組んで、現地で直せる体制を作る
