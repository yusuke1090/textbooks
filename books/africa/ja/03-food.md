# 3. 食べ物

## 主食は「練ったトウモロコシの粉」

東アフリカから南部アフリカでは、トウモロコシの粉をお湯で練った、白くて固いおもちのようなものが主食です。国によって名前が変わります。

| 国 | 名前 |
| --- | --- |
| ケニア・タンザニア | **ウガリ**（ugali） |
| マラウイ・ザンビア | **シマ**（nsima） |
| ジンバブエ | サザ（sadza） |
| 南アフリカ | パップ（pap） |

- 右手で一口分をちぎって丸め、指でくぼみを作って、おかずをすくって食べます
- 味はほとんどなく、おかずと一緒に食べてお腹をふくらませるものです。「ウガリ（シマ）を食べないと、ご飯を食べた気がしない」という人が多い
- だから、トウモロコシの取れ高と値段は、暮らしと政治に直結します（6〜8章）

ほかの主食

- 米（ピラウ・ビリヤニ。海岸の町で多い）
- チャパティ（インドから伝わった薄いパン）
- キャッサバ、さつまいも
- マトケ（料理用のバナナ。ウガンダやタンザニア北西部）

## 3か国の名物

### タンザニア

- **チップス・マヤイ**: フライドポテトを卵でとじたオムレツ。屋台の定番
- **ミシカキ**: 牛肉の串焼き
- **ピラウ**: スパイスで炊いたご飯（海岸の料理）
- **ウロジョ**（ザンジバル・ミックス）: ザンジバルの屋台の、酸っぱくてからいスープ
- ザンジバルはクローブなどの香辛料で有名で、「スパイス・アイランド」とよばれます

### ケニア

- **ギゼリ**: トウモロコシと豆を煮たもの（キクユの人たちの料理）
- **ムキモ**: じゃがいも・青菜・トウモロコシ・豆をつぶしたもの
- **マンダジ**: 揚げパン。朝の紅茶と一緒に食べる
- **ムルシク**: カレンジンの人たちの発酵乳。ひょうたんの中を炭でいぶしてから牛乳を入れて発酵させる。長距離の選手が食べることで知られる

### マラウイ

- **チャンボ**: マラウイ湖でとれるティラピアの仲間。マラウイでいちばん人気の魚で、シマと食べる
- **ウシパ**: マラウイ湖の小魚。干して売る
- **コンドウォレ**: キャッサバの粉で作るシマ（北部の湖の岸で食べる）
- **トブワ**: トウモロコシやモロコシを軽く発酵させた、甘酸っぱい飲み物（お酒ではない）
- 落花生をすりつぶして青菜と煮る料理が多い

## 飲み物

- **チャイ**: 東アフリカの紅茶は、水と牛乳と茶葉と砂糖を一緒に煮出した、甘いミルクティー。しょうが（スワヒリ語で「タンガウィジ」）を入れることも。ケニアは世界有数の紅茶の輸出国です
- **コーヒー**: コーヒーの木のふるさとはエチオピア。タンザニアのキリマンジャロのコーヒーは日本でも有名ですが、地元では紅茶のほうがよく飲まれます
- **牛乳**: ケニアでは、牛乳は毎日の飲み物です。わかして飲む。発酵乳（スワヒリ語で「マジワ・ララ」、寝かせた乳）も好まれます
- **ビール**: タスカー（ケニア）、キリマンジャロ・サファリ（タンザニア）、カールスバーグ（マラウイに工場がある）。モロコシやトウモロコシで作る、酸っぱくてどろっとしたお酒（チブク）もあります

## 食べるときの作法

- 食べる前に手を洗います。家や食堂では、たらいと水差しを持ってきて、手に水をかけてくれることがあります
- 食べるのも、物を渡すのも**右手**です。左手は不浄とされます
- すすめられた食べ物や飲み物は、少しでも口にするのが礼儀です
- 家に招かれたら、砂糖・茶葉・果物などの手みやげが喜ばれます

## 食の今

- 町ではスーパー、ファストフード、カフェが増えています（ナイロビのカフェチェーン「Java House」など）
- それでも、食べ物の多くは、市場と小さな店（ドゥカ、キオスク）で、その日に必要な分だけ買います
- 冷蔵庫がない家も多いので、牛乳はその日に飲むか、発酵乳にします。このことが、6〜8章の「乳を冷やす」話につながります
- 子どもの栄養不足（背が伸びない「発育阻害」）は、タンザニアとマラウイで大きな問題です。牛乳・卵・魚などのたんぱく質を、安く届けることが求められています
