## 時制（7・8章）

| 時制 | 肯定 | 打ち消し |
| --- | --- | --- |
| 現在 | ni-na-soma | si-som-i |
| 過去 | ni-li-soma | si-ku-soma |
| 未来 | ni-ta-soma | si-ta-soma |
| 完了 | ni-me-soma | si-ja-soma（まだ） |
| 習慣 | hu-soma | — |
| 〜したら | ni-ki-soma | — |
| 〜なら…のに | ni-nge-soma | — |

- 短い動詞（kula・kunywa・kuja・kwenda）は、時の印のあとに ku- を残す: ninakula、nilikunywa
- -e・-i・-u で終わる動詞は、現在の打ち消しで終わりを変えない: sirudi

## 命令とお願い（11章）

| 形 | 作り方 | 例 |
| --- | --- | --- |
| 命令（1人） | 語幹 | Soma! |
| 命令（何人か） | 語幹 -eni | Someni! |
| お願い | 主語 ＋ 語幹 -e | Usome. Tusome. |
| 「〜しないで」 | usi- ＋ 語幹 -e | Usisome. |

## 動詞の後ろを変える（12章）

| 形 | 付け方 | 例 |
| --- | --- | --- |
| 受け身 | -wa | pika → pikwa |
| 〜に・〜のために | -ia / -ea | nunua → nunulia |
| 〜させる | -isha / -esha | la → lisha |
| おたがいに | -ana | ona → onana |
| 〜できる・〜になる | -ika / -eka | vunja → vunjika |
