# 10. たずねる言葉

## はい・いいえでたずねる

- 文の形はそのままで、終わりを上げて言います: **Unakunywa chai?** お茶を飲みますか？
- 文の頭に **Je,** を付けると、質問だとはっきりします: **Je, una maswali?** 質問はありますか？
- 答えは **Ndiyo.**（はい）/ **Hapana.**（いいえ）

## たずねる言葉

| スワヒリ語 | 意味 | 例 |
| --- | --- | --- |
| nani | だれ | Yeye ni nani? 彼はだれ？ |
| nini | 何 | Unataka nini? 何が欲しいの？ |
| wapi | どこ | Unaenda wapi? どこへ行くの？ |
| lini | いつ | Utarudi lini? いつ戻るの？ |
| vipi / -je | どうやって・どう | Unaendaje? どうやって行くの？ |
| kwa nini | なぜ | Kwa nini umechelewa? なぜ遅れたの？ |
| gani | どんな・どの | Unatoka nchi gani? どの国から来たの？ |
| -ngapi | いくつ | Una ng'ombe wangapi? 牛を何頭飼っているの？ |
| -pi | どれ | Kitabu kipi? どの本？ |

- たずねる言葉は、たいてい**文の終わり**に置きます。英語のように前へ出しません: **Unaenda wapi?**（あなたは・行く・どこ）
- **-je** は動詞の終わりに付けます: **Unasemaje?**（何て言ったの？）
- **-ngapi** と **-pi** は、名詞に頭を合わせます: **watu wangapi?**（何人？）、**mtu yupi?**（どの人？）、**gari lipi?**（どの車？）、**nyumba ipi?**（どの家？）

## 「どこにある？」は -ko を名詞に合わせる

4章の **-ko**（〜にいる・ある）も、物のときは名詞の頭に合わせます。

| スワヒリ語 | 意味 | クラス |
| --- | --- | --- |
| Choo kiko wapi? | トイレはどこ？ | KI |
| Benki iko wapi? | 銀行はどこ？ | N |
| Soko liko wapi? | 市場はどこ？ | JI |
| Juma yuko wapi? | ジュマはどこ？ | 人 |

## よく使う質問

| スワヒリ語 | 意味 |
| --- | --- |
| Unaitwa nani? | お名前は？ |
| Unatoka wapi? | どこから来ましたか |
| Unakaa wapi? | どこに住んでいますか |
| Hii ni nini? | これは何ですか |
| Hii ni bei gani? | これはいくらですか |
| Saa ngapi? | 何時ですか |
| Una miaka mingapi? | 何歳ですか |
| Unasemaje "cow" kwa Kiswahili? | 「cow」はスワヒリ語で何と言いますか |
| Neno hili lina maana gani? | この言葉はどういう意味ですか |
| Kuna tatizo? | 何か問題がありますか |

## 会話の例

| スワヒリ語 | 意味 |
| --- | --- |
| A: Habari za mchana? | こんにちは |
| B: Nzuri. Karibu. Unatoka wapi? | こんにちは。どちらから？ |
| A: Ninatoka Japani. Ofisi ya ushirika wa wafugaji iko wapi? | 日本から来ました。畜産農家の協同組合の事務所はどこですか |
| B: Iko pale, karibu na benki. | あそこです。銀行の近くです |
| A: Wanafungua saa ngapi? | 何時に開きますか |
| B: Saa mbili asubuhi. | 朝8時です |
| A: Asante sana. | ありがとうございます |
| B: Karibu. | どういたしまして |

## 練習

1. スワヒリ語で言ってください: (1) トイレはどこですか (2) いつ来ますか（あなたは、これから） (3) 牛を何頭飼っていますか (4) なぜ？
2. 日本語にしてください: (1) Unafanya nini? (2) Kitabu kipi? (3) Unatoka nchi gani?

## 練習の答え

1. (1) Choo kiko wapi? (2) Utakuja lini? (3) Una ng'ombe wangapi? (4) Kwa nini?
2. (1) 何をしていますか (2) どの本ですか (3) どの国から来ましたか
