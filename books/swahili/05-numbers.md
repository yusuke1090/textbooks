## 11〜99

- 11〜19 は「10 と 1」の形です: **kumi na moja**（11）、**kumi na tano**（15）
- 20〜90 は、アラビア語から来た言葉です

| 数 | スワヒリ語 |
| --- | --- |
| 20 | ishirini |
| 30 | thelathini |
| 40 | arobaini |
| 50 | hamsini |
| 60 | sitini |
| 70 | sabini |
| 80 | themanini |
| 90 | tisini |

- 25 は **ishirini na tano**、99 は **tisini na tisa**

## 100 から上

| 数 | スワヒリ語 |
| --- | --- |
| 100 | mia (moja) |
| 200 | mia mbili |
| 1,000 | elfu (moja) |
| 2,500 | elfu mbili na mia tano |
| 10,000 | elfu kumi |
| 100,000 | laki (moja) |
| 1,000,000 | milioni (moja) |

- 大きい位から言い、最後の数の前に **na**（と）を入れます: 1,250 は **elfu moja, mia mbili na hamsini**
- **laki** は10万です（インドの言葉から）: 350,000 は **laki tatu na elfu hamsini**
- 数は名詞のあとに置きます: **watu watano**（5人の人）

## 数を名詞に合わせる

1〜5 と 8 は、名詞のクラス（6章）によって頭が変わります。6・7・9・10 と、20 以上の十の位は変わりません。

| 数 | 人・動物 | 物（KI-VI） | お金（N） |
| --- | --- | --- | --- |
| 1 | mtu mmoja | kitabu kimoja | shilingi moja |
| 2 | watu wawili | vitabu viwili | shilingi mbili |
| 3 | watu watatu | vitabu vitatu | shilingi tatu |
| 4 | watu wanne | vitabu vinne | shilingi nne |
| 5 | watu watano | vitabu vitano | shilingi tano |
| 6 | watu sita | vitabu sita | shilingi sita |
| 8 | watu wanane | vitabu vinane | shilingi nane |

- 牛などの動物は、人と同じ形です: **ng'ombe mmoja**（牛1頭）、**ng'ombe wawili**（牛2頭）
- 12頭は **ng'ombe kumi na wawili**（最後の数だけ合わせる）
- 「いくつ」は **-ngapi** で、これも頭を合わせます: **watu wangapi?**（何人？）、**vitabu vingapi?**（何冊？）、**shilingi ngapi?**（何シリング？）

## 順番

- 「〜番目」は **-a ＋ 数** です: **wa pili**（2番目）、**wa tatu**（3番目）
- 1番目だけは **-a kwanza**: **siku ya kwanza**（1日目）、**mtoto wa kwanza**（1人目の子）
- 2番目は **pili** で、**mbili** ではありません

## お金

- タンザニア・シリング（TSh）とケニア・シリング（KSh）は、どちらも **shilingi**（シリンギ）です
- お金は **pesa**（ペサ）
- 値段をたずねる: **Bei gani?**（いくら？）、**Ni shilingi ngapi?**（何シリング？）
- 答え: **Ni shilingi elfu mbili.**（2,000 シリングです）
- 値段の交渉は13章で

## 時刻（スワヒリの時刻）

スワヒリの時刻は、**朝6時を0時**として、日の出から数えます。**saa moja**（1時）は朝7時のことです。

| 日本の時刻 | スワヒリ語 |
| --- | --- |
| 朝7時 | saa moja asubuhi |
| 朝8時 | saa mbili asubuhi |
| 朝9時 | saa tatu asubuhi |
| 昼12時 | saa sita mchana |
| 午後1時 | saa saba mchana |
| 午後4時 | saa kumi jioni |
| 午後6時 | saa kumi na mbili jioni |
| 夜7時 | saa moja usiku |
| 夜10時 | saa nne usiku |
| 夜0時 | saa sita usiku |
| 朝5時 | saa kumi na moja alfajiri |

- 日本の時刻から6を引く（または足す）と、スワヒリの時刻になります
- 時間帯の言葉: **alfajiri**（夜明け）、**asubuhi**（朝）、**mchana**（昼）、**jioni**（夕方）、**usiku**（夜）
- 分: **na nusu**（半）、**na robo**（15分）、**kasoro robo**（15分前）、**na dakika kumi**（10分）
  - 朝8時半: **saa mbili na nusu asubuhi**
  - 朝9時45分: **saa nne kasoro robo asubuhi**（4時の15分前）
- 「何時？」は **Saa ngapi?** です。**saa** は「時計・時間・〜時」のどれにも使います
- 待ち合わせでは、どちらの時刻か確かめます: **Saa mbili za Kiswahili au za Kizungu?**（スワヒリの2時？ ヨーロッパの2時？）

## 曜日

| 曜日 | スワヒリ語 | 読み |
| --- | --- | --- |
| 土曜 | Jumamosi | ジュマモスィ |
| 日曜 | Jumapili | ジュマピリ |
| 月曜 | Jumatatu | ジュマタトゥ |
| 火曜 | Jumanne | ジュマンネ |
| 水曜 | Jumatano | ジュマタノ |
| 木曜 | Alhamisi | アルハミスィ |
| 金曜 | Ijumaa | イジュマア |

- 金曜（**Ijumaa**）は、イスラム教の集まりの日です。そのあとの土曜を「1日目」（**mosi**）として、**Juma ＋ 数** で数えます。月曜は **Jumatatu**（3日目）になります
- **Leo ni Jumatatu.** 今日は月曜です

## 日・週・月・年

| スワヒリ語 | 意味 |
| --- | --- |
| leo | 今日 |
| kesho | 明日 |
| kesho kutwa | あさって |
| jana | 昨日 |
| juzi | おととい |
| sasa | 今 |
| baadaye | あとで |
| siku | 日 |
| wiki | 週（wiki ijayo 来週、wiki iliyopita 先週） |
| mwezi | 月（mwezi ujao 来月）。空の月も mwezi |
| mwaka | 年（mwaka huu 今年） |

- 月の名前は **Januari, Februari, Machi, Aprili, Mei, Juni, Julai, Agosti, Septemba, Oktoba, Novemba, Desemba** です
- 日付は **tarehe**: **tarehe kumi na tano Novemba**（11月15日）

## 練習

1. スワヒリ語で言ってください: (1) 18 (2) 45 (3) 300 (4) 1,500 (5) 25,000
2. スワヒリの時刻で言ってください: (1) 朝8時 (2) 午後1時 (3) 夜9時 (4) 朝10時半
3. **saa tatu asubuhi** は、日本の何時ですか
4. 数の頭を合わせてください: (1) 人3人 (2) 本2冊 (3) 牛5頭

## 練習の答え

1. (1) kumi na nane (2) arobaini na tano (3) mia tatu (4) elfu moja na mia tano (5) elfu ishirini na tano
2. (1) saa mbili asubuhi (2) saa saba mchana (3) saa tatu usiku (4) saa nne na nusu asubuhi
3. 朝9時
4. (1) watu watatu (2) vitabu viwili (3) ng'ombe watano
