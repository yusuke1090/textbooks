# 9. 形容詞・「〜の」・「この」

## 形容詞は名詞のあと

日本語と逆で、形容詞は名詞のあとに置きます。頭は名詞のクラスに合わせます（6章）。

- **mtu mzuri** よい人
- **kitabu kikubwa** 大きい本
- **magari madogo** 小さい車（何台か）

### よく使う形容詞

| 語幹 | 意味 | 語幹 | 意味 |
| --- | --- | --- | --- |
| -zuri | よい・きれい | -baya | 悪い |
| -kubwa | 大きい | -dogo | 小さい |
| -refu | 長い・背が高い | -fupi | 短い |
| -pya | 新しい | -zee | 古い・年をとった |
| -ingi | 多い | -chache | 少ない |
| -zito | 重い | -epesi | 軽い・簡単な |
| -gumu | かたい・むずかしい | -tamu | 甘い・おいしい |
| -kali | からい・きびしい | -bichi | 生の・熟していない |
| -ekundu | 赤い | -eupe | 白い |
| -eusi | 黒い | -ema | よい（人がら） |

- 母音で始まる語幹は、頭とくっついて形が変わります: **watu wengi**（多くの人。wa＋ingi）、**maziwa mengi**（たくさんの牛乳。ma＋ingi）、**mtu mwema**（よい人）

### 頭を付けない形容詞

アラビア語などから来た形容詞は、どの名詞でも形が変わりません。

| スワヒリ語 | 意味 |
| --- | --- |
| safi | きれいな・清潔な・新鮮な |
| ghali | 値段が高い |
| rahisi | 安い・簡単な |
| tayari | 準備ができた |
| muhimu | 大事な |
| bora | すぐれた |
| hodari | 上手な |

- **maziwa safi** 新鮮な牛乳、**bei ghali** 高い値段、**Chakula kiko tayari.** ご飯ができました

### N クラスの形容詞

N クラスの名詞には、語幹の始まりの音によって **n-**・**m-**・**ny-** が付いたり、何も付かなかったりします。

| 語幹 | N の形 | 例 |
| --- | --- | --- |
| -zuri | nzuri | nyumba nzuri（よい家） |
| -dogo | ndogo | nyumba ndogo（小さい家） |
| -refu | ndefu | barabara ndefu（長い道） |
| -pya | mpya | simu mpya（新しい電話） |
| -eupe | nyeupe | kanzu nyeupe（白い長衣） |
| -kubwa | kubwa | nyumba kubwa（大きい家） |
| -tamu | tamu | chai tamu（甘いお茶） |

## 〜の（-a）

「A の B」は、**B ＋ -a ＋ A** の順です。-a の頭は B に合わせます。

| スワヒリ語 | 意味 |
| --- | --- |
| mtoto wa Juma | ジュマの子 |
| kitabu cha mwalimu | 先生の本 |
| gari la kampuni | 会社の車 |
| maziwa ya ng'ombe | 牛の乳 |
| nyumba ya mkulima | 農家の家 |
| shamba la mahindi | トウモロコシ畑 |
| chai ya maziwa | ミルクティー |
| daktari wa mifugo | 獣医（家畜の医者） |

- 形は **wa・ya・la・cha・vya・za・kwa** です（6章の表の「〜の」）

## 私の・あなたの

| 語幹 | 意味 |
| --- | --- |
| -angu | 私の |
| -ako | あなたの |
| -ake | 彼・彼女の |
| -etu | 私たちの |
| -enu | あなたたちの |
| -ao | 彼らの |

頭は「〜の」と同じです。

| 名詞 | 私の | あなたの |
| --- | --- | --- |
| mtoto（子ども） | mtoto wangu | mtoto wako |
| kitabu（本） | kitabu changu | kitabu chako |
| vitabu（本、何冊か） | vitabu vyangu | vitabu vyako |
| gari（車） | gari langu | gari lako |
| jina（名前） | jina langu | jina lako |
| nyumba（家、1軒） | nyumba yangu | nyumba yako |
| nyumba（家、何軒か） | nyumba zangu | nyumba zako |
| ng'ombe（牛） | ng'ombe wangu | ng'ombe wako |

## この・あの

| クラス | この | あの |
| --- | --- | --- |
| 人（1人） | huyu | yule |
| 人（何人か） | hawa | wale |
| M（木1本） | huu | ule |
| MI（木々） | hii | ile |
| JI（1つ） | hili | lile |
| MA（2つ以上） | haya | yale |
| KI（1つ） | hiki | kile |
| VI（2つ以上） | hivi | vile |
| N（1つ） | hii | ile |
| N（2つ以上） | hizi | zile |

- 名詞のあとに置きます: **mtu huyu**（この人）、**kitabu hiki**（この本）、**ng'ombe huyu**（この牛）、**ng'ombe hawa**（これらの牛）
- 1語でも使えます: **Hii ni nini?**（これは何？）
- 「さっき話したその」は **-o** の形です: **huyo**・**hicho**・**hiyo** など

## 比べる

- **kuliko**（〜より）: **Gari hili ni kubwa kuliko lile.** この車はあの車より大きい
- **kuliko wote**（いちばん）: **Ng'ombe huyu ni mzuri kuliko wote.** この牛がいちばんよい
- **sana**（とても）: **mzuri sana**、**kidogo**（少し）: **ghali kidogo**（少し高い）

## 練習

1. 頭を合わせてください: (1) watoto（-zuri） (2) kitabu（-kubwa） (3) magari（-ingi） (4) nyumba（-dogo） (5) ng'ombe 1頭（-kubwa）
2. スワヒリ語で言ってください: (1) 私の車 (2) 先生の本 (3) この牛（1頭） (4) あなたの家

## 練習の答え

1. (1) watoto wazuri (2) kitabu kikubwa (3) magari mengi (4) nyumba ndogo (5) ng'ombe mkubwa
2. (1) gari langu (2) kitabu cha mwalimu (3) ng'ombe huyu (4) nyumba yako
