# 11. 目的語・命令・お願い

## 目的語の印

「私を・あなたを・それを」は、動詞の中の、**語幹のすぐ前**に入れます。

**ni-na-ku-penda** = 私は・今・あなたを・好き → **Ninakupenda.**（あなたが好きです）

| 目的語 | 印 |
| --- | --- |
| 私を・私に | -ni- |
| あなたを・あなたに | -ku- |
| 彼・彼女を | -m-（母音の前は -mw-） |
| 私たちを | -tu- |
| あなたたちを・彼らを | -wa- |

物のときは、主語の頭と同じ印を使います: kitabu → **-ki-**、gari → **-li-**、nyumba → **-i-**、maziwa → **-ya-**。

| スワヒリ語 | 意味 |
| --- | --- |
| Alinisaidia. | 彼が（私を）手伝ってくれた |
| Nitakupigia simu. | あなたに電話します |
| Umemwona Juma? — Ndiyo, nimemwona. | ジュマを見た？ — うん、見たよ |
| Kitabu, nimekinunua. | 本は、もう買った |
| Ng'ombe, nimewauza. | 牛は（何頭か）売った |
| Maziwa, umeyanywa? | 牛乳、飲んだ？ |

- 人や生き物が目的語のときは、名詞があっても印を入れることが多いです: **Nimemwona mwalimu.**（先生を見かけた）
- 物は、もう話に出ていて「それを」と言うときに入れます

## 命令

| 相手 | 作り方 | 例 |
| --- | --- | --- |
| 1人 | 語幹のまま | Soma!（読んで） Sikiliza!（聞いて） Subiri!（待って） |
| 何人か | 終わりを -eni に | Someni! Sikilizeni! Subirini! |

- 終わりが -a でない動詞は **-ni** を付けます: Subiri → **Subirini**

### 形が変わる命令

| 動詞 | 1人に | 何人かに |
| --- | --- | --- |
| kuja 来る | Njoo! | Njooni! |
| kwenda 行く | Nenda! | Nendeni! |
| kula 食べる | Kula! | Kuleni! |
| kunywa 飲む | Kunywa! | Kunyweni! |

## ていねいなお願い（-e の形）

命令はきつく聞こえることがあります。ふつうは「**主語の頭 ＋ 語幹 ＋ 終わりを -e に**」の形を使います（接続法といいます）。

| スワヒリ語 | 意味 |
| --- | --- |
| Tafadhali, unisaidie. | どうか手伝ってください |
| Naomba unisaidie. | 手伝っていただけませんか |
| Nisubiri kidogo. | ちょっと待って |
| Niletee maji. | 水を持ってきて |
| Nikusaidie? | 手伝いましょうか |
| Tuanze. | 始めましょう |
| Twende! | 行きましょう |

- **Twende** は **tu-end-e**（私たちが・行く）が縮まった形です
- **-ni-**（私に）を付けた **Nipe**（ちょうだい）もよく使います: **Nipe maji.**（水をちょうだい）

### 「〜しないで」

**usi- ＋ 語幹 ＋ -e** で作ります。何人かに言うときは **msi-** です。

- **Usiguse!** さわらないで
- **Usijali.** 気にしないで
- **Msiogope.** （みなさん）こわがらないで

## お店や食堂で「〜をください」

| スワヒリ語 | 意味 |
| --- | --- |
| Naomba maji. | 水をください |
| Nipe chai, tafadhali. | お茶をください |
| Nataka... | 〜が欲しい（少し直接的） |
| Ningependa... | 〜が欲しいのですが（ていねい） |

- **Naomba**（お願いします）は、とても便利で、ていねいな言い方です

## 練習

1. スワヒリ語で言ってください: (1) （これから）あなたを手伝います (2) 彼は私を見た (3) 来て！（1人に） (4) 行きましょう (5) さわらないで
2. 日本語にしてください: (1) Naomba maziwa. (2) Nikusaidie? (3) Usijali.
