# 4. 自己紹介と「〜です」

## 人をさす言葉

| スワヒリ語 | 読み | 意味 |
| --- | --- | --- |
| mimi | ミミ | 私 |
| wewe | ウェウェ | あなた |
| yeye | イェイェ | 彼・彼女（男女の区別がない） |
| sisi | スィスィ | 私たち |
| ninyi | ニニ | あなたたち |
| wao | ワオ | 彼ら |

## ni（〜です）と si（〜ではない）

- 主語がだれでも **ni** です。英語の am・is・are のように変わりません
  - **Mimi ni Mjapani.** 私は日本人です
  - **Yeye ni mwalimu.** 彼（彼女）は先生です
  - **Wao ni wakulima.** 彼らは農家です
- 打ち消しは **si** です
  - **Mimi si Mkenya.** 私はケニア人ではありません
- 主語は省くことも多いです: **Ni mimi.**（私です）

### 国・人・言葉

| 国 | 人（1人 / 何人か） | 言葉 |
| --- | --- | --- |
| Japani（日本） | Mjapani / Wajapani | Kijapani |
| Tanzania | Mtanzania / Watanzania | — |
| Kenya | Mkenya / Wakenya | — |
| Uingereza（イギリス） | Mwingereza / Waingereza | Kiingereza（英語） |
| Marekani（アメリカ） | Mmarekani / Wamarekani | — |
| China（中国） | Mchina / Wachina | Kichina |

- 人は **M-**（1人）・**Wa-**（何人か）、言葉は **Ki-** を頭に付けます。この頭の決まりは、6章の「名詞のクラス」につながります

## 名前

| スワヒリ語 | 意味 |
| --- | --- |
| Jina langu ni Kenji. | 私の名前はケンジです |
| Ninaitwa Kenji. | ケンジといいます（ケンジとよばれています） |
| Jina lako nani? / Unaitwa nani? | お名前は？ |

## -ko（〜にいる）

「どこにいる・ある」は、**ni** ではなく **-ko** を使います。

| スワヒリ語 | 意味 | 打ち消し |
| --- | --- | --- |
| niko | 私は〜にいる | siko |
| uko | あなたは〜にいる | hauko |
| yuko | 彼・彼女は〜にいる | hayuko |
| tuko | 私たちは〜にいる | hatuko |
| mko | あなたたちは〜にいる | hamko |
| wako | 彼らは〜にいる | hawako |

- **Uko wapi?** — **Niko Arusha.** どこにいるの？ — アルーシャにいます
- **Juma hayuko.** ジュマはいません
- よく使う言い方: **Niko salama.**（無事です＝元気です）、**Tuko pamoja.**（私たちは一緒だ＝わかるよ、味方だよ）

## -na（〜を持っている）

| スワヒリ語 | 意味 | 打ち消し |
| --- | --- | --- |
| nina | 私は〜を持っている | sina |
| una | あなたは〜を持っている | huna |
| ana | 彼・彼女は〜を持っている | hana |
| tuna | 私たちは〜を持っている | hatuna |
| mna | あなたたちは〜を持っている | hamna |
| wana | 彼らは〜を持っている | hawana |

- **Nina ng'ombe watatu.** 牛を3頭持っています
- **Sina pesa.** お金がありません
- **Una watoto?** — **Ndiyo, nina watoto wawili.** 子どもはいますか？ — はい、2人います
- 「〜がある・ない」は **kuna** / **hakuna** です
  - **Kuna maji?** — **Hakuna.** 水はありますか？ — ありません
  - **Hakuna matata.** 問題はない

## 出身・住まい・仕事

まだ動詞の形（7章）を習っていないので、まとまりで覚えます。

| スワヒリ語 | 意味 |
| --- | --- |
| Unatoka wapi? | どこから来ましたか |
| Ninatoka Japani. | 日本から来ました |
| Unakaa wapi? | どこに住んでいますか |
| Ninakaa Hokkaido. | 北海道に住んでいます |
| Unafanya kazi gani? | 何の仕事をしていますか |
| Mimi ni mkulima. | 私は農家です |
| Ninafanya kazi ya ufugaji wa ng'ombe wa maziwa. | 乳牛を飼う仕事をしています |
| Ninajifunza Kiswahili. | スワヒリ語を勉強しています |
| Ninazungumza Kiswahili kidogo tu. | スワヒリ語は少しだけ話せます |

## 自己紹介の例

> **Habari zenu? Jina langu ni Kenji. Mimi ni Mjapani, ninatoka Hokkaido. Ninafanya kazi ya ufugaji wa ng'ombe wa maziwa. Ninajifunza Kiswahili. Nimefurahi kukutana nanyi. Asanteni.**
>
> みなさん、こんにちは。私の名前はケンジです。日本人で、北海道から来ました。乳牛を飼う仕事をしています。スワヒリ語を勉強しています。みなさんにお会いできてうれしいです。ありがとうございました。

## 練習

1. スワヒリ語で言ってください: (1) 私は日本人です (2) 彼はケニア人ではありません (3) どこにいますか — ナイロビにいます (4) お金がありません
2. 打ち消しにしてください: (1) Nina gari.（車を持っている） (2) Yuko nyumbani.（家にいる） (3) Kuna maziwa.（牛乳がある）

## 練習の答え

1. (1) Mimi ni Mjapani. (2) Yeye si Mkenya. (3) Uko wapi? — Niko Nairobi. (4) Sina pesa.
2. (1) Sina gari. (2) Hayuko nyumbani. (3) Hakuna maziwa.
