# 14. クラスの拡張（継承・仮想関数）

## この章でわかること

- 継承（もとのクラスに機能を足した、新しいクラスを作る）
- protected と、基本クラスのコンストラクタの呼び方
- オーバーライドと仮想関数
- 抽象クラス

## 継承

すでにあるクラスをもとに、メンバを足した新しいクラスを作ることを**継承**といいます。

| 言葉 | 意味 | 例 |
| --- | --- | --- |
| 基本クラス（親クラス） | もとのクラス | `Car` |
| 派生クラス（子クラス） | 継承して作ったクラス | `RacingCar` |

派生クラスは、基本クラスのメンバを受けつぎ、自分のメンバを足します。

```cpp
class Car {
protected:                     // 派生クラスからは使える
    int num;
    double gas;

public:
    Car(int n, double g) : num(n), gas(g) {}
    virtual ~Car() {}
    virtual void show() const
    {
        cout << "ナンバーは" << num << "、ガソリン量は" << gas << "です。\n";
    }
};

class RacingCar : public Car { // Car を継承する
private:
    int course;                // 足したメンバ

public:
    RacingCar(int n, double g, int c) : Car(n, g), course(c) {}
    void show() const override // 基本クラスの show を上書きする
    {
        cout << "レーシングカーのナンバーは" << num << "、ガソリン量は" << gas
             << "、コース番号は" << course << "です。\n";
    }
};
```

### アクセスの指定

| 指定 | そのクラス | 派生クラス | 外 |
| --- | --- | --- | --- |
| `public` | ○ | ○ | ○ |
| `protected` | ○ | ○ | × |
| `private` | ○ | × | × |

`class RacingCar : public Car` の `public` は、基本クラスの public のメンバを、派生クラスでも public のままにするという意味です。ふつうは `public` で継承します。

### 基本クラスのコンストラクタ

派生クラスのオブジェクトを作ると、先に**基本クラスのコンストラクタ**が呼ばれます。どれを呼ぶかは、初期化リストで指定します（`: Car(n, g)`）。指定しないと、基本クラスの引数なしのコンストラクタが呼ばれます。デストラクタは逆の順（派生 → 基本）に呼ばれます。

## オーバーライド

派生クラスで、基本クラスと**同じ名前・同じ引数**のメンバ関数を定義し直すことを**オーバーライド**といいます。

> 名前が同じで**引数がちがう**関数を作るのはオーバーロード（7章）です。名前が似ていますが別のものです。

`override` を付けておくと、基本クラスに同じ関数がない（名前や引数をまちがえた）ときに、エラーで教えてくれます。

## 仮想関数

基本クラスのポインタ（や参照）は、派生クラスのオブジェクトを指せます。そのポインタから関数を呼んだとき、

- ふつうの関数なら、**ポインタの型**（基本クラス）の関数が呼ばれる
- `virtual` を付けた**仮想関数**なら、**実際のオブジェクト**（派生クラス）の関数が呼ばれる

```cpp
int main()
{
    Car* cars[2];
    cars[0] = new Car(1234, 20.5);
    cars[1] = new RacingCar(4567, 30.0, 5);

    for (Car* c : cars) {
        c->show();     // それぞれのクラスの show が呼ばれる
    }
    for (Car* c : cars) {
        delete c;
    }
    return 0;
}
```

```text
ナンバーは1234、ガソリン量は20.5です。
レーシングカーのナンバーは4567、ガソリン量は30、コース番号は5です。
```

同じ呼び方で、オブジェクトごとにちがう動きをすることを**ポリモーフィズム**（多態性）といいます。いろいろな種類のものを、1つの配列にまとめて同じように扱えます。

> 基本クラスのポインタで `delete` するときに派生クラスのデストラクタも呼ばれるよう、継承して使うクラスのデストラクタには `virtual` を付けます（`virtual ~Car() {}`）。

## 抽象クラス

`= 0` を付けた仮想関数を**純粋仮想関数**といいます。中身がなく、派生クラスで必ずオーバーライドします。純粋仮想関数を持つクラスを**抽象クラス**といい、オブジェクトは作れません。「この関数を持つこと」という決まりだけを示すときに使います。

```cpp
class Vehicle {
public:
    virtual void show() const = 0;   // 純粋仮想関数
    virtual ~Vehicle() {}
};

class Bike : public Vehicle {
public:
    void show() const override { cout << "自転車です。\n"; }
};

// Vehicle v;     // エラー（抽象クラスのオブジェクトは作れない）
Bike b;           // OK
```

## 多重継承

C++ では、2つ以上のクラスを継承できます（`class C : public A, public B`）。同じ名前のメンバがあるとあいまいになるなど、ややこしくなるので、使うのは抽象クラス（決まりだけのクラス）を足すときくらいにします。

## まとめ

- `class 派生 : public 基本` で継承する。基本クラスのコンストラクタは初期化リストで呼ぶ
- 派生クラスから使わせたいメンバは `protected`
- オーバーライドには `override`、基本クラスの関数には `virtual` を付ける
- 仮想関数なら、基本クラスのポインタから派生クラスの関数が呼ばれる。デストラクタも `virtual`
- `= 0` の純粋仮想関数を持つ抽象クラスは、オブジェクトを作れない
