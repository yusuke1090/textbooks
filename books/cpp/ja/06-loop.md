# 6. 繰り返し

## この章でわかること

- for 文・while 文・do while 文
- 文の入れ子（九九の表）
- break と continue

## for 文

回数が決まっている繰り返しに使います。

```cpp
for (int i = 1; i <= 5; i++) {
    cout << i << "番目の繰り返しです。\n";
}
cout << "繰り返しが終わりました。\n";
```

`for (初期化; 条件; 変化)` の順に動きます。

1. 初期化（`int i = 1`）を1回だけする
2. 条件（`i <= 5`）が true なら、ブロックの中を実行する。false なら終わる
3. 変化（`i++`）をして、2 にもどる

## while 文

条件が true の間、繰り返します。回数が決まっていないときに使います。

```cpp
int num = 0, sum = 0;
cout << "整数を入力（0 で終わり）\n";
cin >> num;
while (num != 0) {
    sum += num;
    cin >> num;
}
cout << "合計は" << sum << "です。\n";
```

## do while 文

先に1回実行してから、条件を調べます。**必ず1回は実行**されます。

```cpp
int num = 0;
do {
    cout << "1〜9 の数を入力してください。\n";
    cin >> num;
} while (num < 1 || num > 9);     // 最後に ; が要る
```

## 文の入れ子

繰り返しの中に繰り返しを書けます。

```cpp
for (int i = 1; i <= 9; i++) {
    for (int j = 1; j <= 9; j++) {
        cout << i * j << '\t';
    }
    cout << '\n';
}
```

外の `i` が1つ進むたびに、中の `j` が 1〜9 まで回ります（九九の表になる）。

## break と continue

| 文 | すること |
| --- | --- |
| `break` | 繰り返しをすぐに終わる（一番内側の繰り返しだけ） |
| `continue` | その回の残りを飛ばして、次の回に進む |

```cpp
for (int i = 1; i <= 10; i++) {
    if (i == 7) break;          // 7 になったら終わる
    if (i % 2 == 0) continue;   // 偶数は飛ばす
    cout << i << " ";           // 1 3 5
}
```

## 無限ループに注意

条件がいつまでも true だと、繰り返しが終わりません（**無限ループ**）。止まらなくなったら、ターミナルで **Ctrl + C** を押して止めます。

```cpp
int i = 0;
while (i < 5) {
    cout << i << "\n";
    // i++ を忘れると、ずっと 0 を出し続ける
}
```

## 範囲 for 文

配列（9章）やベクタの中身を、1つずつ順に取り出せます（C++11 から）。

```cpp
int test[] = {80, 60, 22, 50, 75};
for (int t : test) {
    cout << t << "\n";
}
```

## まとめ

- 回数が決まっていれば `for`、決まっていなければ `while`、必ず1回するなら `do while`
- `break` で終わる、`continue` で次の回へ
- 止まらないときは Ctrl + C

## 練習問題

```quiz
Q: 次のコードは何を表示しますか。
| int sum = 0;
| for (int i = 1; i <= 4; i++) sum += i;
| cout << sum;
A: 10
E: 1 + 2 + 3 + 4 = 10 です。

Q: 次のコードは何を表示しますか。
| int i = 10;
| do { cout << i; } while (i < 5);
A: 10
E: `do while` は、条件を見る前に必ず1回動きます。

Q: 次のコードは何を表示しますか。
| for (int i = 0; i < 6; i++) {
|     if (i == 4) break;
|     if (i % 2 == 0) continue;
|     cout << i;
| }
A: 13 | 1 3
E: 偶数は飛ばし、4 で終わるので、1 と 3 だけが出ます。

Q: 止まらなくなったプログラムを止めるキーは何ですか。
A: Ctrl+C | Ctrl + C | Ctrl C
E: 無限ループのときに使います。
```
