# 2. 基本的な文法

## プログラムの形

```cpp
#include <iostream>      // 画面に出す機能（cout）を使えるようにする
using namespace std;     // std::cout を cout と書けるようにする

int main()               // プログラムはここから始まる
{
    cout << "こんにちは\n";
    cout << "C++ を始めます\n";
    return 0;            // 0 を返して終わる（正常に終わった、の意味）
}
```

| 決まり | 説明 |
| --- | --- |
| `main` 関数 | プログラムは必ず `main` から始まる。1つのプログラムに1つだけ |
| 文 | 1つの処理の単位。**最後に `;`** を付ける |
| ブロック | `{` から `}` まで。文をまとめる |
| 大文字と小文字 | 区別する。`Main` と `main` は別もの |
| 空白・改行 | 単語の区切り以外では自由。読みやすく字下げ（インデント）する |

### コメント

コンパイラに読まれない、人のためのメモです。

```cpp
// 1 行のコメント（行の終わりまで）
/* 何行にも
   わたるコメント */
```

### using namespace std

`cout` は、本当は `std::cout`（`std` という名前空間の中の `cout`）です。`using namespace std;` と書くと `std::` を省けます。短いプログラムでは便利ですが、大きなプログラムでは名前がぶつかることがあるので、`std::cout` と書くことも多いです。

## 画面に出す（cout）

```cpp
cout << "合計は" << 10 + 5 << "です。\n";   // 合計は15です。
cout << 3.14 << endl;                       // endl でも改行できる
```

- `<<` で、出したいものを順につなぐ
- 改行は `"\n"` か `endl`。`endl` は改行に加えて、出力をすぐ画面に出す（少し遅い）

## リテラル

プログラムに直接書いた値を**リテラル**といいます。

| 種類 | 書き方 | 例 |
| --- | --- | --- |
| 文字リテラル | 1文字を `'` で囲む | `'A'`、`'1'` |
| 文字列リテラル | 文字の並びを `"` で囲む | `"Hello"`、`"123"` |
| 整数リテラル | 10進・8進（`0` で始める）・16進（`0x` で始める）・2進（`0b`） | `10`、`012`、`0xA`、`0b1010`（全部 10） |
| 浮動小数点リテラル | 小数点や指数を使う | `3.14`、`1.5e3`（1500） |

> `'1'` は文字、`1` は数、`"1"` は文字列で、それぞれ別ものです。日本語のような1バイトでない文字は、`'あ'` ではなく `"あ"` と文字列で書きます。

### エスケープシーケンス

キーボードから直接書けない文字は、`\` を付けて表します。

| 書き方 | 意味 |
| --- | --- |
| `\n` | 改行 |
| `\t` | タブ |
| `\\` | `\` そのもの |
| `\'` | `'` |
| `\"` | `"` |
| `\0` | 文字列の終わりの印（9章） |

```cpp
cout << "名前\t点数\n";
cout << "\"C++\" を学ぶ\n";     // "C++" を学ぶ
```

## まとめ

- プログラムは `main` 関数から始まる。文の終わりは `;`、ブロックは `{ }`
- `cout << 値` で画面に出す。改行は `"\n"`
- 文字は `'A'`、文字列は `"ABC"`。`\n` などのエスケープシーケンスで特別な文字を書く

## 練習問題

```quiz
Q: C++ のプログラムは、どの関数から始まりますか。
A: main | main()
E: `int main() { … }` の中から動き始めます。

Q: C++ で、文の終わりに付ける記号は何ですか。
A: ; | セミコロン
E: ブロックは `{ }` で囲みます。

Q: 次のコードは何を表示しますか。
| cout << "A" << 1 + 2 << "B";
A: A3B
E: `1 + 2` は計算されて 3 になります。

Q: 文字列の中で改行を表すエスケープシーケンスは何ですか。
A: \n
E: タブは `\t`、`"` は `\"` と書きます。
```
