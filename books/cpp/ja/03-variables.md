# 3. 変数と型

## 変数

値を入れておく箱を**変数**といいます。C++ では、使う前に**型**（入れる値の種類）と名前を決めます（**宣言**）。

```cpp
int num;          // 宣言: 整数を入れる変数 num を作る
num = 3;          // 代入: num に 3 を入れる
int count = 10;   // 初期化: 作るときに値を入れる
num = count;      // ほかの変数の値を入れる（num は 10 になる）
```

- `=` は「等しい」ではなく、「右の値を左の変数に入れる」の意味
- 初期化していない変数の値は決まっていない（何が入っているかわからない）。作るときに初期化する

### 名前（識別子）の決まり

- 使えるのは、英字・数字・`_`（アンダースコア）
- 数字で始められない（`1st` はだめ、`first1` はよい）
- `int` や `return` のような**キーワード**は使えない
- 大文字と小文字は区別する（`num` と `Num` は別の変数）

## 型

| 型 | 入るもの | 大きさの目安 | 範囲の目安 |
| --- | --- | --- | --- |
| `bool` | 真偽（`true` / `false`） | 1 バイト | |
| `char` | 1文字（1 バイト） | 1 バイト | −128〜127 |
| `short` | 整数 | 2 バイト | −32768〜32767 |
| `int` | 整数（ふつうはこれ） | 4 バイト | 約 ±21 億 |
| `long long` | 大きな整数 | 8 バイト | 約 ±922 京 |
| `float` | 小数（単精度） | 4 バイト | 有効数字 約 7 けた |
| `double` | 小数（倍精度。ふつうはこれ） | 8 バイト | 有効数字 約 15 けた |

- `unsigned int` のように `unsigned` を付けると、0 以上だけになる代わりに、正の範囲が倍になる
- 大きさは環境で変わることがある。`sizeof(int)` で確かめられる

```cpp
cout << "int は " << sizeof(int) << " バイト\n";       // int は 4 バイト
```

### const と auto

```cpp
const double PI = 3.14159;   // const: あとで変えられない（変えようとするとエラー）
auto n = 10;                 // auto: 右の値から型を決めてもらう（int になる）
auto x = 2.5;                // double になる
```

## キーボードから入力する（cin）

```cpp
#include <iostream>
using namespace std;

int main()
{
    int num = 0;
    cout << "整数を入力してください。\n";
    cin >> num;
    cout << num << "が入力されました。\n";
    return 0;
}
```

- `cin >> 変数` で、キーボードから入力した値を変数に入れる（`>>` の向きに注意。`cout` は `<<`）
- `cin >> a >> b;` で、空白で区切った2つの値を続けて入れられる

## まとめ

- 変数は「型 名前 = 初期値;」で作る。初期化しておく
- 整数は `int`、小数は `double`、真偽は `bool`、1文字は `char`
- 変えない値は `const`。`cin >> 変数` で入力する

## 練習問題

```quiz
Q: 小数を入れる変数の型として、この本で使っているものは何ですか。
A: double
E: 整数は `int`、真偽は `bool`、1文字は `char` です。

Q: あとから変えない値にする、型の前に付けるキーワードは何ですか。
A: const
E: `const int MAX = 100;` のように書きます。

Q: キーボードから値を入力して変数に入れるときに使うものは何ですか（`??? >> x;`）。
A: cin
E: 画面に出すのは `cout` です。

Q: 初期値から型を自動で決めるキーワードは何ですか。
A: auto
E: `auto x = 3.5;` なら x は double になります。
```
