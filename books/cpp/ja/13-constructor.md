# 13. コンストラクタと静的メンバ

## コンストラクタ

オブジェクトを作るときに、自動で呼ばれる関数です。メンバの初期化に使います。

- 名前はクラス名と同じ
- 戻り値の型を書かない（`void` も書かない）

```cpp
class Car {
private:
    int num;
    double gas;

public:
    Car();                     // 引数なしのコンストラクタ
    Car(int n, double g);      // 引数ありのコンストラクタ（オーバーロード）
    void show() const;
};

Car::Car() : num(0), gas(0.0)  // : のあとが初期化リスト
{
    cout << "車を作成しました。\n";
}

Car::Car(int n, double g) : num(n), gas(g)
{
    cout << "ナンバー" << num << "、ガソリン量" << gas << "の車を作成しました。\n";
}

void Car::show() const
{
    cout << "ナンバーは" << num << "、ガソリン量は" << gas << "です。\n";
}

int main()
{
    Car car1;                 // 引数なしのコンストラクタが呼ばれる
    Car car2(1234, 20.5);     // 引数ありのコンストラクタが呼ばれる
    car1.show();
    car2.show();
    return 0;
}
```

- 引数の型と数で、どのコンストラクタを呼ぶかが決まる（7章のオーバーロードと同じ）
- **初期化リスト**（`: num(n), gas(g)`）は、メンバを作るときに値を入れる。ブロックの中で代入するより、こちらがふつう。`const` のメンバや参照のメンバは、初期化リストでしか値を入れられない
- コンストラクタを1つも書かないと、何もしない引数なしのコンストラクタが自動で作られる。引数ありを1つでも書くと、引数なしは作られない（`Car car1;` がエラーになる）
- `Car(int n = 0, double g = 0.0);` のように、デフォルト引数で1つにまとめることもできる

## デストラクタ

オブジェクトが消えるときに、自動で呼ばれる関数です。借りたメモリを返すなどの後片付けに使います。

- 名前は `~クラス名`。引数も戻り値もない

```cpp
class Car {
public:
    Car()  { cout << "作りました\n"; }
    ~Car() { cout << "片付けました\n"; }
};

int main()
{
    Car car1;           // 作りました
    {
        Car car2;       // 作りました
    }                   // ブロックを出て car2 が消える: 片付けました
    return 0;
}                       // car1 が消える: 片付けました
```

## オブジェクトの配列

```cpp
Car cars[3];                          // 引数なしのコンストラクタが 3 回呼ばれる
Car cars2[2] = {Car(1234, 20.5), Car(4567, 30.0)};
cars2[1].show();
```

## 静的メンバ

ふつうのメンバ変数は、オブジェクトごとに別々です。`static` を付けたメンバは、**全部のオブジェクトで1つだけ**を共有します。クラスそのものに付いたデータです。

```cpp
class Car {
private:
    int num;
    double gas;

public:
    static int sum;                  // 静的メンバ変数: 作った車の数
    Car(int n, double g);
    static void showSum();           // 静的メンバ関数
};

int Car::sum = 0;                    // 静的メンバ変数は、クラスの外で定義する

Car::Car(int n, double g) : num(n), gas(g)
{
    sum++;                           // 車を作るたびに 1 増やす
}

void Car::showSum()
{
    cout << "車は全部で" << sum << "台あります。\n";
}

int main()
{
    Car::showSum();                  // 車は全部で0台あります。
    Car car1(1234, 20.5);
    Car::showSum();                  // 車は全部で1台あります。
    Car car2(4567, 30.0);
    Car::showSum();                  // 車は全部で2台あります。
    return 0;
}
```

- 静的メンバは、オブジェクトを作らなくても `クラス名::名前` で使える
- 静的メンバ関数の中では、ふつうのメンバ（`num`、`gas`）は使えない（どのオブジェクトのものかわからないため）
- C++17 からは、クラスの中で `inline static int sum = 0;` と書けば、外の定義はいらない

## this ポインタ

メンバ関数の中で、**呼ばれたオブジェクト自身**を指すポインタが `this` です。引数とメンバの名前が同じときなどに使います。

```cpp
void Car::setNum(int num)
{
    this->num = num;      // 左はメンバ、右は引数
}
```

## まとめ

- コンストラクタはクラス名と同じ名前で、戻り値なし。初期化リストでメンバを初期化する
- デストラクタは `~クラス名`。消えるときに後片付けをする
- `static` のメンバは全部のオブジェクトで共有し、`クラス名::名前` で使う
- `this` は自分自身を指すポインタ

Q: 次のプログラムは何を表示しますか。
| class A {

|     A a;

A: 132 | 1 3 2
E: 作るときにコンストラクタ（1）、main の終わりでデストラクタ（2）が動きます。

Q: 全部のオブジェクトで共有するメンバに付けるキーワードは何ですか。
A: static
E: `クラス名::名前` で使います。

Q: メンバ関数の中で、自分自身を指すポインタは何ですか。
