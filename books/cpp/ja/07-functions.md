# 7. 関数

## 関数とは

いくつかの処理をまとめて名前を付けたものを**関数**といいます。同じ処理を何度も書かずにすみ、プログラムが読みやすくなります。

```cpp
#include <iostream>
using namespace std;

// 関数の定義
void buy()
{
    cout << "車を買いました。\n";
}

int main()
{
    buy();          // 関数の呼び出し
    cout << "もう1台買います。\n";
    buy();          // 何度でも呼べる
    return 0;
}
```

呼び出すと関数の中に入り、終わると呼んだ所にもどってきます。

## 引数と戻り値

| 言葉 | 意味 |
| --- | --- |
| 引数（ひきすう） | 関数に渡す値。定義の側の変数を**仮引数**、呼ぶ側で渡す値を**実引数**という |
| 戻り値 | 関数が返す値。`return 値;` で返す。返さない関数の型は `void` |

```cpp
int sum(int x, int y)      // int を2つ受け取り、int を返す
{
    return x + y;
}

int main()
{
    int ans = sum(5, 10);  // 15
    cout << "合計は" << ans << "です。\n";
    return 0;
}
```

- `return` すると、そこで関数は終わる
- 戻り値は1つだけ。たくさん返したいときは、構造体（11章）や参照（8章）を使う

## 関数の宣言（プロトタイプ）

関数は、使う前に定義か**宣言**が要ります。`main` の後ろに定義を書きたいときは、前に宣言だけを書きます。

```cpp
int sum(int x, int y);     // 宣言（プロトタイプ）。; で終わる

int main()
{
    cout << sum(5, 10) << "\n";
    return 0;
}

int sum(int x, int y)      // 定義
{
    return x + y;
}
```

宣言はふつう、ヘッダファイル（10章）にまとめます。

## 値渡し

ふつうの引数は、値の**コピー**が渡されます（**値渡し**）。関数の中で引数を変えても、呼んだ側の変数は変わりません。

```cpp
void swap(int x, int y)
{
    int tmp = x;
    x = y;
    y = tmp;          // x と y を入れかえた…が、コピーを入れかえただけ
}

int main()
{
    int a = 1, b = 5;
    swap(a, b);
    cout << a << " " << b << "\n";    // 1 5（入れかわらない）
    return 0;
}
```

入れかえるには、ポインタか参照を使います（8章）。

## デフォルト引数

引数を省いたときに使う値を決めておけます。デフォルト引数は**後ろの引数から**付けます。

```cpp
double area(double width, double height = 1.0)
{
    return width * height;
}

area(3.0, 2.0);    // 6
area(3.0);         // 3（height は 1.0）
```

## オーバーロード

引数の**型か数**がちがえば、同じ名前の関数をいくつも作れます（**オーバーロード**）。

```cpp
int maxOf(int x, int y)          { return (x > y) ? x : y; }
double maxOf(double x, double y) { return (x > y) ? x : y; }
int maxOf(int x, int y, int z)   { return maxOf(maxOf(x, y), z); }

maxOf(3, 8);         // int 版
maxOf(2.5, 1.5);     // double 版
maxOf(3, 8, 5);      // 3 つの引数の版
```

> **戻り値の型だけ**がちがう関数は、オーバーロードできません（`int f(int)` と `double f(int)` は、呼ぶ側でどちらか決められないのでエラー）。

## インライン関数

`inline` を付けた関数は、呼び出しの所に中身を展開するよう、コンパイラにたのめます。小さな関数を速くするためのものですが、今のコンパイラは付けなくても自分で判断します。

## まとめ

- 関数は「戻り値の型 名前(引数) { 処理 }」。返さないときは `void`
- 使う前に宣言（プロトタイプ）が要る
- ふつうの引数はコピー（値渡し）。デフォルト引数は後ろから
- オーバーロードは引数の型か数でちがいを付ける。戻り値の型だけではだめ

## 練習問題

```quiz
Q: 値を返さない関数の戻り値の型は何ですか。
A: void
E: `void hello() { … }` のように書きます。

Q: 次のプログラムは何を表示しますか。
| void twice(int x) { x = x * 2; }
| int main() {
|     int a = 5;
|     twice(a);
|     cout << a;
| }
A: 5
E: ふつうの引数はコピー（値渡し）なので、関数の中で変えても a は変わりません。

Q: 次のプログラムは何を表示しますか。
| int add(int a, int b = 10) { return a + b; }
| int main() { cout << add(3) << " " << add(3, 4); }
A: 13 7
E: b を省くと、デフォルトの 10 が使われます。

Q: 同じ名前で、引数の型や数がちがう関数をいくつも作ることを何といいますか。
A: オーバーロード | 多重定義 | overload | overloading
E: 戻り値の型だけがちがうものは作れません。
```
