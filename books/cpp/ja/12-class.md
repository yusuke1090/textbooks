# 12. クラスの基本

## この章でわかること

- クラスとオブジェクト（インスタンス）
- メンバ変数とメンバ関数
- public と private（カプセル化）

## クラスとは

**クラス**は、データ（**メンバ変数**）と、そのデータを使う機能（**メンバ関数**）をまとめた型です。「車」というクラスなら、ナンバーやガソリンの量がデータ、「表示する」「給油する」が機能です。

クラスを使ってプログラムを組み立てる考え方を、**オブジェクト指向**といいます。

## クラスを宣言する

```cpp
class Car {
public:
    int num;           // メンバ変数
    double gas;

    void show();       // メンバ関数の宣言
};                     // 最後の ; を忘れない

// メンバ関数の定義（クラス名:: を付ける）
void Car::show()
{
    cout << "ナンバーは" << num << "です。\n";
    cout << "ガソリン量は" << gas << "です。\n";
}
```

- `Car::show` の `::` は、「Car クラスの show」という意味
- メンバ関数の中では、同じオブジェクトのメンバ変数をそのまま（`num`、`gas`）使える

## オブジェクトを作る

クラスは「設計図」です。設計図から作った実体を**オブジェクト**（**インスタンス**）といいます。1つのクラスから、オブジェクトをいくつも作れます。

```cpp
int main()
{
    Car car1;              // Car クラスのオブジェクト car1 を作る
    car1.num = 1234;
    car1.gas = 25.5;
    car1.show();           // メンバ関数を呼ぶ

    Car car2;              // 別のオブジェクト（データは car1 と別々）
    car2.num = 4567;
    car2.gas = 30.0;
    car2.show();
    return 0;
}
```

## public と private

メンバに、外から使えるかどうかを決められます。

| 指定 | 使える所 |
| --- | --- |
| `public` | どこからでも |
| `private` | そのクラスのメンバ関数の中だけ（外からはエラー） |

データは `private` にして、`public` のメンバ関数を通してだけ変えられるようにするのがふつうです（**カプセル化**）。おかしな値が入るのを防げます。

```cpp
class Car {
private:
    int num;
    double gas;

public:
    void setNumGas(int n, double g);
    void show();
};

void Car::setNumGas(int n, double g)
{
    if (g > 0 && g < 1000) {       // ありえる値だけ受け付ける
        num = n;
        gas = g;
        cout << "ナンバーを" << num << "に、ガソリン量を" << gas << "にしました。\n";
    } else {
        cout << g << "は正しいガソリン量ではありません。\n";
    }
}

void Car::show()
{
    cout << "ナンバーは" << num << "、ガソリン量は" << gas << "です。\n";
}

int main()
{
    Car car1;
    // car1.gas = -10;            // エラー（private なので外から触れない）
    car1.setNumGas(1234, 20.5);
    car1.show();
    car1.setNumGas(1234, -10);    // 受け付けない
    return 0;
}
```

> `class` は何も書かないと `private`、`struct` は `public` になります。ちがいはそれだけで、`struct` にもメンバ関数を書けます。

## const メンバ関数

メンバ変数を変えないメンバ関数には、後ろに `const` を付けます。`const` のオブジェクトからも呼べるようになり、まちがって変えるとエラーで教えてくれます。

```cpp
class Car {
    // …
public:
    double getGas() const { return gas; }    // クラスの中に定義も書ける
};
```

## まとめ

- クラスは、データ（メンバ変数）と機能（メンバ関数）をまとめた型。宣言は `};` で終わる
- オブジェクトは、クラスから作った実体（インスタンス）。クラスの中の変数のことではない
- メンバ関数の定義は `クラス名::関数名`
- データは `private`、使う関数は `public`（カプセル化）
