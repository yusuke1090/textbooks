# 10. 大きなプログラム（スコープ・動的メモリ・ファイル分割）

## スコープ

変数が使える範囲を**スコープ**といいます。

| 変数 | 作る場所 | 使える範囲 |
| --- | --- | --- |
| ローカル変数 | 関数やブロック `{ }` の中 | そのブロックの中だけ |
| グローバル変数 | 関数の外 | ファイルのどこからでも |

```cpp
int a = 0;            // グローバル変数

void func()
{
    int a = 10;       // ローカル変数（グローバルの a とは別もの）
    cout << a << "\n";       // 10（近いほうが使われる）
    cout << ::a << "\n";     // 0（:: でグローバルの a）
}
```

- 名前が同じなら、内側（ローカル）の変数が優先される。`::`（**スコープ解決演算子**）を付けるとグローバルのものを指す
- グローバル変数はどこからでも変えられるので、まちがいを見つけにくい。なるべく引数と戻り値で渡す

## 記憶寿命

| 変数 | 生きている期間 |
| --- | --- |
| ローカル変数 | ブロックに入ったときに作られ、出ると消える |
| `static` を付けたローカル変数 | 最初に通ったときに1回だけ初期化され、プログラムの終わりまで残る |
| グローバル変数 | プログラムの始めから終わりまで |

```cpp
void count()
{
    static int n = 0;    // 1回だけ 0 にする
    n++;
    cout << n << "回目の呼び出し\n";
}
// count(); count(); count(); → 1回目、2回目、3回目
```

## 動的なメモリ

配列の大きさは、ふつうコンパイルのときに決まっていなければなりません。実行してからの入力で大きさを決めたいときは、`new` でメモリを借ります（**動的なメモリの確保**）。

```cpp
int num = 0;
cout << "何人分の点数を入れますか？\n";
cin >> num;

int* pT = new int[num];          // int を num 個分、借りる
for (int i = 0; i < num; i++) {
    cin >> pT[i];
}
// …使う…
delete[] pT;                     // 返す（配列は delete[]）
```

| 借りる | 返す |
| --- | --- |
| `int* p = new int;` | `delete p;` |
| `int* p = new int[n];` | `delete[] p;` |

- 返し忘れると、使えないメモリがたまっていく（**メモリリーク**）
- 返したあとのポインタを使うと、落ちたりおかしな値になったりする

今の C++ では、`new` と `delete` を直接書くことは少なくなりました。配列なら `std::vector`（9章）、1つのものなら `std::unique_ptr`（`#include <memory>`）を使えば、自動で返されます。

```cpp
vector<int> t(num);              // num 個の int。ブロックを出ると自動で返される
auto p = make_unique<int>(5);    // ブロックを出ると自動で delete される
```

## ファイルを分ける

大きなプログラムは、役割ごとにファイルを分けます。

| ファイル | 書くこと |
| --- | --- |
| ヘッダファイル（`.h`） | 関数の宣言（プロトタイプ）、クラスの宣言 |
| ソースファイル（`.cpp`） | 関数の定義、`main` |

`myfunc.h`:

```cpp
#pragma once           // このヘッダを2回読みこまないようにする（インクルードガード）

int maxOf(int x, int y);
```

`myfunc.cpp`:

```cpp
#include "myfunc.h"

int maxOf(int x, int y)
{
    return (x > y) ? x : y;
}
```

`main.cpp`:

```cpp
#include <iostream>
#include "myfunc.h"    // 自分のヘッダは " " で囲む（標準のものは < >）
using namespace std;

int main()
{
    cout << maxOf(3, 8) << "\n";
    return 0;
}
```

コンパイルするときは、`.cpp` を全部並べます（`.h` は書かない）。

```bash
g++ -std=c++17 -Wall -o app main.cpp myfunc.cpp
./app
```

- `#pragma once` の代わりに、`#ifndef MYFUNC_H` / `#define MYFUNC_H` / `#endif` で囲む書き方もある
- ほかのファイルのグローバル変数を使うときは、`extern int count;` と宣言する
- ファイルが増えたら、CMake などのビルドの道具を使う（ラズパイピコ開発ガイドの教科書でも使います）

## 名前空間

名前がぶつからないように、名前をグループに入れておけます。

```cpp
namespace farm {
    int count = 0;
    void hello() { cout << "farm の hello\n"; }
}

farm::hello();          // 名前空間名::名前 で使う
```

`std::cout` の `std` も名前空間です。

## まとめ

- ローカル変数はブロックの中だけ。`::` でグローバルを指す。`static` のローカル変数は値が残る
- `new` で借りたら `delete`（配列は `delete[]`）。今は `vector` や `unique_ptr` を使う
- 宣言はヘッダ（`.h`）、定義はソース（`.cpp`）。`g++` には `.cpp` を全部渡す

## 練習問題

```quiz
Q: 次のプログラムは何を表示しますか。
| void count() {
|     static int n = 0;
|     n++;
|     cout << n;
| }
| int main() { count(); count(); count(); }
A: 123 | 1 2 3
E: `static` のローカル変数は、関数を抜けても値が残ります。

Q: `new` で借りた配列のメモリを返すときに使うものは何ですか。
A: delete[] | delete []
E: 1つだけなら `delete` です。今は `vector` や `unique_ptr` を使います。

Q: 関数の宣言を書くヘッダファイルの拡張子は何ですか。
A: .h | h | .hpp
E: 定義はソース（`.cpp`）に書き、`g++` には `.cpp` を全部渡します。

Q: 名前の前に付けて、グローバルの変数を指す記号は何ですか。
A: ::
E: `::x` と書くと、同じ名前のローカル変数ではなくグローバルの x になります。
```
