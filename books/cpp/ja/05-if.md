# 5. 条件分岐

## if 文

条件が `true` のときだけ、ブロックの中を実行します。

```cpp
int res = 0;
cout << "整数を入力してください。\n";
cin >> res;

if (res == 1) {
    cout << "1が入力されました。\n";
}
cout << "処理を終わります。\n";
```

> `if (res = 1)` と書くと、比べるのではなく 1 を**代入**してしまい、いつも true になります。比べるのは `==` です（`-Wall` を付けると警告が出ます）。

## if else 文

条件が `false` のときにすることも書けます。

```cpp
if (res == 1) {
    cout << "1が入力されました。\n";
} else {
    cout << "1以外が入力されました。\n";
}
```

## else if（3つ以上に分ける）

```cpp
int score = 0;
cin >> score;

if (score >= 80) {
    cout << "A\n";
} else if (score >= 60) {
    cout << "B\n";
} else {
    cout << "C\n";
}
```

上から順に調べ、最初に当てはまったものだけを実行します。

## 論理演算子で条件を組み合わせる

```cpp
if (score >= 0 && score <= 100) {
    cout << "正しい点数です。\n";
}
if (score < 0 || score > 100) {
    cout << "点数がおかしいです。\n";
}
```

## switch 文

1つの値で、たくさんに分けるときに使います。

```cpp
int res = 0;
cin >> res;

switch (res) {
case 1:
    cout << "1が入力されました。\n";
    break;
case 2:
    cout << "2が入力されました。\n";
    break;
default:
    cout << "1か2を入力してください。\n";
    break;
}
```

- `case 値:` の後ろは **`:`（コロン）**
- `break` で switch から出る。`break` を忘れると、**次の case の中まで続けて実行**してしまう
- どの case にも当てはまらないときは `default` を実行する
- `case` に書けるのは、整数や文字（`'a'`）のような決まった値だけ。範囲（60 以上など）は if を使う

## 条件演算子

`条件 ? 真のときの値 : 偽のときの値` で、2つのうちどちらかの値を選びます。

```cpp
int a = 5, b = 8;
int big = (a > b) ? a : b;     // 8
cout << (score >= 60 ? "合格" : "不合格") << "\n";
```

短い選び方に便利ですが、入れ子にすると読みにくいので、そのときは if を使います。

## まとめ

- `if (条件) { } else if (条件) { } else { }`。比べるのは `==`
- `switch` は `case 値:` と `break`。`break` を忘れると次に続く
- `条件 ? A : B` で値を選ぶ

## 練習問題

```quiz
Q: 次のコードは何を表示しますか。
| int t = 25;
| if (t >= 30) cout << "hot";
| else if (t >= 20) cout << "warm";
| else cout << "cool";
A: warm
E: 上から順に調べて、最初に当てはまった所だけを動かします。

Q: 次のコードは何を表示しますか。
| int n = 2;
| switch (n) {
|     case 1: cout << "a";
|     case 2: cout << "b";
|     case 3: cout << "c";
| }
A: bc
E: `break` がないので、case 2 から下へ続けて動きます。

Q: 次のコードは何を表示しますか。
| int x = 7;
| cout << (x % 2 == 0 ? "even" : "odd");
A: odd
E: `条件 ? A : B` は、条件が真なら A、偽なら B です。
```
