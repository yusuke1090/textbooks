# 8. ポインタと参照

## この章でわかること

- アドレスとポインタ（`&` と `*`）
- ポインタを引数にして、呼んだ側の変数を変える
- 参照と参照渡し

## アドレス

変数は、メモリのどこかに置かれています。その場所の番号を**アドレス**といいます。変数の前に `&`（**アドレス演算子**）を付けると、アドレスがわかります。

```cpp
int a = 5;
cout << "変数 a の値は" << a << "です。\n";
cout << "変数 a のアドレスは" << &a << "です。\n";   // 0x7ffd... のような 16 進数
```

アドレスは、実行するたびに変わることがあります。

## ポインタ

アドレスを入れておく変数を**ポインタ**といいます。

```cpp
int a = 5;
int* pA;          // int を指すポインタ pA を宣言（int *pA; とも書く）
pA = &a;          // a のアドレスを入れる（pA は a を指す）

cout << pA << "\n";     // a のアドレス
cout << *pA << "\n";    // 5（pA が指す先の値）

*pA = 50;               // 指す先に 50 を入れる
cout << a << "\n";      // 50（a が変わる）
```

| 書き方 | 意味 |
| --- | --- |
| `int* p;` | 宣言のときの `*` は「ポインタの型」 |
| `&a` | a のアドレス（アドレス演算子） |
| `*p` | p が指す先の値（**間接参照演算子**） |

- 何も指していないことを表すには `nullptr` を入れる（`int* p = nullptr;`）
- 初期化していないポインタや `nullptr` に `*` を付けると、プログラムが落ちる

## ポインタを引数にする

7章の `swap` は、コピーを入れかえていたので、呼んだ側は変わりませんでした。**アドレス**を渡せば、呼んだ側の変数を変えられます。

```cpp
void swap(int* pX, int* pY)
{
    int tmp = *pX;    // 指す先の値を取っておく
    *pX = *pY;
    *pY = tmp;
}

int main()
{
    int num1 = 5, num2 = 10;
    swap(&num1, &num2);                     // アドレスを渡す
    cout << num1 << " " << num2 << "\n";    // 10 5（入れかわった）
    return 0;
}
```

## 参照

**参照**は、変数の「別名」です。宣言のときに `&` を付け、必ず初期化します。

```cpp
int a = 5;
int& rA = a;      // rA は a の別名
rA = 50;
cout << a << "\n";    // 50
```

- 宣言のときの `&` は「参照の型」、式の中の `&a` は「アドレス」。同じ記号で意味がちがう
- 一度決めた参照は、ほかの変数の別名に変えられない

### 参照渡し

引数を参照にすると、`*` や `&` を書かずに、呼んだ側の変数を変えられます（**参照渡し**）。

```cpp
void swap(int& x, int& y)
{
    int tmp = x;
    x = y;
    y = tmp;
}

int main()
{
    int num1 = 5, num2 = 10;
    swap(num1, num2);                       // そのまま渡す
    cout << num1 << " " << num2 << "\n";    // 10 5
    return 0;
}
```

### const 参照

大きなデータ（文字列や構造体）を値渡しすると、コピーに時間がかかります。変えないなら `const` の参照で渡すと、コピーせずに、しかも変えられないようにできます。

```cpp
void show(const string& name)     // コピーしない。中で name を変えるとエラー
{
    cout << name << "\n";
}
```

## ポインタと参照の使い分け

| | ポインタ | 参照 |
| --- | --- | --- |
| 何も指さない | `nullptr` にできる | できない（必ず何かの別名） |
| 指す先を変える | できる | できない |
| 書き方 | `*p`、`&a` が要る | ふつうの変数と同じ |
| 主な使い道 | 配列（9章）、動的メモリ（10章） | 関数の引数（特に `const` 参照） |

## まとめ

- `&a` でアドレス、`int* p = &a;` でポインタ、`*p` で指す先の値
- アドレスか参照を渡せば、関数の中から呼んだ側の変数を変えられる
- 変えない大きな引数は `const 型&` で渡す

## 練習問題

```quiz
Q: 変数 a のアドレスを取り出す書き方は何ですか。
A: &a
E: `int* p = &a;` で、p は a を指すポインタになります。

Q: 次のコードは何を表示しますか。
| int a = 3;
| int* p = &a;
| *p = 8;
| cout << a;
A: 8
E: `*p` は p が指す先、つまり a そのものです。

Q: 次のプログラムは何を表示しますか。
| void twice(int& x) { x = x * 2; }
| int main() {
|     int a = 5;
|     twice(a);
|     cout << a;
| }
A: 10
E: 参照渡し（`int&`）なので、呼んだ側の a が変わります。

Q: 変えない大きな引数を、コピーせずに渡す書き方は何ですか（`string` の場合）。
A: const string& | const std::string& | const string &
E: `const 型&` で渡すと、コピーせず、中で変えることもできません。
```
