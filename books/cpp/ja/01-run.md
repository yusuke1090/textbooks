# 1. プログラムを実行する

この教科書は、『やさしいC++ 第5版』（高橋麻奈 著、SB クリエイティブ）を読んでまとめた [学習ノート](https://note.com/k_1090/n/n9ca36fcc9a8a) をもとにしています。ノートの誤りは直し、今の C++ でよく使う書き方（`std::string`・`std::vector` など）も少し足しています。

## プログラムが動くまで

コンピュータが直接わかるのは、0 と 1 の並び（**機械語**）だけです。人が読める C++ の文章（**ソースコード**）を書き、それを機械語に直してから動かします。

| 順番 | すること | できるもの |
| --- | --- | --- |
| 1 | エディタでソースコードを書く | ソースファイル（`hello.cpp`） |
| 2 | **コンパイラ**で機械語に直す（コンパイル） | オブジェクトファイル（`hello.o`） |
| 3 | **リンカ**で、使った部品（ライブラリ）とつなぐ（リンク） | 実行ファイル（`hello`、Windows では `hello.exe`） |
| 4 | 実行する | 画面に結果が出る |

2 と 3 は、ふつう1つのコマンド（`g++`）でまとめてします。この流れ全体を**ビルド**といいます。

> Python は、書いたものをそのつど読んで動かします（インタプリタ）。C++ は先に機械語にしておくので、速く動きます。その代わり、書き直したら毎回コンパイルし直します。

## 準備（Ubuntu・VS Code）

### コンパイラを入れる

```bash
sudo apt update
sudo apt install g++
g++ --version          # バージョンが出れば OK
```

### VS Code を開く

1. 勉強用のフォルダを作って、VS Code で開く

   ```bash
   mkdir -p ~/apps/cpp-study
   cd ~/apps/cpp-study
   code .
   ```

2. 左の拡張機能（四角が4つのアイコン）で「C/C++」（Microsoft）を入れる。色分け・入力の補完・エラーの下線が出るようになる
3. **Ctrl + `**（バッククォート）で、下にターミナルを出す。コンパイルと実行はここでする

## 最初のプログラム

VS Code で `hello.cpp` を作り、次のように書いて保存します（Ctrl + S）。

```cpp
#include <iostream>
using namespace std;

int main()
{
    cout << "ようこそC++！\n";
    return 0;
}
```

ターミナルでコンパイルして、実行します。

```bash
g++ -std=c++17 -Wall -o hello hello.cpp
./hello
```

```text
ようこそC++！
```

| 部分 | 意味 |
| --- | --- |
| `g++` | C++ のコンパイラ |
| `-std=c++17` | C++17 の決まりでコンパイルする |
| `-Wall` | 間違えやすい書き方に警告を出す（付けておく） |
| `-o hello` | できる実行ファイルの名前（付けないと `a.out`） |
| `./hello` | 今いるフォルダ（`./`）の `hello` を実行する |

## エラーが出たら

コンパイルに失敗すると、ファイル名・行番号・理由が出ます。

```text
hello.cpp:6:28: error: expected ';' before 'return'
```

- `hello.cpp` の **6 行目 28 文字目**あたりで、`;` が足りないという意味
- 実際の誤りは、その行か、**1つ前の行**にあることが多い
- エラーがたくさん出たら、**一番上**から直す。1つ直すと、ほかも消えることが多い
- `warning`（警告）はコンパイルできるが、まちがいのもと。これも直す

## Visual Studio（Windows）の場合

元の本は Windows の Visual Studio を使っています。

1. 「新しいプロジェクトの作成」→「空のプロジェクト」を選ぶ
2. ソリューションエクスプローラーの「ソースファイル」を右クリック →「追加」→「新しい項目」→「C++ ファイル」
3. コードを書いて、**Ctrl + F5**（デバッグなしで開始）で、コンパイルと実行がまとめてできる

## まとめ

- ソースコードをコンパイル・リンクして、実行ファイルを作ってから動かす
- Ubuntu では `g++ -std=c++17 -Wall -o 名前 ファイル.cpp` でコンパイルし、`./名前` で実行
- エラーは行番号を見て、一番上から直す

## 練習問題

```quiz
Q: ソースコードを、コンピューターが動かせる実行ファイルに変えることを何といいますか（リンクの前の段階）。
A: コンパイル | compile | こんぱいる
E: コンパイル・リンクして実行ファイルを作ってから動かします。

Q: Ubuntu で C++ をコンパイルするコマンドは何ですか。
A: g++ | gpp
E: `g++ -std=c++17 -Wall -o 名前 ファイル.cpp` でコンパイルします。

Q: `g++` で、できる実行ファイルの名前を決めるオプションは何ですか。
A: -o
E: `-o hello` なら `./hello` で実行します。

Q: コンパイルのエラーがたくさん出たら、上と下のどちらから直しますか。
A: 上 | 一番上 | いちばん上 | 上から
E: 最初のエラーが原因で、あとのエラーが続けて出ることが多いからです。
```
