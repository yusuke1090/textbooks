# 4. 演算子

## この章でわかること

- 四則演算と、整数の割り算の注意
- 代入演算子・インクリメント
- 比較・論理演算子と優先順位
- 型の変換（キャスト）

## 式と演算子

`a + 5` のように、値と記号を組み合わせたものを**式**といいます。`+` を**演算子**、`a` や `5` を**オペランド**といいます。

## 算術演算子

| 演算子 | 意味 | 例（`a = 7`、`b = 2`） |
| --- | --- | --- |
| `+` | 足す | `a + b` → 9 |
| `-` | 引く | `a - b` → 5 |
| `*` | かける | `a * b` → 14 |
| `/` | 割る | `a / b` → **3**（整数どうしは小数を切り捨て） |
| `%` | 割った余り | `a % b` → 1 |

> 整数どうしの割り算は、小数点以下が捨てられます。`7 / 2` は 3、`7.0 / 2` は 3.5 です。

## 代入演算子

計算と代入をまとめて書けます。

| 書き方 | 同じ意味 |
| --- | --- |
| `x += 10` | `x = x + 10` |
| `x -= 10` | `x = x - 10` |
| `x *= 10` | `x = x * 10` |
| `x /= 10` | `x = x / 10` |
| `x %= 10` | `x = x % 10` |

```cpp
int x = 30;
x -= 10;
cout << x << "\n";     // 20
```

## インクリメント・デクリメント

`++` は 1 増やし、`--` は 1 減らします。前に付けるか後ろに付けるかで、式の値がちがいます。

```cpp
int a = 1;
int b = ++a;   // 前置: 先に増やしてから使う → a は 2、b は 2
int c = 1;
int d = c++;   // 後置: 使ってから増やす → c は 2、d は 1
```

1行に `++` だけを書くとき（`a++;`）は、どちらでも同じです。

## 比較演算子と論理演算子

比べた結果は、`true`（正しい）か `false`（正しくない）になります。5章の条件分岐で使います。

| 演算子 | 意味 |
| --- | --- |
| `==` | 等しい（`=` は代入なので注意） |
| `!=` | 等しくない |
| `>`、`>=` | より大きい、以上 |
| `<`、`<=` | より小さい、以下 |
| `&&` | かつ（両方が true なら true） |
| `\|\|` | または（どちらかが true なら true） |
| `!` | でない（true と false を入れかえる） |

```cpp
int score = 75;
bool pass = (score >= 60) && (score <= 100);   // true
```

## 優先順位

算数と同じく、`*` や `/` は `+` や `-` より先に計算します。主なものを、先に計算する順に並べます。

| 順 | 演算子 |
| --- | --- |
| 1 | `++` `--`（後置）、`()`（関数の呼び出し） |
| 2 | `++` `--`（前置）、`!`、`-`（符号）、`sizeof` |
| 3 | `*` `/` `%` |
| 4 | `+` `-` |
| 5 | `<<` `>>` |
| 6 | `<` `<=` `>` `>=` |
| 7 | `==` `!=` |
| 8 | `&&` |
| 9 | `\|\|` |
| 10 | `?:`（5章） |
| 11 | `=` `+=` などの代入 |

迷ったら `( )` を付けます。読みやすくもなります。

## 型の変換

### 自動の変換

型のちがう値どうしを計算すると、大きい型にそろえて計算されます（`int + double` は `double`）。大きい型から小さい型に入れると、入りきらない部分が失われます。

```cpp
double d = 3.9;
int i = d;        // 3（小数点以下が捨てられる）
```

### キャスト

型を自分で指定して変えることを**キャスト**といいます。

```cpp
int sum = 7, n = 2;
cout << sum / n << "\n";                          // 3
cout << static_cast<double>(sum) / n << "\n";     // 3.5
cout << (double)sum / n << "\n";                  // 3.5（古い書き方）
```

## まとめ

- `+ - * / %`。整数どうしの `/` は切り捨て
- `x -= 10` は `x = x - 10`。`++` は前置と後置で式の値がちがう
- 等しいは `==`。`&&`（かつ）・`||`（または）・`!`（でない）
- 小数で計算したいときは `static_cast<double>(...)` でキャストする

## 練習問題

```quiz
Q: 次のコードは何を表示しますか。
| cout << 17 / 5 << " " << 17 % 5;
A: 3 2
E: 整数どうしの `/` は切り捨て、`%` は余りです。

Q: 次のコードは何を表示しますか。
| int a = 5;
| int b = a++;
| cout << a << " " << b;
A: 6 5
E: 後置の `a++` は、増やす前の値（5）を式の値にします。

Q: 次のコードは何を表示しますか。
| int x = 100;
| x -= 10;
| x *= 2;
| cout << x;
A: 180
E: (100 − 10) × 2 = 180 です。

Q: 整数どうしの割り算を小数で計算するために使うキャストは何ですか（`???<double>(a)`）。
A: static_cast
E: `static_cast<double>(a) / b` と書きます。
```
