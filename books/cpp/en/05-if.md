# 5. Branching

## What you will learn

- if statements, if else statements and else if
- The switch statement (`case value:` and break)
- The conditional operator (`?:`)

## The if statement

The block runs only when the condition is `true`.

```cpp
int res = 0;
cout << "Please enter an integer.\n";
cin >> res;

if (res == 1) {
    cout << "1 was entered.\n";
}
cout << "Finishing.\n";
```

> If you write `if (res = 1)`, instead of comparing, it **assigns** 1, so it is always true. Comparison is `==` (with `-Wall`, you get a warning).

## The if else statement

You can also write what to do when the condition is `false`.

```cpp
if (res == 1) {
    cout << "1 was entered.\n";
} else {
    cout << "Something other than 1 was entered.\n";
}
```

## else if (splitting into three or more)

```cpp
int score = 0;
cin >> score;

if (score >= 80) {
    cout << "A\n";
} else if (score >= 60) {
    cout << "B\n";
} else {
    cout << "C\n";
}
```

Conditions are checked from the top, and only the first one that matches runs.

## Combining conditions with logical operators

```cpp
if (score >= 0 && score <= 100) {
    cout << "Valid score.\n";
}
if (score < 0 || score > 100) {
    cout << "Invalid score.\n";
}
```

## The switch statement

Use it to branch many ways on one value.

```cpp
int res = 0;
cin >> res;

switch (res) {
case 1:
    cout << "1 was entered.\n";
    break;
case 2:
    cout << "2 was entered.\n";
    break;
default:
    cout << "Please enter 1 or 2.\n";
    break;
}
```

- After `case value` comes **`:` (a colon)**
- `break` leaves the switch. If you forget `break`, it **keeps running into the next case**
- When no case matches, `default` runs
- `case` can only take fixed values such as integers or characters (`'a'`). For ranges (60 or more and so on), use if

## The conditional operator

`condition ? value if true : value if false` chooses one of two values.

```cpp
int a = 5, b = 8;
int big = (a > b) ? a : b;     // 8
cout << (score >= 60 ? "pass" : "fail") << "\n";
```

It is handy for short choices, but nesting it is hard to read, so use if in that case.

## Summary

- `if (condition) { } else if (condition) { } else { }`. Compare with `==`
- `switch` uses `case value:` and `break`. If you forget `break`, it continues into the next case
- Choose a value with `condition ? A : B`
