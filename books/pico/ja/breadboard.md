# 7. 道具の使い方

部品をピコにつなぐための道具の使い方です。8章の外付けの LED から使います。

## 用意するもの

| 部品 | 説明 |
| --- | --- |
| ブレッドボード | 穴に差すだけで配線できる板。はんだ付け不要 |
| ジャンパーワイヤー | ブレッドボードの穴どうしや、モジュールのピンをつなぐ線 |
| ピンヘッダ | ピコやセンサー基板に付けて、ブレッドボードに差せるようにする（はんだ付けが必要なことが多い） |
| 抵抗 | 電気の流れをおさえる部品。LED と一緒につなぐ |

![ブレッドボード（ハーフサイズ）](images/breadboard.jpg)

## ブレッドボードのしくみ

ブレッドボードの穴の下には金属の板が入っていて、決まった穴どうしがつながっています。

![ブレッドボードの中のつながり](images/breadboard.svg)

| 場所 | つながり方 |
| --- | --- |
| 真ん中の a〜e | **縦の5穴**が1本につながっている。f〜j も同じ |
| 真ん中の溝 | 溝の上（a〜e）と下（f〜j）は**つながっていない** |
| 上下の ＋ / − の列 | **横一列**が全部つながっている。電源（3.3V）と GND を配るのに使う |

- ピコは**溝をまたぐように**差します。そうすると、左右のピンがショートしません。USB を右にすると、上の列は左はしが20番で右へ 19、18 … 1番、下の列は左はしが21番で右へ 22、23 … 40番と並びます
- 同じ縦の列（例: 5列の a〜e）に差した部品の足どうしは、線を使わなくてもつながります
- ピコの 3V3(OUT) を ＋ の列に、GND を − の列につないでおくと、センサーの電源を取りやすくなります

![動画: ブレッドボードの使い方（DIY電子工作）](https://www.youtube.com/watch?v=Umwu2R7QZB4)

## ジャンパーワイヤーの種類

| 種類 | 使うところ |
| --- | --- |
| オス-オス | ブレッドボードの穴どうしをつなぐ（一番よく使う） |
| オス-メス | ブレッドボードと、ピンヘッダが付いたモジュールをつなぐ |
| メス-メス | ピンヘッダどうしを直接つなぐ |

線の色を決めておくと、まちがいが減ります（例: 赤 = 3.3V、黒 = GND、青 = SDA、黄 = SCL）。

![オス-オスのジャンパーワイヤー](images/jumper-wires.jpg)

## 抵抗の値の読み方

抵抗は、電気の流れをおさえる部品です。LED は必ず抵抗と一緒につなぎます（つながないと、LED やピコのピンがこわれます）。
8章の外付けの LED には **220Ω〜1kΩ** のどれでも使えます。迷ったら **330Ω** です。数字が大きいほど、LED は暗くなります。足に向きはありません。

![抵抗（帯の色で値がわかる）](images/resistors.jpg)

値は数字では書いてなく、**色の帯**で表します。袋やセットに書いてある番号（型番）は、値ではないことが多いです。

![抵抗の帯の読み方](images/resistor-bands.svg)

1. 少し離れた帯（4本帯は金、5本帯は茶）を右にして持つ
2. 左から、数字の帯を読む（4本帯は2本、5本帯は3本）
3. 次の帯は、後ろに付ける 0 の数（茶なら 0 を1つ、黒なら付けない）
4. 右はしの帯は誤差（金は ±5%、茶は ±1%）。値には使わない

| 値 | 4本帯 | 5本帯 |
| --- | --- | --- |
| 100Ω | 茶・黒・茶・金 | 茶・黒・黒・黒・茶 |
| 220Ω | 赤・赤・茶・金 | 赤・赤・黒・黒・茶 |
| 330Ω | 橙・橙・茶・金 | 橙・橙・黒・黒・茶 |
| 1kΩ | 茶・黒・赤・金 | 茶・黒・黒・茶・茶 |
| 4.7kΩ | 黄・紫・赤・金 | 黄・紫・黒・茶・茶 |
| 10kΩ | 茶・黒・橙・金 | 茶・黒・黒・赤・茶 |

> 茶と赤、橙と赤は見分けにくいことがあります。迷ったら**テスター**で測ります。Ω のモード（目盛りを選ぶテスターは 2000 か 2k）にして、抵抗の両方の足に赤と黒の棒を当てます。330Ω なら `328` のように、330 に近い数字が出ます。`OL` や `1` だけが出たら、目盛りが小さすぎるか、棒が足に当たっていません。

## はんだ付けの基本

はんだ付けは、はんだ（すずなどの金属の細い線）をこての熱で溶かして、金属どうしをつなぐことです。ピンヘッダを付ける前に、道具の選び方と安全な使い方を覚えます。

### はんだごての選び方（ワット数と温度）

ワット（W）は、こての**温める力**で、温度そのものではありません。W が大きいほど早く温まり、太い線や広い金属に熱をとられても、温度が下がりにくくなります。

| こて | 向き |
| --- | --- |
| **温度調節つき**（50〜80W くらい） | いちばんおすすめ。目盛りを 330〜350℃ に合わせる（鉛の入っていないはんだなら 350〜370℃） |
| 温度調節なし（20〜30W） | 安い。ピンヘッダくらいなら付けられる。温度は変えられず、30W で 480℃ くらいになるものもある。熱すぎると、部品や基板の金属（パッド）を傷める |

- 温度調節なしで 40W 以上のものは、太い線や板金用です。電子工作には熱すぎます

### はんだの選び方（太さと種類）

電子工作用の「**やに入り**」はんだを使います。やに（フラックス）が、溶けたはんだを金属になじませます。

| 太さ | 向き |
| --- | --- |
| **0.6mm** | ピンヘッダ・小さい部品。少しずつ送れて、付けすぎにくい。**はじめてならこれ** |
| 0.8mm | ピンヘッダ・LED の足・ジャンパーワイヤーの線。0.6mm より早く付く |
| 1.0〜1.2mm | 太い線・電池ボックスの線。ピコのピンには多すぎて、となりとつながりやすい |

| 種類 | 溶ける温度 | こての温度 |
| --- | --- | --- |
| 鉛入り（Sn60・Sn63 など） | 約183〜190℃ | 330〜350℃。低い温度で溶けて、はじめてでも扱いやすい。作業のあとは手を洗う |
| 鉛フリー（すず・銀・銅） | 約217℃ | 350〜370℃。少し高い温度がいり、つやが出にくい |

### 温まるまでの時間

| こて | 電源を入れてから使えるまで（目安） |
| --- | --- |
| 温度調節つき | 30秒〜1分 |
| 温度調節なし | 2〜3分 |

時間より確かなのは、こて先にはんだを当ててみることです。**すぐ（1秒以内に）溶ければ準備OK** です。ゆっくり溶ける・溶けないときは、もう少し待ちます。

### 1か所を温める時間

| すること | 時間 |
| --- | --- |
| こて先で、部品の足とパッドの両方を温める | 2〜3秒 |
| はんだを当てて、溶かし込む | 1〜2秒 |
| 全部で | **5秒以内**（LED など熱に弱い部品は3秒まで） |
| こてを離してから、はんだが固まるまで | **2〜3秒**。この間は部品も基板も動かさない |
| 指でさわれるくらい冷めるまで | 30秒くらい |

- うまく付かなくても、こてを当て続けないでください。いったん離して、10秒くらい冷ましてからやり直します
- 固まる前に動かすと、表面がくもった、ひびの入りやすい付き方になります。そのときは、もう一度温めて付け直します

### こて先をきれいにする（スポンジ・金属たわし）

こて先にたまったよごれ（黒いカスや古いはんだ）は、スポンジか金属たわしでぬぐいます。こて先が汚れていると、熱がうまく伝わらず、はんだが付きにくくなります。

**スポンジ**（水を使う）


1. 使う前に水でぬらし、**軽くしぼる**。押すと少しにじむくらい。びしょびしょだと、こて先の温度が急に下がる
2. こて先を、スポンジの上で**さっと1回なでる（1秒くらい）**。押しつけたり、長くこすったりしない
3. こて先が**銀色に光れば**きれい。黒いままなら、もう一度なでる
4. 数か所付けるごとに、同じようにぬぐう

- 乾いたスポンジは使わないでください。こて先の熱で焦げます
- 台所用のスポンジは使わないでください。溶けて、こて先が傷みます。こて台に付いている、熱に強いスポンジを使います

**金属たわし**（真ちゅうや銅の細い線を丸めたもの。水を使わない）

1. こて先を、たわしに**軽く差して抜く**。2〜3回くり返す
2. こて先が銀色に光ればきれい

- 水を使わないので、こて先の温度が下がりません。スポンジより、こて先が長持ちします
- たわしにたまったはんだのくずは、ときどき容器ごとさかさにして捨てます

### 余分なはんだを取る（はんだ吸い取り線）

![はんだ吸い取り線（細い銅の線を編んだもの）](images/desolder-braid.jpg)

はんだ吸い取り線は、細い銅の線を編んだテープです。となりのピンとはんだでつながったとき（ブリッジ）や、はんだを付けすぎたときに使います。

1. 吸い取り線の先を、取りたいはんだの上に置く
2. その上から、こて先を押し当てる（2〜3秒）
3. はんだが溶けて、銅の線に吸い込まれる。吸った所は銀色になる
4. **吸い取り線とこてを、いっしょに離す**。こてだけ先に離すと、線がはんだでくっつく
5. 銀色になった先は、もう吸わないので、ニッパーで切って捨てる

- 銅は熱をよく伝えるので、吸い取り線の先を**指で持たない**でください。ケースや、巻いてある所を持ちます
- 吸いにくいときは、はんだを少し足してから吸うと、よく取れます（新しいはんだのやにが助けます）

![動画: 金属たわしでこて先をきれいにする・吸い取り線ではんだを取る](videos/solder-cleanup.mp4)

### 安全に使う

- こては**必ずこて台に置く**。机やブレッドボードの上に、直接置かない
- 持つのは**グリップだけ**。金属の所は 300℃ 以上ある。落としたら、手でつかもうとせずに離れる
- 使い終わったら、**こて先にはんだを少しのせてから電源を切る**（こて先がさびにくい）。電源を切っても **10分くらいは熱い**ので、冷めるまでさわらない・片付けない
- 煙（はんだの中のやにが溶けたもの）を吸わない。窓を開けるか、扇風機で横に流す
- 鉛入りのはんだを使ったあとは**手を洗う**。作業しながら食べたり飲んだりしない
- 切った部品の足が飛ぶことがあるので、メガネか保護めがねをかける
- 紙やビニール袋など、燃えやすい物を近くに置かない

![動画: はんだごての準備と片付け、1か所を付ける時間](videos/soldering-basics.mp4)

## ピンヘッダの付け方

ピンヘッダは、黒や黄色の樹脂の棒に、金属のピンが並んだ部品です。
ピコのふちに並んだ穴（片側20個ずつ）にはんだ付けすると、ブレッドボードに差せるようになります。

- **USB でつないでプログラムを動かすだけなら、なくても大丈夫です。** LED やセンサーをブレッドボードでつなぐとき（8章の外付けの LED から）に必要になります
- 最初からピンヘッダが付いた「Pico H」「Pico WH」というモデルもあります。その場合、この節は飛ばしてください
- ピコの端にある3つの小さな穴（DEBUG）は、このガイドでは使いません。付けなくてよいです

![ピンヘッダの付け方](images/pin-header.svg)

### 用意するもの

| 道具 | 説明 |
| --- | --- |
| はんだごて | 温度調節できるものが使いやすい。330〜350℃ くらい |
| こて台 | 熱いこてを置く台。こて先を拭くスポンジ付きが便利 |
| はんだ | 電子工作用、太さ 0.6〜0.8mm くらい |
| ブレッドボード | ピンをまっすぐ固定する台として使う |
| ニッパー | ピンヘッダを切り分けるときに使う |

![はんだごて・こて台・はんだ](images/soldering-kit.jpg)

### 手順

1. ピンヘッダを **20ピンずつ2本** にする。40ピンの棒なら、真ん中で折るかニッパーで切る
2. ブレッドボードに、ピンヘッダの **長い側を下にして** 差す。2本の間隔はピコの幅に合わせ、真ん中の溝をまたぐようにする
3. その上にピコを、**チップのある面を上にして** 載せる。短い側のピンが、ピコの穴から少し出る
4. まず **対角の角の2本** だけはんだ付けする。ピコが傾いていないか見て、傾いていたらそのピンを温め直して直す
5. 残りのピンも **全部（2本で40本）**、1本ずつはんだ付けする。使わないピンも付けておくと、ぐらつかず、あとでどのピンでも使える
   - こて先を、**ピンと穴のまわりの金属（パッド）の両方** に当てて 2〜3 秒温める
   - そこへはんだを当てて溶かし込む。量は穴のまわりが埋まるくらい
   - **はんだを先に離して、次にこてを離す**
6. 全部付いたら、ピコをブレッドボードからまっすぐ引き抜く

![動画: ピコにピンヘッダをはんだ付けする（TENTO ch.）](https://www.youtube.com/watch?v=TW-Q8bvAClk)

### できあがりの確認

- ○ 富士山のような形で、つやがある
- × 玉のように丸くなっている、ピンとパッドの間にすき間がある → こてを当てて温め直す
- × 隣のピンとはんだでつながっている（ブリッジ）→ 温めて余分なはんだをこて先で引き取る

付け終わったら USB でつなぎ、「接続の確認」が3つとも緑になるかを見ます。

> **注意**
> - はんだ付けの間は USB を抜いておく
> - こてを長く当てすぎると、ブレッドボードの樹脂が溶けることがある
> - センサーモジュールにも同じ要領で付ける。こちらも短い側を基板に、長い側をブレッドボードに向ける

## まとめ

- ブレッドボードは縦5穴と、横一列の ＋ / − がつながっている。ピコは溝をまたいで差す
- 抵抗は色の帯で値を読む。LED には 220Ω〜1kΩ（迷ったら 330Ω）
- ピンヘッダは長い側をブレッドボードに差して台にし、上からピコをはんだ付けする
- はんだごては温度調節つきで 330〜350℃。1か所は5秒以内。こて先は、ぬらしてしぼったスポンジでさっとぬぐう
- 使い終わったら、こて先にはんだをのせて電源を切る。10分くらいは熱いので、こて台に置いたままにする
- ピンヘッダは穴に差しただけではつながらない。40本全部はんだ付けする
