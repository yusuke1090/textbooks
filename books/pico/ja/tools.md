# 2. 開発器具一覧

ピコで電子工作をするときに使う道具を、写真と使い方でまとめます。
部品（LED・抵抗・センサー）は、それぞれの章の「用意するもの」にあります。

**最初にそろえるもの**

| 道具 | 何に使う |
| --- | --- |
| USB ケーブル | ピコと PC をつなぐ（書き込み・電源・`printf`） |
| ブレッドボード | はんだ付けなしで、部品を差してつなぐ |
| ジャンパーワイヤー | ブレッドボードの穴どうしや、ピンをつなぐ |
| ピンヘッダ | ピコをブレッドボードに差せるようにする（Pico H・WH には付いている） |
| はんだごて・はんだ | ピンヘッダや線を付ける |
| ニッパー | 線や部品の足を切る |

**あると便利なもの**

| 道具 | 何に使う |
| --- | --- |
| はんだ吸い取り線 | 付けまちがえたはんだを取る |
| ワイヤーストリッパー | 線の先のビニールをむく |
| ラジオペンチ | 小さい部品をつまむ・足を曲げる |
| 熱収縮チューブ | はんだ付けした所を包む |
| テスター | 電圧や、線がつながっているかを測る |

## つなぐ道具

### USB ケーブル

![USB ケーブル（左がピコにさすマイクロUSB、右が PC にさす USB-A）](images/usb-cable.jpg)

- ピコと PC をつないで、プログラムの書き込み・電源・`printf` の出力を見るのに使う（4章）
- **データ通信ができるもの**を使う。充電専用のケーブルでは、ピコが PC に出てこない
- ピコ側の差し口に合わせる。公式のピコはマイクロUSB、互換ボードには USB-C のものもある

### ブレッドボード

![ブレッドボード](images/breadboard.jpg)

- 穴に部品の足や線を差すだけで、回路が作れる板。はんだ付けがいらないので、何度でも組み直せる
- **試作の台**として使う。まずブレッドボードで動くのを確かめてから、はんだ付けで仕上げる
- 中に金属の板が入っていて、縦の5穴と、上下の ＋ / − の横一列がつながっている（7章）
- 付録G のイルミネーションでは、ピコと抵抗をのせたままツリーの根元に置き、LED の線をつなぐ台にする
- 大きさは 830穴（フルサイズ）と 400穴（ハーフ）。ピコと部品を一緒にのせるなら 830穴

### ジャンパーワイヤー

![ジャンパーワイヤー（オス-オス）](images/jumper-wires.jpg)

- ブレッドボードの穴どうしや、センサーのピンをつなぐ線。先が金属のピン（オス）か、穴（メス）になっている
- **オス-オス**はブレッドボードの穴どうし（一番よく使う）、**オス-メス**はブレッドボードとセンサーのピン、**メス-メス**はピンどうし
- 穴の奥まで差す。浅いと、つながったり切れたりする

### ピンヘッダ

![ピンヘッダ](images/pin-header-strip.jpg)

- ピコのふちの穴（片側20個）にはんだ付けして、ブレッドボードに差せるようにするピンの列（付け方は7章）
- ピコに付いてくることが多い。最初から付いている「Pico H」「Pico WH」なら、いらない

## はんだ付けの道具

### はんだごて・こて台・はんだ

![はんだごて・こて台・はんだ](images/soldering-kit.jpg)

- はんだ（すずなどの金属の細い線）を熱で溶かして、金属どうしをつなぐ（7章）
- こては温度を変えられるものが使いやすい（330〜350℃）。はんだは電子工作用の 0.6〜0.8mm
- こて台に置いて使う。先はとても熱いので、使い終わったらすぐ電源を切る

### はんだ吸い取り線

![はんだ吸い取り線](images/desolder-braid.jpg)

- 細い銅の編み線。余分なはんだの上にのせて、こてで温めると、はんだを吸い取る
- となりのピンとはんだでつながってしまったとき（ブリッジ）や、付けまちがえたときに使う

## 線を加工する道具

### ニッパー

![ニッパー](images/nipper.jpg)

- 線や、LED・抵抗の長い足を切る
- 電子工作用の、刃の小さいものが使いやすい。硬い針金やネジは切らない（刃が欠ける）

### ワイヤーストリッパー

![ワイヤーストリッパー](images/wire-stripper.jpg)

- 線の先のビニール（被覆）をむく。線の太さ（AWG）に合った穴ではさんで、引く
- ニッパーで軽くはさんで引いてもむけるが、中の細い線まで切りやすい

### ラジオペンチ

![ラジオペンチ](images/pliers.jpg)

- 先の細いペンチ。小さい部品をつまむ、部品の足を曲げる、線をねじる

### 熱収縮チューブ

![熱収縮チューブ](images/heat-shrink.jpg)

- 温めると縮むチューブ。はんだ付けした所にかぶせて縮め、ほかの線とふれないようにする
- はんだ付けの**前に**線に通しておく。ドライヤーやライターで温める
- なければビニールテープで巻く

## 測る道具

### テスター（マルチメーター）

![テスター](images/multimeter.jpg)

- 電圧（V）・抵抗（Ω）・電流と、線がつながっているか（導通）を測る（18章）
- 「電池が何 V か」「ジャンパーワイヤーが中で切れていないか」「はんだ付けがつながっているか」を確かめる
- 導通のモードでは、つながっているとピーと鳴る

## まとめ

- 最初にそろえるのは、USB ケーブル・ブレッドボード・ジャンパーワイヤー・ピンヘッダ・はんだごてとはんだ・ニッパー
- ブレッドボードは、はんだ付けなしで回路を作って試す台。動くのを確かめてから、はんだ付けで仕上げる
- ジャンパーワイヤーは、つなぐ先に合わせてオス-オス・オス-メス・メス-メスを使い分ける
- テスターがあると、電池の電圧や、線が切れていないかを確かめられる

## 練習問題

```quiz
Q: はんだ付けをしないで、部品を差して回路を作る板を何といいますか。
A: ブレッドボード
E: 動くのを確かめてから、はんだ付けで仕上げます。

Q: ブレッドボードの穴どうしをつなぐのに一番よく使うジャンパーワイヤーは、オス-オス・オス-メス・メス-メスのどれですか。
A: オス-オス | オスオス
E: センサーのピンにつなぐときは、オス-メスを使います。

Q: ピコをブレッドボードに差せるように、ふちの穴にはんだ付けするピンの列を何といいますか。
A: ピンヘッダ | ピンヘッダー
E: Pico H・Pico WH には、最初から付いています。

Q: はんだ付けした所にかぶせて、温めて縮めるチューブを何といいますか。
A: 熱収縮チューブ
E: はんだ付けの前に線に通しておきます。なければビニールテープで巻きます。

Q: 線がつながっているか（導通）や、電池の電圧を測る道具を何といいますか。
A: テスター | マルチメーター
E: 導通のモードでは、つながっているとピーと鳴ります。
```
