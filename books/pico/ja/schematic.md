# 10. 回路図の読み方

センサーやカメラの基板を買うと、売り場のページやデータシートに**回路図**が載っています。回路図は「どの部品のどの足が、どこにつながっているか」を記号で描いた地図です。

この章では、記号と線の読み方を覚えてから、カメラの基板（OV7670）の回路図を1つずつ読みます。読めるようになると、「どのピンに何をつなぐか」「何 V を入れてよいか」を自分で確かめられます。

## 絵と回路図のちがい

8章の外付けの LED を、絵と回路図で描くと次のようになります。

![同じ LED の回路を、絵と回路図で](images/sch-led.svg)

| | 絵（配線図） | 回路図 |
| --- | --- | --- |
| 部品 | 本物に似た形 | 決まった記号 |
| 並び | 本物と同じ | 本物とはちがう |
| 使う所 | ブレッドボードに差すとき | 回路を調べるとき |

回路図の上の位置と、基板の上の位置は関係ありません。**見るのは「何と何がつながっているか」だけ**です。

## 部品の記号

![よく出る部品の記号](images/sch-symbols.svg)

記号の横には、**部品の番号**（R1・C3・U2 など）と**値**が書いてあります。番号の頭の文字で、部品の種類がわかります。

| 頭の文字 | 部品 |
| --- | --- |
| R | 抵抗 |
| C | コンデンサ |
| U・IC | IC（チップ） |
| D・LED | ダイオード・LED |
| J・P・CN | コネクタ |
| SW | スイッチ |
| Q | トランジスタ |

基板の上にも、同じ番号が白い文字で印刷されています。回路図の「C7」が基板のどれかは、この文字で探します。

![基板の白い文字（R1・C7 など）。回路図の部品の番号と同じ](images/pcb-silkscreen.jpg)

### 値の読み方

| 書き方 | 意味 |
| --- | --- |
| `10`（抵抗） | 10Ω。Ω は書かないことが多い |
| `1K`・`4K7` | 1kΩ（1,000Ω）・4.7kΩ。`4K7` は小数点の所に K を置く書き方 |
| `4.7uF` | 4.7µF（マイクロファラッド）。µ の代わりに u と書く |
| `0.1uF` | 0.1µF = 100nF |
| `10nF` | 0.01µF |

コンデンサは、電気を少しだけためて、電圧のゆれをならす部品です。大きい値（10µF など）は形も大きく、小さい値（0.1µF など）は米つぶより小さいものがあります。

![いろいろなコンデンサ](images/capacitors.jpg)

## 線のつながり

![線がつながっている所と、つながっていない所](images/sch-wires.svg)

- 線は電線です。線でつながった所は、全部同じ電圧です
- 線が交わる所に**黒い点**があれば、つながっています
- 点がなく、ただ交差しているだけなら、**つながっていません**（上を通り過ぎているだけ）
- T の字に分かれる所は、つながっています（点を付けて描くことが多い）

## 名前でつなぐ

大きな回路図を全部線で描くと、線だらけになります。そこで、線の先に**名前**を付けて、**同じ名前どうしはつながっている**ことにします。

![名前でつなぐ](images/sch-names.svg)

- **ネット名**: 線の先に書いた名前（`SIO_C`・`D0` など）。離れた所に同じ名前があれば、そこまで線を引いたのと同じです
- **電源の記号**: T の字に `3V3`・`2V8` などの名前。`3V3` は 3.3V、`2V8` は 2.8V です（V を小数点の所に置く）
- **GND の記号**: 下向きの三角や、短くなっていく横線。全部つながっていて、0V です
- **AGND**: アナログの部分の GND。基板のどこかで GND とつながっているので、ピコにつなぐときは GND と同じに考えてよいです

## IC の箱の読み方

IC は四角い箱で描き、まわりに足（ピン）が出ています。

![IC の箱の読み方](images/sch-ic.svg)

1. **部品の番号**: U1。基板の白い文字と同じ
2. **型番**: PAM3101DAB28。「PAM3101 datasheet」で検索すると、データシート（説明書）が見つかる
3. **ピンの番号**: 箱の外の数字。本物の足の番号
4. **ピンの名前**: 箱の中の文字。足の役目

箱の中の並びは、本物の足の並びとはちがいます。入口を左、出口を右のように、読みやすい順に並べてあります。

よく出るピンの名前です。

| 名前 | 役目 |
| --- | --- |
| VIN・VCC・VDD | 電源の入口 |
| GND・VSS | 0V |
| OUT | 出口 |
| EN | 1 で動く・0 で止まる |
| RESET | やり直し |
| NC | どこにもつながっていない |

名前の上に横線が引いてあったり、`#`・`n` が付いていたり（`RESET#`・`nRESET`）したら、**0 のときに働く**という意味です。

## 例: カメラの基板（OV7670）を読む

アリエクで売っている OV7670 のカメラの基板（2列×9本のピン）の回路図です。読みやすく描き直しました。付録I でピコにつなぐカメラも、同じ形の基板です。

読む順番は、次のとおりです。

1. 電源の入口を探す（コネクタの 3V3 と GND）
2. IC を見つけて、型番から役目を調べる
3. 電源の流れを追う（何 V が、どこへ）
4. 信号の線を、名前でコネクタまで追う

### 電源の部分

![カメラの基板の電源の部分](images/sch-camera-power.svg)

1. **U1（PAM3101DAB28）**: 3.3V を **2.8V** に下げる IC（レギュレータ）。型番の最後の `28` が 2.8V です。VIN（1番）に 3V3 が入り、OUT（5番）から 2V8 が出ます。EN（3番）は VIN につないであるので、電源が入るといつも動きます
2. **C2・C3・C5**: 入口と出口のコンデンサ。電圧のゆれをならします。U1 の GND（2番）の線は EN の線と交差していますが、点がないのでつながっていません
3. **R1 と C1**: 2V8 から **AVDD**（光を測るアナログの部分の電源）を作ります。10Ω の抵抗とコンデンサで、細かいゆれを通さないようにしています。R2 と C10・C11 も同じで、**DOVDD**（信号のピンの電源）を作ります
4. **U2（PAM3101DAB180）**: 2.8V を **1.8V**（`180` = 1.80V）に下げて、**DVDD**（チップの中の計算の電源）を作ります

まとめると、こうなります。

```text
3V3（コネクタの1番）
 └ U1 → 2V8 ┬ R1 → AVDD   2.8V  光を測る所
            ├ R2 → DOVDD  2.8V  信号のピン（D0〜D7 など）
            └ U2 → DVDD   1.8V  チップの中の計算
```

### センサーとコネクタ

![カメラの基板のセンサー（U3）とコネクタ](images/sch-camera-sensor.svg)

1. **camera**: 2列×9本のピン（コネクタ）。ピコとつなぐのはここだけです。1番が 3V3、2番が GND。ほかの16本は、線の先に名前だけが付いています
2. **同じ名前**: U3（OV7670）の側にも同じ名前があります。コネクタの3番 `SIO_C` は、U3 の3番 `SIO_C` とつながっています。D0〜D7 も同じで、コネクタの16番 `D0` は U3 の9番 `D0` です
3. **C12〜C16（0.1µF）**: 電源のピンのすぐそばに置くコンデンサ（パスコン）。IC が急に電気を使ったときのゆれをおさえます。基板では、チップのまわりの小さな部品です

![本物の OV7670（真ん中）と、まわりの小さなコンデンサ](images/image-sensor.jpg)

`STROBE`（16番）は、コネクタに同じ名前がありません。外には出していない（使わない）ピンです。

### 回路図からわかること

- ピコからは **3.3V だけ**を入れればよい。2.8V と 1.8V は、基板が自分で作ります。ピコの 3V3(OUT)（36番）につなぎます
- D0〜D7 などの信号は **2.8V**（DOVDD）で出てきます。ピコは 2V くらいから 1 と読むので、そのまま読めます
- 細い帯の線（FPC）だけのカメラは、U1・U2 のような電源の部品がないので、ピコに直接つなげません
- ピコとのつなぎ方は、付録I の表のとおりです

## 回路図を探す

- 基板の回路図は、売り場のページか「型番 schematic」で探します
- IC のピンの役目は「型番 datasheet」で探します
- ピコの回路図は、[Pico データシート](https://datasheets.raspberrypi.com/pico/pico-datasheet.pdf) の最後に載っています。読む練習によいです

## まとめ

- 回路図は「何と何がつながっているか」の地図。並びは本物とちがう
- 交わる所の点はつながっている。点がない交差はつながっていない
- 同じ名前（ネット名・電源の記号）はつながっている。GND の記号は全部つながっている
- IC は、箱の外がピンの番号、中がピンの名前。役目は型番のデータシートで調べる
- 読む順番は、電源の入口 → IC → 電源の流れ → 信号の名前

## 練習問題

```quiz
Q: 2本の線が交わる所に黒い点がありません。2本はつながっていますか（はい・いいえ）。
A: いいえ | つながっていない
E: 点がない交差は、上を通り過ぎているだけです。

Q: 抵抗の値に `4K7` と書いてあります。何 kΩ ですか。
A: 4.7
E: 小数点の所に K を置く書き方です。4.7kΩ = 4,700Ω。

Q: 電源の記号に `2V8` と書いてあります。何 V ですか。
A: 2.8
E: V を小数点の所に置く書き方です。

Q: 回路図で C3 と書いてある部品は何ですか。
A: コンデンサ | コンデンサー
E: 頭の文字で種類がわかります。R は抵抗、U は IC です。

Q: 離れた2つの線に、同じ名前 `SIO_C` が付いています。つながっていますか（はい・いいえ）。
A: はい | つながっている
E: 同じ名前どうしは、線を引いたのと同じです。
```
