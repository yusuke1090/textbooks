# 付録A. 用語

## 全体

| 用語 | 意味 |
| --- | --- |
| 一神教 | 神はただひとつと考える宗教（ユダヤ教・キリスト教・イスラム教・シク教） |
| 多神教 | たくさんの神を信じる宗教（ヒンドゥー教・神道など） |
| 創唱宗教 | 開いた人（開祖）がはっきりしている宗教 |
| 民族宗教 | 開祖がなく、その民族の暮らしの中でできた宗教 |
| 聖典 | 宗教の大事な教えをまとめた本 |
| 啓示 | 神が人に、自分の意思や言葉を伝えること |
| 預言者 | 神の言葉をあずかって、人々に伝える人（「予言者」とはちがう） |
| 改宗 | 信じる宗教を変えること |
| 世俗化 | 社会や暮らしの中で、宗教の力が弱まること |
| 政教分離 | 国と宗教を切り離すこと |
| 無宗教 | どの宗教にも属していないと答える人。神や霊を信じる人もいる |

## インドの宗教

| 用語 | 宗教 | 意味 |

## 東アジア・日本

| 用語 | 意味 |
| --- | --- |
| 五常 | 儒教の仁・義・礼・智・信 |
| 孝 | 親や祖先を大切にすること |
| 道（タオ） | 道教の、宇宙と自然の大きな流れ |
| 無為自然 | 無理をせず、自然のままに生きること |
| 八百万の神 | 神道の、たくさんの神々 |
| 氏子 | その神社の地域に住み、神社を支える人 |
| 檀家 | その寺に葬式や法要を任せ、寺を支える家 |
| 神仏習合 | 神と仏を一緒に拝むこと |
| 本地垂迹 | 日本の神は、仏が姿を変えて現れたものという考え |
| 神仏分離 | 1868年に明治政府が神社と寺を分けたこと |
| 国家神道 | 明治から1945年まで、国が神道を管理し、国の祭りとしたもの |
| 新宗教 | 江戸時代の終わり以降に生まれた宗教団体 |
