# 11. そのほかの宗教

## ゾロアスター教

| 項目 | 内容 |
| --- | --- |
| 生まれた所 | 古代のイラン |
| 開いた人 | ザラスシュトラ（ゾロアスター）。いつの人かははっきりせず、前1000年ごろとも、前6世紀ごろともいわれる |
| 神 | 善の神アフラ・マズダー。悪の霊アンラ・マンユと戦っていて、人は善の側を選ぶべきだと説く |
| 信者 | 十数万人ほど。イランと、インドのパールシーとよばれる人々 |

- 火を清らかなものとして、寺院で絶やさずに燃やし続けます（「拝火教」とよばれたのはそのため）
- ペルシャの王朝（ササン朝など）の国の宗教でしたが、7世紀からのイスラム化で少数派になりました。一部はインドに移り、パールシーとして商業で成功しました（インドのタタ財閥など）
- 「最後の審判」「天国と地獄」「救い主」などの考えは、ユダヤ教・キリスト教・イスラム教に影響したといわれます
- 自動車のマツダの名前は、創業者の松田の名前と、アフラ・マズダーからとったと会社が説明しています

![ゾロアスター教の火の寺院（イラン・ヤズド）。中で火が燃え続けている](images/yazd.jpg)

## バハイ教

| 項目 | 内容 |
| --- | --- |
| 生まれた所 | 19世紀のイラン |
| 開いた人 | バハーウッラー（1817〜1892年） |
| 教え | 神はひとつで、すべての宗教はその神から出たもの。人類はひとつ、男女平等、科学と宗教の調和、世界の平和 |
| 中心 | イスラエルのハイファ（世界本部と庭園） |

- 生まれたイランでは、いまも厳しい迫害を受けています

![バハイ教の庭園と聖廟（イスラエル・ハイファ）。世界遺産](images/bahai.jpg)

## アフリカの伝統宗教

- サハラより南のアフリカには、民族ごとにたくさんの伝統宗教があります。共通することが多くあります
  - 遠くにいる創造の神と、身近な自然の霊・祖先の霊
  - 祖先は死んだあとも家族を見守り、大切にしないと災いがあると考える
  - 霊と人をつなぐ人（祈とう師・占い師・薬草にくわしい人）が、病気や悩みの相談にのる
- いまは多くの人がキリスト教やイスラム教を信じていますが、祖先の霊を大切にする考えや儀式を、一緒に続けている人も多くいます（[アフリカの教科書](https://yusuke1090.github.io/textbooks/?b=africa) 1章）
- **ヴォドゥン**: 西アフリカのベナン・トーゴの宗教。ベナンでは1月10日が「ヴォドゥンの日」で、国の祝日になっています

![ベナンのヴォドゥンの祭り（2024年）](images/vodun.jpg)

### アメリカ大陸に渡った宗教

- 16〜19世紀の奴隷貿易で連れて行かれたアフリカの人々は、自分たちの神々の信仰を、キリスト教の聖人と重ね合わせて守りました

| 宗教 | 国 | もと |
| --- | --- | --- |
| ブードゥー | ハイチ | ベナンのヴォドゥンとカトリック |
| サンテリア | キューバ | ナイジェリアのヨルバの神々とカトリック |
| カンドンブレ | ブラジル | ヨルバなど西アフリカの神々 |

## 先住民の信仰とシャーマニズム

| 地域 | 信仰 |
| --- | --- |
| オーストラリア | アボリジニの「ドリーミング」。祖先の霊が大地・動物・人を作ったという物語と、それを受けつぐ決まり。ウルル（エアーズロック）は聖地 |
| 北アメリカ | 先住民の、自然と動物の霊・創造の物語・儀式 |
| モンゴル・シベリア | シャーマン（霊と人をつなぐ人）。天（テンゲル）と自然の霊を祭る。モンゴルの「オボー」（石を積んだ塚）に、旅の無事を祈る |
| 日本（アイヌ） | 自然や動物、道具にも「カムイ」（神）が宿るとし、感謝の儀式をする |

- 先住民の聖地や儀式は、植民地の時代に禁じられたり、壊されたりしてきました。いまは、その権利を守ることが大事にされています。ウルルは2019年に登ることが禁止されました

## アジアのほかの宗教

| 宗教 | 国 | 中身 |
| --- | --- | --- |
| カオダイ教 | ベトナム | 1926年にできた。仏教・道教・儒教・キリスト教・イスラム教をひとつにまとめようとする。シンボルは「天の目」。聖人にフランスの作家ヴィクトル・ユーゴーも入っている |
| 天道・一貫道 | 台湾など | 儒教・仏教・道教をまとめた民間の宗教 |
| ヤズィーディー教 | イラク北部など | 古くからの独自の信仰。2014年に過激派組織 IS に襲われ、多くの人が殺され、連れ去られた |
| ドルーズ派 | レバノン・シリア・イスラエル | イスラム教から分かれた。外の人は信者になれない |

![カオダイ教の本山（ベトナム・タイニン）](images/caodai.jpg)

## まとめ

- ゾロアスター教: 古代イランの善と悪の戦い。火の寺院。のちの宗教に影響
- バハイ教: すべての宗教はひとつの神から。人類の一体
- アフリカの伝統宗教: 祖先と自然の霊。アメリカ大陸でブードゥー・サンテリア・カンドンブレに
- 先住民の信仰とシャーマニズム。カオダイ教など、いくつもの宗教をまとめた新しい宗教もある
