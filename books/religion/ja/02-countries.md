# 2. 国と宗教

数字は、とくに書いていなければ Pew の2020年の推計です。国勢調査の年が書いてあるものは、その国の調べです。どれも目安で、「約」をつけて丸めています。

## 宗教ごとに多い国

| 宗教 | 信者がいちばん多い国 | その宗教が多数派の国 |
| --- | --- | --- |
| キリスト教 | アメリカ、ブラジル、メキシコ、フィリピン、ロシア、ナイジェリア、コンゴ民主共和国など | 120の国と地域。ヨーロッパ・南北アメリカ・サハラより南のアフリカ・オセアニアに多い |
| イスラム教 | インドネシア（約2.4億人）、パキスタン（約2.3億人）、インド（約2.1億人）、バングラデシュ（約1.5億人） | 中東・北アフリカ（人口の94%）、中央アジア、南アジア・東南アジアの一部、西アフリカの一部 |
| ヒンドゥー教 | インド（世界のヒンドゥー教徒の約95%） | インド（79%）、ネパール（81%）。モーリシャスでもいちばん多い（48%） |
| 仏教 | タイ（約6,800万人）、中国（約5,300万人） | カンボジア（97%）、タイ（94%）、ミャンマー（89%）、ブータン（75%）、スリランカ（70%）、ラオス（64%）、モンゴル（51%） |
| ユダヤ教 | イスラエル、アメリカ（この2か国に85%） | イスラエル（約4分の3） |
| 無宗教 | 中国（約13億人）、アメリカ（約1億人）、日本（約7,300万人） | 中国・北朝鮮・日本・ベトナム・チェコ・香港・マカオ・オランダ・ウルグアイ・ニュージーランド |

## 東アジア

| 国 | 多い宗教 | メモ |
| --- | --- | --- |
| 日本 | 無宗教（約半分。調べ方で4〜6割）、仏教、神道 | 多くの人が、神社にも寺にも行く（10章） |
| 中国 | 無宗教（約9割） | 仏教（4%）、キリスト教、イスラム教（回族・ウイグル族）、道教。祖先や民間の神を拝む人は多い。宗教は国が管理する（9章） |
| 韓国 | 無宗教（約半分） | キリスト教（プロテスタントが多い）が約3割、仏教が2割弱。儒教の礼儀と祖先の祭りが強く残る |
| 台湾 | 民間信仰・道教・仏教 | 「そのほかの宗教」が多数派の、世界でただひとつの所（9章） |
| モンゴル | 仏教（チベット仏教、約半分）、無宗教 | シャーマニズム（自然の霊）も残る |
| 北朝鮮 | 無宗教 | 国が宗教を厳しく制限している |

## 東南アジア

| 国 | 多い宗教 | メモ |
| --- | --- | --- |
| インドネシア | イスラム教（約87%） | イスラム教徒の数が世界一。キリスト教も1割ほど。バリ島はヒンドゥー教 |
| マレーシア | イスラム教（約6割） | 憲法でイスラム教を連邦の宗教とする。中国系に仏教・道教、インド系にヒンドゥー教が多い |
| フィリピン | キリスト教（約9割。カトリックが中心） | アジアでいちばんキリスト教徒が多い国。南部のミンダナオ島にイスラム教徒 |
| タイ | 仏教（94%） | 上座部仏教。南部にイスラム教徒 |
| ミャンマー | 仏教（89%） | 西部のラカイン州のイスラム教徒（ロヒンギャ）の問題（12章） |
| カンボジア・ラオス | 仏教（97%・64%） | 上座部仏教。ラオスは民間の精霊信仰も多い |
| ベトナム | 無宗教が多数 | 仏教・祖先の祭り・民間信仰が暮らしの中にある。カトリック、カオダイ教（11章） |
| シンガポール | 仏教・キリスト教・無宗教・イスラム教・道教 | いくつもの宗教がまざっている |
| ブルネイ | イスラム教 | 国王が宗教の長でもある |

## 南アジア

| 国 | 多い宗教 | メモ |
| --- | --- | --- |
| インド | ヒンドゥー教（79%） | イスラム教（15%、約2.1億人）、キリスト教、シク教、仏教、ジャイナ教。憲法では世俗国家 |
| ネパール | ヒンドゥー教（81%） | ブッダの生まれた地ルンビニーがある。仏教も多い |
| パキスタン | イスラム教（ほぼ全員） | 1947年に、イスラム教徒の国としてインドから分かれた |
| バングラデシュ | イスラム教（約9割） | ヒンドゥー教が1割ほど |
| スリランカ | 仏教（70%） | ヒンドゥー教（タミル人）、イスラム教、キリスト教 |
| ブータン | 仏教（75%。チベット仏教） | 南部にヒンドゥー教 |
| アフガニスタン | イスラム教（ほぼ全員） | イスラム法による統治 |

## 中東・北アフリカ

人口の94%がイスラム教徒の地域です。

| 国 | 多い宗教 | メモ |
| --- | --- | --- |
| サウジアラビア | イスラム教（スンニ派が多い） | 聖地メッカとメディナがある。外国から来た働き手には、ほかの宗教の人も多い |
| イラン | イスラム教シーア派 | シーア派を国の宗教とする。宗教の指導者が国の最高指導者 |
| イラク | イスラム教（シーア派が多数、スンニ派） | キリスト教やヤズィーディー教の少数派 |
| トルコ | イスラム教（スンニ派） | 憲法は政教分離（世俗主義）。イスタンブールに東ローマ帝国の教会だったアヤソフィア |
| エジプト | イスラム教（約9割） | キリスト教（コプト正教会）が1割ほど |
| イスラエル | ユダヤ教（約4分の3） | アラブ系のイスラム教徒が約2割、キリスト教徒、ドルーズ |
| レバノン | イスラム教（スンニ派・シーア派）とキリスト教 | 宗派ごとに、大統領・首相・議会の席を分ける仕組み |
| アラブ首長国連邦・カタール | イスラム教 | 外国から来た働き手が多く、ヒンドゥー教徒・キリスト教徒も多い |
| モロッコ・アルジェリア・チュニジア | イスラム教（ほぼ全員） | |

## ヨーロッパ

| 国 | 多い宗教 | メモ |
| --- | --- | --- |
| イタリア | キリスト教（カトリック、約8割） | ローマの中にバチカン市国がある |
| スペイン・ポルトガル | キリスト教（カトリック） | 無宗教が増えている |
| ポーランド | キリスト教（カトリック、約9割） | 教会が社会で強い力を持ってきた |
| フランス | キリスト教（46%）、無宗教（4割以上） | イスラム教徒も多い。公の場から宗教を離す「ライシテ」（12章） |
| イギリス | キリスト教（49%）、無宗教（4割以上） | イングランド国教会。イスラム教・ヒンドゥー教・シク教の人も多い |
| ドイツ | キリスト教（カトリックとプロテスタント）、無宗教 | 教会に入っている人は「教会税」を払う。トルコ系のイスラム教徒 |
| オランダ | 無宗教（54%） | 2020年に無宗教が多数派になった |
| チェコ・エストニア | 無宗教 | ヨーロッパでも特に無宗教が多い |
| 北欧（スウェーデン・デンマークなど） | キリスト教（ルター派） | 教会に属していても、ふだん教会に行く人は少ない |
| ロシア | キリスト教（ロシア正教会） | イスラム教徒も1割ほど（タタール人・チェチェン人など） |
| ギリシャ・ルーマニア・セルビア・ウクライナ | キリスト教（正教会） | |
| ボスニア・ヘルツェゴビナ、アルバニア、コソボ | イスラム教が多い | オスマン帝国の時代に広まった |

## サハラより南のアフリカ

いまは、世界のキリスト教徒の約3割がこの地域に住んでいます。

| 国 | 多い宗教 | メモ |
| --- | --- | --- |
| ナイジェリア | イスラム教とキリスト教がほぼ半々 | 北部はイスラム教、南部はキリスト教 |
| エチオピア | キリスト教（エチオピア正教会など、約3分の2） | イスラム教が約3分の1。4世紀からのキリスト教の国 |
| ケニア | キリスト教（約86%） | イスラム教が約11%（海岸と北東部）。2019年の国勢調査 |
| タンザニア | キリスト教とイスラム教 | キリスト教のほうが多い。ザンジバルはほとんどがイスラム教 |
| マラウイ | キリスト教（約77%） | イスラム教が約14%（湖の南のほう）。2018年の国勢調査 |
| コンゴ民主共和国 | キリスト教（9割以上） | カトリックとプロテスタント、キンバング教会 |
| 南アフリカ | キリスト教（約8割） | アフリカで生まれた独立教会（ザイオン・クリスチャン教会など） |
| セネガル・マリ・ソマリア・スーダン | イスラム教 | |
| ベナン・トーゴ | キリスト教・イスラム教・ヴォドゥン | ヴォドゥン（伝統宗教）が国の祝日になっている（ベナン、11章） |

- アフリカでは、キリスト教やイスラム教を信じながら、祖先の霊を大切にする昔からの考えも続けている人が多くいます（[アフリカの教科書](https://yusuke1090.github.io/textbooks/?b=africa)）

## オセアニア

| 国 | 多い宗教 | メモ |
| --- | --- | --- |
| オーストラリア | キリスト教（47%）、無宗教（4割） | キリスト教の割合が10年で大きく下がった。先住民アボリジニの信仰（11章） |

## 国の中で宗教が分かれている例

| 国 | 分かれ方 |
| --- | --- |
| ナイジェリア | 北がイスラム教、南がキリスト教。選挙では大統領と副大統領を、ちがう宗教の人で組むことが多い |
| レバノン | 18の宗派を認め、宗派ごとに政治の役職を分ける |
| インド | ヒンドゥー教が多数で、イスラム教徒が約2億人。地域によっては、シク教（パンジャーブ）やキリスト教（ナガランドなど北東部、ケーララ）が多い |
| マレーシア | 民族と宗教が重なる（マレー系はイスラム教、中国系は仏教・道教・キリスト教、インド系はヒンドゥー教） |
| ボスニア・ヘルツェゴビナ | ボシュニャク人はイスラム教、セルビア人は正教会、クロアチア人はカトリック |
| 北アイルランド（イギリス） | カトリックとプロテスタントが対立し、1998年の和平合意まで争いが続いた |
