# 8. シク教とジャイナ教

## シク教

### あらまし

| 項目 | 内容 |
| --- | --- |
| 信者 | 約2,500〜3,000万人 |
| 多い所 | インド北西部のパンジャーブ州（州の人口の約6割）。移民でカナダ・イギリス・アメリカにも多い |
| 開いた人 | グル・ナーナク（1469〜1539年）。このあと10代のグル（師）が続いた |
| 神 | 唯一の神。形がなく、すべての宗教の神は同じひとつの神だと考える |
| 聖典 | グル・グラント・サーヒブ。10代目のグルが、自分の後は人ではなくこの聖典をグルとすると定めた |
| 祈る場所 | グルドワーラー（「グルの門」） |
| 聖地 | アムリトサルの黄金寺院（ハリマンディル・サーヒブ） |

- インドの人口に占める割合は2%ほどですが、軍・運輸・農業・海外への移住で目立つ存在です。日本で「インドの人はターバンを巻いている」というイメージがあるのは、シク教徒の姿から来ています

![黄金寺院と、池で身を清める巡礼者（インド・アムリトサル）。シク教の総本山](images/golden-temple.jpg)

### 歴史

| いつ | できごと |
| --- | --- |
| 1499年ごろ | ナーナクが「ヒンドゥー教徒もイスラム教徒もない」と悟り、教えを説き始める |
| 16〜17世紀 | 歴代のグルが聖典をまとめ、黄金寺院を建てる。ムガル帝国と対立し、2人のグルが処刑される |
| 1699年 | 10代グル・ゴービンド・シングが、信者の共同体「カールサー」を作り、5つのK（下）を定める |
| 1799〜1849年 | パンジャーブにシク王国 |
| 1947年 | インドとパキスタンの分離で、パキスタン側にいた多くのシク教徒がインドへ移った |
| 1984年 | 自分たちの国を求める武装勢力が立てこもった黄金寺院に、インド軍が突入。その後、インディラ・ガンディー首相がシク教徒の護衛に暗殺され、各地でシク教徒が襲われた |

### 教えときまり

- 唯一の神を心に念じ、正直に働き、得たものを分け合うことを大切にします
- **カーストを認めず、男女も平等**とします。輪廻と業の考えはヒンドゥー教と共通です
- 洗礼を受けた信者は「5つのK」を身に着けます

| 5つのK | 中身 |
| --- | --- |
| ケーシュ | 髪とひげを切らない。髪はターバンで包む |
| カンガー | 木のくし |
| カラー | 鉄の腕輪 |
| カッチャー | 綿の下着 |
| キルパーン | 小さな剣（弱い人を守るしるし） |

- 男性は名前に「シン（ライオン）」、女性は「カウル（王女）」を付けます
- たばこ・酒・決まった方法で処理した肉（ハラールなど）を避けます

### ランガル（無料の食堂）

- グルドワーラーには、宗教・身分・国に関係なく、誰でも無料で食事ができる食堂（ランガル）があります。みんなが床に並んで座り、同じものを食べることで、平等を表します
- 料理と片付けは信者のボランティアです。黄金寺院のランガルでは、毎日5万〜10万人が食べるといわれます

![ランガルの台所で料理するシク教徒のボランティア（インド・パンジャーブ）](images/langar.jpg)

## ジャイナ教

### あらまし

| 項目 | 内容 |
| --- | --- |
| 信者 | 約450万人（インドの2011年の国勢調査）。ほとんどがインドにいる |
| 開いた人 | ヴァルダマーナ（マハーヴィーラ、「偉大な英雄」）。ブッダと同じころ（前6〜前5世紀）の人。それより前にも23人の祖師（ティールタンカラ）がいたとされる |
| 目標 | 魂を業（カルマ）のけがれから清め、輪廻から抜け出す |
| 祈る場所 | 寺院。白い大理石の美しい寺が多い |
| 宗派 | 白い服を着る白衣派と、僧が衣を着ない裸行派 |

### 教えときまり

| きまり | 中身 |
| --- | --- |
| 不殺生（アヒンサー） | すべての生き物を傷つけない。いちばん大事な教え |
| 食べ物 | 肉・魚・卵を食べない。土の中の小さな生き物を傷つけないように、じゃがいも・玉ねぎ・にんじんなどの根菜も食べない人が多い。日が沈んだら食べない人も |
| 僧 | 小さな虫を吸いこまないように口を布でおおい、歩く前に道をほうきではく人もいる |
| 5つの誓い | 殺さない・うそをつかない・盗まない・性の慎み・物を持ちすぎない |
| 多面的な見方 | ひとつの物事には多くの見方があり、ひとつの見方だけが正しいとは言えないと考える |

- 生き物を殺す仕事（農業や漁業も）を避けたことから、商業・金融・宝石の仕事につく人が多く、インドの経済で大きな役割をはたしてきました
- ガンディーの非暴力の考えにも、ジャイナ教の影響があったといわれます

![ラーナクプルのジャイナ教寺院の中（インド・ラージャスターン州）。1,400本をこえる大理石の柱がある](images/ranakpur.jpg)

## まとめ

- シク教: 15世紀にナーナクが開いた。唯一の神、カーストの否定と平等。ターバンと5つのK、誰でも食べられるランガル
- ジャイナ教: ブッダと同じころのマハーヴィーラ。不殺生を徹底し、根菜も食べない人が多い
- どちらもインドの輪廻と業の考えを受けつぎながら、独自の道を作った
