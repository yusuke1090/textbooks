# 7. 仏教

## この章でわかること

- 仏教のあらましと、ブッダの生涯
- 四諦・八正道・縁起・無常など、ブッダの教え
- 上座部仏教・大乗仏教・チベット仏教のちがい
- アジアに広がった歴史と、いまの様子

## あらまし

| 項目 | 内容 |
| --- | --- |
| 信者 | 約3.2億人（2020年）。2010年から人数が減った、ただひとつの大きな宗教 |
| 多い国 | タイ（約6,800万人）、中国（約5,300万人）、ミャンマー、日本、スリランカ、ベトナム、カンボジアなど。信者の98%がアジアにいる |
| 仏教が多数派の国 | カンボジア（97%）、タイ（94%）、ミャンマー（89%）、ブータン（75%）、スリランカ（70%）、ラオス（64%）、モンゴル（51%） |
| 開いた人 | ブッダ（ゴータマ・シッダールタ。日本では釈迦、お釈迦さま）。「ブッダ」は「目覚めた人」という意味 |
| 聖典 | お経（ブッダの教えをまとめたもの）。パーリ語・サンスクリット語・漢文・チベット語のものがある |
| 祈る場所 | 寺、仏塔（ストゥーパ。ブッダの骨などを納めた塔。日本の五重塔のもと） |
| 聖地 | ルンビニー（生まれた所、ネパール）、ブッダガヤ（悟った所、インド）、サールナート（初めて教えを説いた所）、クシナガラ（亡くなった所） |

## ブッダの生涯

| いつ（目安） | できごと |
| --- | --- |
| 前5世紀ごろ（前6世紀とする説も） | いまのネパールのルンビニーで、シャカ族の王子として生まれる |
| 29歳 | 老い・病・死の苦しみに悩み、家族と城を出て修行の道に入る（出家） |
| 6年ほど | きびしい苦行をするが、悟れなかった。苦行も、ぜいたくも、どちらにもかたよらない「中道」を選ぶ |
| 35歳ごろ | ブッダガヤの菩提樹の下で瞑想し、悟りを開く |
| その後45年ほど | サールナートで初めて教えを説き、インド北部を歩いて教えを広める。弟子の集まり（僧伽、サンガ）ができる |
| 80歳 | クシナガラで亡くなる（入滅） |

## ブッダの教え

| 教え | 中身 |
| --- | --- |
| 四諦（4つの真理） | ①生きることには苦しみがある（苦）　②苦しみの原因は、欲や執着にある（集）　③欲と執着をなくせば、苦しみはなくなる（滅）　④そのための方法がある（道） |
| 八正道 | 苦しみをなくす8つの正しい道。正しい見方・考え・言葉・行い・暮らし・努力・気づき・心の集中 |
| 縁起 | すべてのものは、ほかのものとの関わり合いで起こる。それだけで存在するものはない |
| 無常 | すべては変わり続け、同じままのものはない |
| 無我 | 変わらない「わたし」というものはない |
| 涅槃（ニルヴァーナ） | 欲と執着の火が消えた、安らかな悟りの境地。輪廻から抜け出すこと |
| 五戒 | 信者が守る5つのこと。生き物を殺さない・盗まない・よこしまな性の行いをしない・うそをつかない・酒を飲まない |

- 仏教は、インドの輪廻と業の考えを受けつぎながら、カーストを認めず、誰でも修行して悟れると説きました
- 「仏・法（教え）・僧（修行する仲間）」を「三宝」として大切にします

## 広がった歴史

| いつ | できごと |
| --- | --- |
| 前3世紀 | インドのアショーカ王が仏教を守り、各地に広める。スリランカに伝わる |
| 前後〜 | 「すべての人を救う」ことを目指す大乗仏教が起こる |
| 1〜3世紀 | ガンダーラ（いまのパキスタン・アフガニスタン）で、ギリシャの彫刻の影響を受けて、初めて仏像が作られる |
| 1世紀ごろ | シルクロードを通って中国に伝わる |
| 4世紀 | 朝鮮半島に伝わる |
| 6世紀 | 日本に伝わる（538年、552年の説がある） |
| 7世紀〜 | チベットに伝わる。のちにモンゴルへ |
| 5〜13世紀 | スリランカから東南アジア（ミャンマー・タイ・カンボジア・ラオス）に上座部仏教が広まる |
| 12〜13世紀 | インドでは、ヒンドゥー教に吸収されたり、イスラム教の勢力に寺を壊されたりして、ほとんど見られなくなる |
| 1956年 | インドのアンベードカル（憲法を作った人。ダリット出身）が、カーストに反対して数十万人とともに仏教に改宗する |
| 20世紀〜 | 欧米で、禅や瞑想（マインドフルネス）が広まる |

## 3つの大きな流れ

| | 上座部仏教（テーラワーダ） | 大乗仏教 | チベット仏教 |
| --- | --- | --- | --- |
| 広まった道 | 南へ（南伝） | 北へ（北伝） | 北へ。インドの後期の仏教を受けつぐ |
| 多い国 | スリランカ、タイ、ミャンマー、カンボジア、ラオス | 中国、台湾、韓国、日本、ベトナム | チベット、モンゴル、ブータン、ネパールの一部 |
| 考え方 | 出家した僧が、きびしい戒律を守って修行し、自分が悟ることを目指す | 悟りを目指しながら、ほかの人を救う「菩薩」を理想とする。在家の人も救われる | 大乗の教えに、真言・儀式を使う密教が加わる |
| 仏・菩薩 | おもにブッダ | 阿弥陀仏・薬師如来・観音菩薩・地蔵菩薩など多くの仏と菩薩 | 多くの仏・菩薩と守り神。指導者（ラマ）を大切にする |
| お経の言葉 | パーリ語 | 漢文（日本・中国・韓国） | チベット語 |
| 特徴 | 僧は朝に托鉢し、昼すぎから次の朝まで食べない。男性が一時的に出家する習慣（タイ・ミャンマー） | 禅、浄土（念仏）、法華経の信仰など、多くの宗派 | ダライ・ラマなど、指導者が生まれ変わると考え、その子どもを探して後を継がせる |

## いまの様子

- 中国・日本・韓国で、仏教を信じると答える人が減っています。お寺の後継ぎがいない、檀家が減るなど、日本の寺も変わり目にあります（10章）
- タイやミャンマーでは、仏教が国と社会の中心にあり、僧は大きな尊敬を受けています。一方で、仏教の僧の一部が、少数派のイスラム教徒への反発をあおったことも問題になりました
- ダライ・ラマ14世は、1959年にチベットからインドに亡命しました。後継ぎを誰が決めるかで、中国政府と対立しています
- 欧米では、瞑想・マインドフルネス・禅が、宗教としてだけでなく、心の健康の方法として広まっています

## まとめ

- ブッダの悟りから始まる。四諦・八正道で苦しみをなくし、涅槃を目指す
- 縁起・無常・無我。誰でも修行して悟れると説き、カーストを認めなかった
- 上座部（南アジア・東南アジア）、大乗（東アジア）、チベット仏教の3つの流れ
- 生まれたインドではほとんど消え、アジア全体に広がった
