# 10. 日本の宗教

## 数字で見る日本の宗教

| 調べ | 数字 |
| --- | --- |
| 文化庁『宗教年鑑』（令和4年版）の信者の数 | 神道系 約8,700万人、仏教系 約8,300万人、キリスト教系 約190万人、諸教 約710万人。合計 約1億8,000万人で、人口より多い |
| Pew の調査（2023年、大人） | 仏教 46%、神道 4%、宗教はない 42% |
| Pew の推計（2020年、子どもを含む） | 宗教はない 57%（約7,300万人） |

- 『宗教年鑑』の数字は、神社や寺が自分で報告したものです。神社は地域の住民（氏子）を、寺は檀家を数えるので、1人が両方に数えられ、人口より多くなります
- 「宗教は信じていない」と答える人でも、初詣・お盆・お墓参り・お守りなどは、習慣として多くの人が行います。日本では「宗教」が、特定の教団に入ることだと受け取られやすいためです
- 宗教団体は全国に約18万あります。神道系が約8万4千、仏教系が約7万7千です（『宗教年鑑』令和6年版）

## 神道

### あらまし

| 項目 | 内容 |
| --- | --- |
| 神 | 八百万の神（やおよろずのかみ）。山・川・木・岩・海などの自然、祖先、すぐれた人も神として祭る |
| 開いた人・聖典 | いない。決まった聖典もない。『古事記』（712年）と『日本書紀』（720年）に神話が書かれている |
| 祭る場所 | 神社。鳥居が入口のしるし。家では神棚 |
| 神職 | 神主（宮司・禰宜）。巫女が手伝う |
| 中心の神社 | 伊勢神宮（天照大御神をまつる） |

![伊勢神宮（三重県）の手水舎。お参りの前に、ここで手と口を清める](images/ise.jpg)

### 考え方

- **けがれと清め**: 死や病気などのけがれを嫌い、水で手と口を清める（手水）、お祓いを受けるなどして、清らかな状態を大切にします
- **まつり**: 神をむかえ、もてなし、感謝し、豊作や無事を祈る。地域の祭りの多くは神社の祭りです
- **自然への感謝**: 大きな木や岩にしめ縄をはり、神が宿るものとして大切にします
- 死んだあとのことや、正しい生き方を細かく説く教えはあまりなく、毎日の暮らしと季節の行事に溶けこんでいます

## 日本の仏教

### 歴史

| 時代 | できごと |
| --- | --- |
| 6世紀 | 朝鮮半島の百済から仏教が伝わる（538年、552年の説）。受け入れるかどうかで、蘇我氏と物部氏が争う |
| 飛鳥時代 | 聖徳太子が仏教を重んじ、法隆寺などを建てる |
| 奈良時代 | 国を守るための仏教。聖武天皇が国ごとに国分寺を建て、東大寺の大仏を作る（752年に開眼） |
| 平安時代 | 最澄が天台宗（比叡山）、空海が真言宗（高野山）を開く |
| 鎌倉時代 | 武士や庶民にわかりやすい新しい宗派が生まれる（下の表） |
| 江戸時代 | キリスト教を取りしまるため、すべての家がどこかの寺に属する「寺請制度」。寺が葬式と先祖の供養をになう「檀家制度」ができる |
| 明治時代 | 神仏分離で、寺の仏像や建物がこわされることもあった（廃仏毀釈） |

### おもな宗派

| 宗派 | 開いた人 | 特徴 |
| --- | --- | --- |
| 天台宗 | 最澄 | 法華経を中心に、多くの教えを学ぶ。比叡山から鎌倉の宗派の開祖が多く出た |
| 真言宗 | 空海 | 密教。真言（呪文）と儀式。高野山。四国八十八か所のお遍路 |
| 浄土宗 | 法然 | 「南無阿弥陀仏」と唱えれば、阿弥陀仏の極楽浄土に生まれ変われる |
| 浄土真宗 | 親鸞 | 阿弥陀仏を信じる心そのものを大事にする。僧も結婚した。いま信者がいちばん多い宗派（西本願寺・東本願寺など） |
| 臨済宗 | 栄西 | 禅。師から出される問い（公案）を考える。武士に広まり、茶道・庭園の文化にもつながった |
| 曹洞宗 | 道元 | 禅。ただひたすら座る（只管打坐）。寺の数がいちばん多い |
| 日蓮宗 | 日蓮 | 法華経をもっとも大事にし、「南無妙法蓮華経」と唱える |

### 暮らしの中の仏教

- 葬式の多くは仏教の形で行います。亡くなった人に戒名（法名）をつけ、四十九日・一周忌などの法要を行います
- 家の仏壇に位牌をおき、祖先を供養します
- 地方では檀家が減り、住職のいない寺も増えています

## 神仏習合と、明治の分離

- 奈良時代から、神と仏を一緒に拝む「神仏習合」が進みました。「日本の神は、仏が人を救うために姿を変えて現れたもの」（本地垂迹）と考えられ、神社の中に寺があることもふつうでした
- 1868年、明治政府は神仏分離令を出し、神社と寺を分けました。その後、神道は国が管理する「国家神道」となり、天皇を中心にした国づくりや、戦争への動員と結びつきました
- 1945年の敗戦のあと、国と神道は切り離され、日本国憲法で信教の自由と政教分離が定められました（20条・89条）

## 日本のキリスト教

- 16世紀に伝わり、禁止と潜伏の時代を経て、明治時代に再び認められました（4章）
- 信者は人口の約1%ですが、ミッション系の学校・病院、教会での結婚式、クリスマスなどで身近です
- 長崎と天草の潜伏キリシタンの遺産は、2018年に世界遺産になりました

![大浦天主堂（長崎）。1865年に潜伏キリシタンが信仰を打ち明けた「信徒発見」の場所](images/oura.jpg)

## 新宗教

| 時期 | おもな団体 |
| --- | --- |
| 江戸時代の終わり〜明治 | 天理教（1838年）、金光教、黒住教、大本 |
| 昭和 | 創価学会（日蓮の教えにもとづく。1930年）、立正佼成会、霊友会、生長の家、PL教団など |
| 昭和の後半〜 | 「新新宗教」とよばれる団体。自己啓発や神秘体験を重んじるものも |

- 社会問題になった団体もあります。オウム真理教は1995年に地下鉄サリン事件を起こし、裁判所の命令で解散させられました
- 旧統一教会（世界平和統一家庭連合）は、高額な献金をめぐる被害が問題になり、2025年3月に東京地方裁判所が解散を命じ、2026年6月に最高裁判所で確定しました

- 人生の節目では、生まれたら神社にお宮参り、結婚式はキリスト教式か神前式、葬式は仏教、ということがよくあります。「いいとこ取り」とも言われますが、場面ごとに役わりを分けてきた、日本の宗教の特徴です

## まとめ

- 「宗教を信じていない」と答える人が多いが、行事や習慣として、神道と仏教が暮らしに深く入っている
- 神道: 八百万の神、けがれと清め、まつり。神社と神棚
- 仏教: 6世紀に伝わり、鎌倉時代に多くの宗派。江戸時代の檀家制度で葬式と先祖供養の役わり
- 神仏習合が長く続き、明治に分けられた。戦後に政教分離
