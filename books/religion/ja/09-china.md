# 9. 儒教と道教（中国・韓国・台湾）

## この章でわかること

- 中国で生まれた儒教と道教の考え
- 中国・韓国・台湾で、宗教がどう暮らしに入っているか
- いまの中国と宗教の関係

## 東アジアの宗教のあらまし

- 東アジアでは、ひとつの宗教だけを信じるより、**儒教・道教・仏教・祖先の祭り・民間の神々を、場面ごとに使い分ける**のがふつうです
- 「宗教を信じていますか」と聞かれると「いいえ」と答える人が多いのに、お墓参り・線香・お守り・占いはよくします。中国語や日本語の「宗教」という言葉が、教団に入ることを指すように受け取られやすいからです
- 2023年の Pew の調査では、台湾・日本・ベトナムの大人の約半分以上が「山や川や木には霊が宿る」と答えています

## 儒教

### あらまし

| 項目 | 内容 |
| --- | --- |
| 開いた人 | 孔子（前551〜前479年）。中国の春秋時代、魯の国（いまの山東省）の人 |
| 本 | 『論語』（孔子と弟子の言葉）。四書（論語・孟子・大学・中庸）と五経 |
| 大事にすること | 仁（思いやり）・義（正しさ）・礼（礼儀と作法）・智（知恵）・信（まこと）の「五常」。親を大切にする「孝」 |
| 祭る場所 | 孔子廟。家では祖先の位牌 |

- 儒教は、神を拝むことより、人としての正しい生き方と、家族・社会・国の秩序を説く教えです。宗教なのか、道徳や政治の思想なのかは、意見が分かれます
- それでも、孔子を祭る儀式や、祖先を祭る儀礼（祭祀）を大切にしてきました

![孔子廟の大成殿（中国・山東省の曲阜）。孔子のふるさとにある](images/confucius-temple.jpg)

### 歴史

| いつ | できごと |
| --- | --- |
| 前6〜前5世紀 | 孔子が、乱れた世の中を、思いやりと礼で治めようと説く |
| 前4〜前3世紀 | 孟子（人の性は善）、荀子（人の性は悪）が教えを広げる |
| 前2世紀 | 漢の時代に、国の学問になる |
| 7世紀〜1905年 | 役人を選ぶ試験（科挙）で、儒教の本が試験に出された |
| 12世紀 | 朱熹が朱子学をまとめる。のちに朝鮮王朝や、日本の江戸幕府の学問になる |
| 20世紀 | 中国の文化大革命（1966〜76年）で、古い考えとして激しく攻撃される。いまは、中国政府が伝統文化として見直している |

### 暮らしの中の儒教

- 年上・親・先生を敬う。言葉づかいや、お酒をつぐ順番などの作法
- 祖先を祭る。韓国では、正月やお盆（秋夕、チュソク）に、祖先に料理を供える祭祀（チェサ）を行う家が多い
- 学問と試験を重んじる（東アジアの受験の熱心さにつながっているともいわれる）

## 道教

### あらまし

| 項目 | 内容 |
| --- | --- |
| もとになった人 | 老子（『道徳経』）、荘子。老子がどんな人だったかは、よくわかっていない |
| 大事にすること | 「道（タオ）」。宇宙と自然の大きな流れ。人は、無理をせず自然のままに生きる（無為自然） |
| 目標 | 長生きと不老不死（仙人）。体と心を養う |
| 神々 | 玉皇大帝、関帝（三国志の関羽。商売の神）、媽祖（海の女神）、財神、土地の神、かまどの神など、とても多い |
| 祭る場所 | 道観（道教の寺）、廟 |

- 2世紀に、張陵が「五斗米道（天師道）」という教団を作り、宗教としての道教が始まったとされます
- 陰と陽の考え、風水、太極拳、漢方の考え、お札、占いなどは、道教とつながっています
- 儒教が「社会の中での正しい生き方」なら、道教は「自然の中での自由な生き方と、体の養生」を説くとよく言われます

## 中国の仏教と民間信仰

- 仏教は1世紀ごろにシルクロードを通って伝わり、中国の考えとまざって、禅や浄土の教えが生まれました（7章）
- 観音菩薩は、とくに人気があります
- 春節（旧正月）、清明節（お墓参り）、中秋節などに、線香をあげ、紙で作ったお金を燃やして祖先に送る習慣があります

## いまの中国と宗教

- 中国共産党は無神論の立場で、党員は宗教を信じないことになっています
- 国は、仏教・道教・イスラム教・カトリック・プロテスタントの5つを認め、それぞれ国の管理する団体を通して活動させています。登録しない教会などは、取りしまりの対象になることがあります
- 2020年の Pew の推計では、宗教を持つと答えた人は約1割で、世界でいちばん低い割合です。それでも、祖先の祭りや民間の神へのお参りは広く行われています
- 新疆ウイグル自治区のイスラム教徒（ウイグル族）や、チベットの仏教への政府の取りしまりは、国際的な問題になっています

## 韓国

- 宗教を持たない人が約半分、キリスト教（プロテスタントが多い）が約3割、仏教が2割弱です
- 20世紀に、キリスト教が急に広まりました。大きな教会が多く、社会や政治への影響も大きい
- 儒教の作法と祖先の祭りは、宗教を問わず強く残っています
- ムーダン（巫堂）とよばれるシャーマンの儀式（クッ）も続いています

## 台湾

- 民間信仰・道教・仏教が混じり合った信仰が多数派で、町のあちこちに廟があります
- 海の女神**媽祖**の信仰がとくにさかんで、毎年、媽祖の像をかついで何百キロも歩く巡礼に、数百万人が参加します

![媽祖をまつる廟で、線香を持って祈る人（台湾・鹿港）](images/mazu.jpg)

## まとめ

- 東アジアでは、儒教・道教・仏教・祖先の祭りを一緒に信じるのがふつう
- 儒教: 孔子。仁・礼・孝。家族と社会の秩序。祖先の祭り
- 道教: 老子。道（タオ）と無為自然。不老長寿、陰陽、風水
- 中国は国が宗教を管理する。韓国はキリスト教が多く、台湾は民間信仰・道教がさかん
