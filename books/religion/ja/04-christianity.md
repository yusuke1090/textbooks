# 4. キリスト教

## この章でわかること

- キリスト教のあらましと、イエスの教え
- ローマ帝国から世界へ広がった歴史
- カトリック・正教会・プロテスタントのちがい
- 行事と、日本のキリスト教

## あらまし

| 項目 | 内容 |
| --- | --- |
| 信者 | 約23億人（2020年）。世界でいちばん多い宗教 |
| 多い国 | アメリカ、ブラジル、メキシコ、フィリピン、ロシア、ナイジェリア、コンゴ民主共和国など |
| 開いた人 | イエス（前4年ごろ〜30年ごろ）。信者は「キリスト（救い主）」とよぶ |
| 神 | 唯一の神。父なる神・子なるイエス・聖霊が、ひとつの神であるとする（三位一体） |
| 聖典 | 聖書。ユダヤ教から受けついだ「旧約聖書」と、イエスと弟子たちのことを書いた「新約聖書」 |
| 祈る場所 | 教会 |
| 指導者 | 神父（カトリック）、司祭（正教会）、牧師（プロテスタント） |
| 聖地 | エルサレム（イエスが死に、復活したとされる場所）、ローマのバチカン（カトリックの中心） |

## 始まりと歴史

| いつ | できごと |
| --- | --- |
| 前4年ごろ | イエスがベツレヘムで生まれる（いまの西暦の数え方は、イエスの誕生を基にしたが、少しずれている） |
| 30年ごろ | イエスが神の国が近いと説き、病人を治し、貧しい人や罪人とされた人と交わる。ユダヤ教の指導者と対立し、ローマ帝国によって十字架で処刑される。弟子たちは「3日目に復活した」と信じて広める |
| 1世紀 | パウロらが、ユダヤ人以外にも広める。ローマ帝国の中で、くり返し迫害を受ける |
| 313年 | ローマ帝国がキリスト教を認める（ミラノ勅令） |
| 392年 | ローマ帝国の国の宗教になる |
| 1054年 | 西のローマ・カトリック教会と、東の正教会に分かれる |
| 1096〜1291年 | 十字軍。ヨーロッパの国々が、聖地エルサレムを取るためにくり返し兵を送る |
| 1517年 | ドイツのルターが教会のやり方を批判し、宗教改革が始まる。プロテスタントが生まれる |
| 16世紀〜 | スペイン・ポルトガルの船とともに、中南米・アフリカ・アジアに広がる。1549年にザビエルが日本に来る |
| 19〜20世紀 | 宣教師がアフリカ・アジア・太平洋の島々に広める |
| 2020年 | 信者がいちばん多い地域が、ヨーロッパからサハラより南のアフリカになる |

## 何を信じるか

- **神の愛**: 神は人を愛している。人も神を愛し、**隣人を自分のように愛しなさい**（イエスがいちばん大事だとした2つの教え）
- **罪と救い**: 人はみな罪を持っている。神の子イエスが十字架で死に、人の罪をつぐなった。イエスを信じる人は救われ、永遠の命を受ける
- **復活**: イエスは死んで3日目によみがえった。キリスト教でいちばん大事な出来事
- **終わりの日**: いつかイエスがもう一度来て、世界を裁き、神の国が完成する
- イエスの教えは、たとえ話（よいサマリア人、放蕩息子など）や「山上の説教」（「心の貧しい人は幸い」「敵を愛しなさい」）で伝えられています

## 3つの大きな流れ

| | カトリック | 正教会 | プロテスタント |
| --- | --- | --- | --- |
| 人数 | 約14.2億人（バチカンの数え方、2024年） | 約2〜3億人 | 約8〜9億人（いくつもの教派の合計） |
| 中心 | ローマ教皇（バチカン） | 国ごとの教会（ロシア正教会、ギリシャ正教会など）。コンスタンティノープル総主教が名目上の第一 | 中心はない。聖書だけをよりどころにする |
| 特徴 | 7つの秘跡（洗礼・ミサの聖体など）、聖母マリアや聖人を敬う。神父は結婚しない | イコン（聖人の絵）を大切にする。古い形の礼拝。司祭は結婚できる | 信仰と聖書を大事にする。牧師は結婚できる。教派がとても多い |
| 多い所 | 中南米、南ヨーロッパ、ポーランド、フィリピン、アフリカ | ロシア、東ヨーロッパ、ギリシャ。エチオピアなどの東方諸教会も近い | 北ヨーロッパ、ドイツ北部、イギリス、アメリカ、アフリカ、韓国 |

- プロテスタントの教派: ルター派（北欧・ドイツ）、改革派・長老派（スイス・オランダ・スコットランド・韓国）、聖公会（イングランド国教会）、バプテスト、メソジスト、ペンテコステ派など
- **ペンテコステ派・福音派**は、聖霊の力・いやし・熱心な礼拝を重んじ、アフリカ・中南米・アジアで急に増えています
- キリスト教から生まれた新しい団体に、末日聖徒イエス・キリスト教会（モルモン教）やエホバの証人などがあります。考え方が大きくちがうので、ふつうの教会とは別に扱われます

## きまりと行事

| 行事 | いつ | 中身 |
| --- | --- | --- |
| 礼拝・ミサ | 毎週日曜 | 日曜はイエスが復活した日。教会に集まって祈り、賛美歌を歌い、聖書の話を聞く |
| 洗礼 | 信者になるとき | 水で清めて信者になる。カトリックや正教会では、赤ちゃんのうちに受けることが多い |
| 聖餐（ミサ・聖体） | 礼拝のとき | パンとぶどう酒をいただき、イエスの最後の晩さんを思い出す |
| クリスマス | 12月25日（正教会の多くは1月7日） | イエスの誕生を祝う |
| 四旬節 | 復活祭の前の約40日 | 食事やぜいたくをひかえて祈る |
| 復活祭（イースター） | 3〜4月（春分の後の最初の満月の次の日曜） | イエスの復活を祝う。いちばん大事な祭り。卵がしるし |

- 食べ物の決まりはほとんどありません。ただし、正教会では肉や乳製品を食べない断食の期間が多く、カトリックでも金曜に肉を食べない習慣がある所があります

## 世界のキリスト教

![ラリベラの聖ギオルギス教会（エチオピア）。12〜13世紀に、岩を上から掘り下げて作られた](images/lalibela.jpg)

![ナイジェリアの教会の礼拝。アフリカではキリスト教徒が増えている](images/nigeria-church.jpg)

![クリスマス前の夜明けのミサ「シンバン・ガビ」（フィリピン）](images/simbang-gabi.jpg)

- **アフリカ**: エチオピアには4世紀から教会があります。19〜20世紀に宣教師が広め、いまはアフリカ人が始めた独立教会やペンテコステ派も多い
- **中南米**: 16世紀にスペイン・ポルトガルが持ちこみ、カトリックの地域になりました。いまは福音派が急に増えています（ブラジルなど）
- **韓国**: 人口の約3割がキリスト教徒。ソウルには世界最大級の教会があります
- **ヨーロッパ・北アメリカ**: 教会に行く人が減り、無宗教が増えています。使われなくなった教会が、住宅や店になることもあります
- 2025年4月にフランシスコ教皇が亡くなり、5月にアメリカ出身のレオ14世が初めて教皇に選ばれました

## 日本のキリスト教

- 1549年、イエズス会のザビエルが鹿児島に来て広めました。キリシタン大名も生まれ、信者は数十万人になったといわれます
- 1614年に江戸幕府が禁止し、1637〜38年の島原・天草一揆のあと、取りしまりがさらに厳しくなりました。信者は「潜伏キリシタン」として、ひそかに信仰を守りました
- 1865年、長崎の大浦天主堂で、潜伏キリシタンが神父に信仰を打ち明けました（信徒発見）。1873年に禁止の高札が下ろされました
- いまの信者は、人口の約1%です。それでも、ミッション系の学校や病院、教会式の結婚式、クリスマスなどで、キリスト教は身近にあります（10章）

## まとめ

- イエスを救い主（キリスト）と信じ、神の愛と隣人愛を説く。十字架の死と復活が中心
- カトリック・正教会・プロテスタントの3つの大きな流れ
- 信者がいちばん多い宗教。いまはアフリカと中南米で増え、ヨーロッパ・北アメリカで減っている
