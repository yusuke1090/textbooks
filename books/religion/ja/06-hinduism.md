# 6. ヒンドゥー教

## あらまし

| 項目 | 内容 |
| --- | --- |
| 信者 | 約12億人（2020年）。世界で3番目に大きい宗教 |
| 多い国 | インド（世界の信者の約95%）、ネパール（人口の81%）、バングラデシュ、モーリシャス（48%）。インドネシアのバリ島。移民でアメリカ・イギリス・中東にも |
| 開いた人 | いない。インドの暮らしの中で、3,000年以上かけてできあがった |
| 神 | たくさんの神々。ブラフマー（つくる）・ヴィシュヌ（守る）・シヴァ（こわして新しくする）が三大神。人々は自分が好きな神を選んで信じることが多い |
| 聖典 | ヴェーダ（いちばん古い）、ウパニシャッド（哲学）、叙事詩『マハーバーラタ』（その中の『バガヴァッド・ギーター』）と『ラーマーヤナ』 |
| 祈る場所 | 寺院（マンディル）と、家の祭壇 |
| 聖地 | ガンジス川（ガンガー）とその岸のバラナシなど |

- 「ヒンドゥー」は、もとはペルシャ語で「インダス川の向こうの人」という意味です。信者自身は「サナータナ・ダルマ（永遠の法）」とよぶこともあります

| 神 | 役わり・すがた |
| --- | --- |
| ヴィシュヌ | 世界を守る。困ったときに姿を変えて現れる（化身）。ラーマやクリシュナは化身 |
| シヴァ | 世界をこわし、新しくする。踊りの神、修行者の神。リンガ（石の柱）で表されることも |
| ブラフマー | 世界をつくる。ただし、ブラフマーを中心に祭る寺はとても少ない |
| ガネーシャ | 象の頭の神。始まりと商売の神。何かを始めるときに拝む |
| ラクシュミー | 富と幸運の女神（ヴィシュヌの妻） |
| サラスヴァティー | 学問・芸術の女神 |
| ドゥルガー・カーリー | 悪と戦う強い女神 |
| ハヌマーン | 猿の神。ラーマを助けた |

## 始まりと歴史

| いつ | できごと |
| --- | --- |
| 前2600〜前1900年ごろ | インダス文明。のちのヒンドゥー教につながる要素もあったと考えられている |
| 前1500年ごろ | アーリヤ人がインド北西部に入り、神々への賛歌「ヴェーダ」と、火の儀式をつかさどる祭司（バラモン）の宗教（バラモン教）ができる |
| 前800〜前500年ごろ | ウパニシャッドの哲学。輪廻と解脱の考えがまとまる。前5世紀ごろ、仏教とジャイナ教が生まれる |
| 前後数百年 | 叙事詩と法典（『マヌ法典』）ができ、民間の神々の信仰と合わさって、いまのヒンドゥー教の形になっていく |
| 4〜6世紀 | グプタ朝。寺院と神像の信仰が広まる |
| 6世紀〜 | 神へのひたすらな愛を説く「バクティ」の運動が南インドから広がる。東南アジアにも伝わる（カンボジアのアンコール・ワットは、もとはヴィシュヌの寺） |
| 13〜19世紀 | 北インドをイスラム教の王朝（ムガル帝国など）が治める |
| 19世紀 | イギリスの植民地のもとで、改革の運動が起こる |
| 1947年 | インドとパキスタンが、宗教によって分かれて独立。多くの人が移動し、争いで多くの人が亡くなった |

## 何を信じるか

| 考え | 中身 |
| --- | --- |
| 輪廻（サンサーラ） | 生き物は死んでも、また何かに生まれ変わる。これがずっと続く |
| 業（カルマ） | よい行いはよい結果を、悪い行いは悪い結果を生み、次の生まれ方を決める |
| 解脱（モークシャ） | 輪廻のくり返しから抜け出すことが、最後の目標 |
| ブラフマンとアートマン | 宇宙の根本（ブラフマン）と、自分の本当の姿（アートマン）は、もともと同じ（梵我一如）。これを悟ると解脱できる |
| ダルマ | その人が守るべきつとめ・正しい生き方 |
| 解脱への道 | 知恵の道（哲学・瞑想）、行いの道（見返りを求めずにつとめを果たす）、信愛の道（神をひたすら愛する）。ヨーガも修行の方法のひとつ |

## カースト

- ヒンドゥー教の社会では、生まれによって身分と職業が決まる仕組みが続いてきました
- **ヴァルナ**: バラモン（祭司）・クシャトリヤ（王・戦士）・ヴァイシャ（商人など）・シュードラ（それ以外の働き手）の4つ。その外に置かれ、ひどい差別を受けてきた人々がいます（いまは「ダリット」とよばれる）
- **ジャーティ**: 実際の暮らしでは、職業や地域ごとの数千の集まり（ジャーティ）が、結婚相手や付き合いを決めてきました
- インドの憲法（1950年）はカーストによる差別を禁じ、大学の入学や公務員に、ダリットなどの枠を設けています。それでも、結婚や村の暮らしには、いまも影響が残っています
- カーストに反対して、仏教・キリスト教・シク教に改宗した人も多くいます（7章のアンベードカル）

## きまりと暮らし

| きまり | 中身 |
| --- | --- |
| 牛 | 牛は神聖な生き物。牛肉を食べない人がほとんど。多くの州で牛を殺すことが法律で禁じられている |
| 菜食 | 肉・魚・卵を食べない菜食の人が多い（特にバラモンや、南インド・西インド）。食べる人も、牛肉は避けることが多い |
| プージャー | 神の像に花・灯明・お香・食べ物をささげて拝む。家の祭壇でも毎日行う |
| しるし | 額の印（ティラカ）。既婚の女性が額に付ける赤い点（ビンディ）や、髪の分け目の赤い粉 |
| 人生の儀式 | 名付け、聖なるひもを授かる儀式、結婚式（火のまわりを7回まわる） |
| 葬式 | 火葬にして、灰を川に流す。ガンジス川が特に尊ばれる |

## いまの様子

- インドでは、ヒンドゥー教の考えを国の中心にしようとする「ヒンドゥー・ナショナリズム」が強まり、インド人民党（BJP）が政権を担っています。イスラム教徒などの少数派との関係が、国の内外で議論になっています
- ネパールは、2006〜08年に「ヒンドゥー教の王国」から世俗の国に変わり、王制もやめました
- ヨーガと瞑想は、宗教をはなれて世界中に広まりました

## まとめ

- 開祖のいない、インドで3,000年以上かけてできた宗教。神々がたくさんいる
- 輪廻・業・解脱。ダルマ（つとめ）を果たして生きる
- 牛を神聖とし、菜食の人が多い。ディーワーリーとホーリーが大きな祭り
- 信者の95%はインドにいる。日本の弁天や大黒天は、もとはインドの神
