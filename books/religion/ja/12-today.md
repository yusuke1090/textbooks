# 12. 宗教といまの世界

## この章でわかること

- 国と宗教の関係（国の宗教、政教分離、宗教を制限する国）
- 宗教が関わる争いを、どう見ればよいか
- 仕事や旅行で、宗教について気をつけること

## 国と宗教の関係

| 形 | 中身 | 例 |
| --- | --- | --- |
| 国の宗教を決めている | 憲法などで、特定の宗教を国の宗教や特別な宗教とする。ほかの宗教も認めることが多い | イギリス（イングランド国教会）、デンマーク（ルター派）、サウジアラビア・イラン（イスラム教）、マレーシア（イスラム教）、カンボジア（仏教） |
| 宗教の法で国を治める | 宗教の法（イスラム法など）を、国の法律のもとにする | サウジアラビア、イラン、アフガニスタン |
| 政教分離 | 国は特定の宗教を支えず、宗教も政治の力を持たない | 日本、アメリカ、フランス、トルコ、インド |
| 宗教を制限する | 国が宗教を管理し、活動を制限する | 中国、北朝鮮 |

- 政教分離にも、いろいろな形があります
  - **アメリカ**: 国の宗教を作らないが、宗教は社会の中で大きな力を持つ。大統領が聖書に手を置いて就任の宣誓をする
  - **フランス**: 「ライシテ」。公の場から宗教を遠ざけることを重んじ、2004年から公立の学校で、目立つ宗教のしるし（スカーフ、大きな十字架、キッパなど）を身に着けることを禁じている
  - **日本**: 憲法20条で信教の自由と、国が宗教活動をしないことを、89条で宗教団体に公のお金を使わないことを定めている
  - **インド**: 憲法は世俗国家だが、結婚や相続には宗教ごとの法律がある

## 世俗化と、宗教が強くなる動き

- ヨーロッパ・北アメリカ・東アジアでは、宗教を信じない人が増えています（世俗化）
- 一方、アフリカ・中東・南アジアなどでは、宗教はいまも暮らしと政治の中心にあり、人口の増え方も大きいので、世界全体では宗教を持つ人が4人に3人のままです
- 宗教を政治の力にしようとする動き（宗教ナショナリズム）が、いろいろな国で見られます

## 宗教が関わる争い

宗教がちがうことだけで争いが起こることは、実はあまり多くありません。土地・民族・貧しさ・政治の力が重なり、宗教が「どちらの側か」を表すしるしになることが多いのです。

| 地域 | 中身 |
| --- | --- |
| イスラエルとパレスチナ | ユダヤ人の国イスラエルと、パレスチナのアラブ人（多くはイスラム教徒、一部キリスト教徒）の、土地と国をめぐる争い。エルサレムの聖地が重なることも問題を難しくしている |
| 北アイルランド | カトリック（アイルランドとの統一を望む人が多い）とプロテスタント（イギリスに残ることを望む人が多い）の争い。1998年の和平合意で大きな争いは終わった |
| インドとパキスタン | 1947年の分離独立と、カシミール地方をめぐる対立 |
| ミャンマー | イスラム教徒の少数民族ロヒンギャが迫害され、2017年に70万人以上が隣のバングラデシュへ逃れた |
| ナイジェリア・サヘル地域 | イスラム過激派の武装組織による襲撃。土地や水をめぐる農民と牧畜民の争いと重なる |
| 中東（イラク・シリアなど） | スンニ派とシーア派の対立が、国どうしの争いと重なる。2014年からは過激派組織 IS が広い地域を支配した |

- 過激派の暴力は、その宗教のほとんどの信者が反対しています。ひとつの事件で、その宗教全体を決めつけないことが大事です
- 一方で、宗教は、病院・学校・貧しい人の支援・災害のときの助け合い・和平の仲立ちなど、社会を支える大きな力にもなっています

## 仕事や旅行で気をつけること

### 食べ物

| 宗教 | 気をつけること |
| --- | --- |
| イスラム教 | 豚肉と豚から作ったもの（ラード・ゼラチン・ブイヨン）、酒（料理に使うみりんや酒も）を避ける。ハラールの認証のある店や食品 |
| ユダヤ教 | コーシャ。豚・えび・貝を避け、肉と乳製品を一緒にしない |
| ヒンドゥー教 | 牛肉を避ける。菜食の人が多い |
| ジャイナ教 | 肉・魚・卵に加え、根菜を食べない人も |
| 仏教 | 僧や熱心な人は肉や酒を避けることがある（精進料理） |
| シク教 | 牛肉を避ける人が多い。たばこと酒を避ける |

- 食事に招くときや会食の店を選ぶときは、まず相手に「食べられないものはありますか」と聞くのがいちばん確かです
- 料理の材料をはっきり書いた表示や、ベジタリアン・ハラールの印は、外国から来た人の大きな助けになります

### 祈りと休み

| 宗教 | 気をつけること |
| --- | --- |
| イスラム教 | 1日5回の礼拝。会議や行事の予定に、礼拝の時間と場所（静かな部屋）を考える。ラマダン中は昼間に食べないので、昼食会を避け、相手の前で飲み食いするのに気を配る。金曜の昼は大事な礼拝 |
| ユダヤ教 | 金曜の日没から土曜の日没までは安息日。仕事や移動を避ける人がいる |
| キリスト教 | 日曜は礼拝と休みの日。クリスマスと復活祭の時期は、欧米の会社が長く休む |
| ヒンドゥー教 | ディーワーリーの時期は、インドの会社の休みとお祝いの時期 |

### 宗教の建物に入るとき

- 肌を出しすぎない服で（肩・ひざをかくす）。モスクでは、女性は髪をスカーフでおおうよう求められることが多い
- モスク・ヒンドゥー教やジャイナ教の寺院・グルドワーラー・日本の寺の建物では、靴を脱ぐ。グルドワーラーでは頭を布でおおう
- 礼拝中の人の前を横切らない。写真をとってよいか確かめる
- タイなどでは、人の頭（特に子どもや僧の頭）にさわらない。女性は僧にさわらない

### 話すとき

- 相手の宗教を決めつけず、知りたいことがあれば、ていねいに聞く
- 冗談やからかいのたねにしない。神や預言者を描いた絵や言葉に、強い思いを持つ人もいる
- 同じ宗教でも、国・宗派・人によって、決まりの守り方は大きくちがう。「イスラム教徒だから必ずこうする」と考えず、その人に合わせる

## まとめ

- 国と宗教の関係は、国の宗教・宗教の法・政教分離・宗教の制限とさまざま
- 争いの多くは、土地・民族・政治が宗教と重なって起こる。ひとつの事件で宗教全体を決めつけない
- 食べ物・祈り・休み・服装の決まりを知り、わからないときは相手に聞く
