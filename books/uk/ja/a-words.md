# 付録A. 農業と酪農の英語

イギリスの農家・ニュース・展示会でよく聞く言葉です。アメリカとちがう言い方には（英）を付けました。

## 畑と作物

| 英語 | 意味 |
| --- | --- |
| arable | 畑作（の） |
| combinable crops | コンバインで刈る作物（麦・菜種・豆） |
| winter wheat / spring barley | 秋まき小麦 / 春まき大麦 |
| oilseed rape（OSR） | 菜種（英）。アメリカでは canola |
| sugar beet | てんさい |
| drilling | 種まき（種をまく機械 = drill） |
| tillage / min-till / no-till | 耕すこと / 少しだけ耕す / 耕さない |
| cover crop | 被覆作物（畑を休ませる間に植える） |
| yield（t/ha） | 収量（1 ha あたりのトン） |
| headland | 畑の端の、機械が回る所 |
| hedgerow / dry stone wall | 生け垣 / 石垣 |
| polytunnel | ビニールの簡易ハウス |

## 家畜と酪農

| 英語 | 意味 |
| --- | --- |
| dairy herd | 乳牛の群れ |
| cow / heifer / calf | 子を産んだ雌牛 / まだ産んでいない若い雌牛 / 子牛 |
| bull / steer / bullock | 雄牛 / 去勢した雄牛（米）/ 去勢した雄牛（英） |
| calving / block calving | 分娩 / 季節を決めていっせいに分娩させること |
| dry cow | 乾乳牛（搾らずに休ませている牛） |
| milking parlour | 搾乳室（英。アメリカは parlor） |
| robotic milking / AMS | 搾乳ロボット（automatic milking system） |
| cubicle housing | フリーストールの牛舎（英） |
| grazing / paddock | 放牧 / 放牧地の区画 |
| silage / clamp | サイレージ / サイレージを詰める所（英。bunker） |
| slurry | ふん尿の混ざった液体 |
| ppl（pence per litre） | 1リットルあたりのペンス（乳の値段） |
| milk recording | 乳検（1頭ずつの乳量と成分の検査） |
| SCC（somatic cell count） | 体細胞数（乳房炎の目安） |
| bulk tank | バルククーラー（乳を冷やすタンク） |
| mobility score / lameness | 歩様スコア / 跛行（足の悪さ） |
| BCS（body condition score） | ボディコンディションスコア（太り具合） |
| bTB（bovine TB） | ウシ結核 |
| ewe / ram / lamb / tup | 雌羊 / 雄羊 / 子羊 / 雄羊（北イングランドの言い方） |

## お金と制度

| 英語 | 意味 |
| --- | --- |
| Defra | 環境・食料・農村省（イングランドの農業の役所） |
| AHDB | 農業・園芸開発委員会（統計と研究） |
| NFU | 全国農業者組合 |
| BPS | 基本支払い（EU 時代の面積の補助金。2027年でなくなる） |
| ELM / SFI | 環境土地管理 / 持続可能な農業のインセンティブ |
| APR | 農業財産控除（相続税の軽減） |
| aligned contract | スーパーと組んだ乳の契約 |
| Red Tractor | イギリスの農産物の品質・安全の認証 |
| TIFF（total income from farming） | 農業の所得の合計 |
| contractor | 作業を請け負う人（刈り取り・散布などを頼む相手） |

## よく聞く言い方

| 英語 | 意味 |
| --- | --- |
| How's the herd doing? | 牛の調子はどう？ |
| We're out on grass. | （牛を）放牧に出している |
| She's bulling. | （その牛は）発情している |
| The milk cheque | 乳代（毎月の乳の代金） |
| It's been a wet one. | 雨の多い（年・季節）だった |
| Cheers / Ta | ありがとう |
