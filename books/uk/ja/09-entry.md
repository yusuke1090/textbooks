# 9. イギリスで農業の IoT をするなら

アフリカの教科書の9章（タンザニア・ケニア・マラウイ）とくらべながら読むと、ちがいがよくわかります。

## 良いところ・難しいところ

| 良いところ | 難しいところ |
| --- | --- |
| 英語で仕事ができる。法律と契約がしっかりしている | ヨーロッパとアメリカの大きな会社（レリー、デラバル、GEA、ディア、MSD など）がすでにいる |
| 人が高く、農場が大きいので、機械とデータにお金を払う | 農家はもうけに厳しく、乳と小麦の値段で予算がすぐ変わる |
| 補助金と研究の場所が多く、試験をしやすい | 新しい製品を試すのに慎重。農家どうしの口コミが大事 |
| 酪農家はスマホとデータに慣れている | 電波の届かない農場が多い |
| 日本の機械（クボタなど）の評判が良い | 時差9時間、移動に14時間ほど（直行便） |

- アフリカ（とくにケニア・タンザニア）は「これから伸びる、安さが一番の市場」、イギリスは「もう大きくて、質と結果を求める市場」です

## 製品を売るための決まり

| 項目 | 中身 |
| --- | --- |
| **製品の安全と認証** | EU の **CE マーク**がイギリス（GB）でも期限なく認められている（無線機器を含む多くの製品）。イギリス独自の **UKCA マーク**でもよい。北アイルランドは CE がいる |
| **電波** | ヨーロッパと同じ帯を使う。LoRaWAN・Sigfox などは **868 MHz**（日本は920 MHz）。日本の技適の機器は、そのままでは使えない。イギリス向けの周波数の機器を用意する |
| **つながる機器のセキュリティ** | 2024年4月から、ネットにつながる製品は「初期パスワードを全部同じにしない」「弱点の報告の窓口を出す」「更新をいつまで出すか示す」の3つが義務（PSTI 法） |
| **データ** | **UK GDPR**（EU の個人情報の決まりとほぼ同じ）。農家の名前・場所・連絡先は個人情報。データをどこに置き、だれが使えるかを契約で示す |
| **電気** | 230 V・50 Hz、プラグは3ピンの BF 型 |
| **家畜の決まり** | 牛は全頭に耳標が付き、生まれた・動いた・死んだを国に届ける。体に付ける機器は、動物福祉の点からも説明できるようにする |

- CE マークで売るときは、EU の決まりを全部守り、EU 内の輸入者か代理人の名前を書く必要があります

## 進め方

### 1. 調べる

- 統計と市場: **AHDB**（牛乳の値段・頭数・生産費）、Defra の農業統計
- ニュース: 農業の新聞（Farmers Weekly、Farmers Guardian）、農家の団体（NFU）
- 日本の窓口: **JETRO ロンドン**（市場調査、展示会の日本のブース、会社の作り方の相談）

### 2. 展示会と農業ショーに行く

![ロイヤル・ハイランド・ショー（エディンバラ）の牛の審査。農業ショーは、農家と直接 話せる場所](images/highland-show.jpg)

| 名前 | いつ・どこ | 中身 |
| --- | --- | --- |
| **LAMMA** | 1月、バーミンガム | 農業機械とテクノロジー。イギリス最大級 |
| **Dairy-Tech** | 2月、ストーンリー（コヴェントリーの近く） | 酪農の技術だけの展示会 |
| **Cereals** | 6月 | 畑作。畑で実際に機械を動かして見せる |
| **Groundswell** | 6月末〜7月、ハートフォードシャー | 環境再生型の農業（不耕起・被覆作物など） |
| **Royal Highland Show** | 6月、エディンバラ | スコットランドの大きな農業ショー |
| **Royal Welsh Show** | 7月、ビルス・ウェルズ | ウェールズの大きな農業ショー |
| **UK Dairy Day** | 9月、テルフォード | 酪農家が集まる。牛の品評会と展示 |

- 夏の農業ショーは、地元の農家が家族で来る「お祭り」です。売り込みより、まず話を聞く場所と考えます

### 3. 試験をする

- 大学や研究農場（ハーパー・アダムズ、SRUC、ロザムステッドなど）と組んで、数字（何頭の病気を何日早く見つけたか、何ポンド得したか）を出す
- Innovate UK の補助金は、イギリスで登記した会社が申し込むのがふつうです
- イギリスの会社（Ltd）は、ネットで1日ほど、数十ポンドで作れます

### 4. 売る

- 農家に直接より、**農家がすでに信頼している人**を通すのが近道です
  - 農業機械の販売店（ディーラー）
  - 獣医（酪農家は月に何回も獣医と会う）
  - 乳業メーカーとスーパー（アラインド契約の農家に、データの記録を求めている。7章）
  - 酪農のコンサルタント、牛乳の検査の会社
- 値段は、買い切りより、**月額**（1頭あたり、1農場あたり）が多い。農家にとって最初の負担が小さい

![クボタのトラクター。日本の農業機械は、イギリスでも小〜中型のトラクターや芝刈りの機械で使われている](images/kubota.jpg)

## 日本の会社

- **クボタ**: イギリスに販売の会社（クボタ UK、オックスフォードシャー）。トラクター・小型の建設機械・芝刈り機
- **ヤンマー**、**イセキ**: 販売店を通して、小型のトラクターや機械を売る
- 日本の会社は「壊れにくい」「部品が手に入る」という評判があり、これは新しい製品を売るときの追い風になります

## 酪農の IoT で考えられること

| 課題（7章） | IoT でできそうなこと |
| --- | --- |
| 人手が足りない | 発情・分娩・病気の知らせで、見回りの時間を減らす |
| 跛行（足の悪さ）の記録が求められる | カメラで歩き方を自動で点数に。乳業メーカーへの報告もそのまま出す |
| 放牧の草の管理 | 草の量を測る（衛星・ドローン・測る板）、牛の居場所（GPS） |
| ウシ結核 | 牛どうし、牛と野生動物の接触の記録。検査の日程の管理 |
| 乳の値段と生産費 | 乳量・エサ・費用のデータをまとめ、1 L あたりの生産費を出す |
| 環境（スラリー・メタン） | タンクの水位、まいた量と場所の記録。メタンの見える化 |
| 電波が届かない | LoRaWAN（868 MHz）のゲートウェイを農場に置く。衛星との組み合わせ |

- すでにある製品（7章の SenseHub、CowManager、CattleEye など）と、**何がちがうのか**（安い・電池が長い・放牧で使える・ほかのデータとつながる）を、ひとことで言えるようにすることが大事です
- 酪農の群れはイギリスのほうが日本より大きく、データの見せ方（何百頭を一覧で）も変わります

## まとめ

- イギリスは「お金を払う理由がある、成熟した市場」。そのかわり、競争が激しく、結果の数字が求められます
- 電波（868 MHz）・認証（CE/UKCA）・セキュリティ（PSTI）・データ（UK GDPR）を、最初から製品に入れておく
- 展示会と農業ショーで話を聞き、大学や獣医・販売店と組んで、小さく試してから広げる
