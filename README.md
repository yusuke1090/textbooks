## 本棚の「今日の勉強」

- 本棚の一番上に、今日 勉強した時間と1日の目標（5〜60分から選ぶ、はじめは15分）の輪、🔥 連続日数（目標に届いた日が続いた日数）と最長記録、▶ 続きから（最後に開いた本の、読んでいた章）、旅の地図を出す
- 旅（教科書をめぐる世界一周）: これまでに勉強した時間の合計で、東京 → 京都 → 北京 → … → ナイロビ → … → ロンドン → エディンバラ → 東京 と進む（27町・全部で90時間。最初は30分・1時間で次の町に着き、だんだん長くなる。東京に帰ると2周目）。地図は今の町と次の町に寄り、道に1日ごとの足あと（その日の勉強が終わったところ）。下に着いた町の写真（押すと大きく、着いた日と写真の出典）。町に着くと、読む画面にその町の写真のお祝いが出る
- 旅日記: 勉強した日ごとに、その日の終わりにいた町のおみやげ（町ごとに1つ、STOPS の最後）・日付・分の棒（15分に届いた日は金色）・着いた町。新しい3日分で、「もっと見る」で全部。押すとその日の時間とおみやげの名前
- 町・時間・写真は `tools/make_trip.py` の STOPS。写真は教科書の写真（books/<id>/images）を使う。`python3 tools/make_trip.py <フォルダ>` で `trip/trip.json`（町と地図）と `trip/<町>.jpg`（小さい写真）を作る。地図は [Natural Earth](https://www.naturalearthdata.com/)（パブリックドメイン）の ne_50m_land・ne_50m_lakes の geojson をフォルダに入れておく
- 時間は、読む画面が見えていて、2分以内に操作（スクロール・タップ・入力など）があったときと、読み上げ中だけ、10秒ずつ数える
- 目標に届くと、読む画面に 🎉 が出る（1日1回）
- 記録は `textbooks-study`（日ごとの秒数・目標に届いた日・目標）と `textbooks-last`（最後に開いた本）。iPhone と PC では別々

## スマホと PC で記録を合わせる（ID とパスワードでログイン）

本棚の右上の「☁ ログイン」で、ID とパスワードでログインすると（はじめは「はじめて使う（登録）」）、勉強時間・連続日数・続きから・練習問題の結果・単語のチェック・付箋と線とメモ・今勉強中の並びを、スマホと PC で合わせる（Firebase の Authentication のメール/パスワードと Firestore。`sync.js`）。ID とパスワードが同じなら同じ人。Firebase の中では ID を `ID@textbooks.example.com` の形のメールアドレスとして使う（メールは送らない）。

- 勉強時間は端末ごとに記録して足す（本棚の「今日の勉強」に「2台の合計」と出る）。ほかの記録は、あとで変えたほうを使う
- ログインする前からその端末にあった記録は、最初のログインのときに、付箋・練習問題・単語のチェック・今勉強中の並びは足し合わせ、ほかはすでにあるほうを使う
- 変えた記録は 8秒ごとと、ページを離れるときに送る。ほかの端末の変更は、すぐ届く（本棚は描き直す）
- `firebase-config.js` が `null` のあいだは、ログインの欄を出さず、記録は今までどおり端末の中だけ

### Firebase の設定（最初の1回、本人の Google アカウントで）

1. https://console.firebase.google.com を開き、「プロジェクトを作成」。名前は `textbooks`、Google アナリティクスはオフでよい
2. プロジェクトのトップで「ウェブ」（`</>`）のアイコンを押してアプリを追加。名前は `textbooks`、Firebase Hosting にはチェックしない。出てくる `firebaseConfig`（apiKey・authDomain・projectId・appId など）を写して Claude に渡す（公開してよい値。`firebase-config.js` に入れる）
3. 左の「構築 → Authentication → 始める → Sign-in method」で **メール / パスワード** を有効にする（「メールリンク」はオフのまま）
4. 左の「構築 → Firestore Database → データベースを作成」。場所は `asia-northeast1`（東京）、本番環境モード。できたら「ルール」に `firestore.rules` の中身を貼って「公開」

無料の範囲（1日に読み 5万回・書き 2万回）で足りる。記録は `users/{ログインした人}/kv/{キー}` に置き、ルールで本人だけが読み書きできる。

[スマート農業News](https://github.com/yusuke1090/smart-agri-news) も同じ Firebase とログインを使い、☆ お気に入りと 🔤 の履歴を同じ置き場所に `agri-news-` のキーで置く（教科書の `sync.js` は `textbooks-` のキーしか使わない）。同じ `yusuke1090.github.io` なので、どちらかでログインすれば両方でログインしている。

## 読む画面でできること

- **目次**: 部ごとに章が並ぶ。章の ▶ で小見出しが開き、押すとその見出しの所へ移る
- **◀ ▶** で前後の章へ。開き直すと、前に読んでいた章の、読んでいた所から出る
- **日本語 / English**（2つの言葉がある教科書）: 同じ章の、同じ見出しの所が出る
- **図**: 下に「図 9-1 説明」が付く。押すと大きく表示する
- **言葉の説明**: 本文の点線の言葉（用語集にある言葉。章ごとに最初の1回）や、コードの関数・引数・コマンドを押すと、吹き出しで意味が出る
- **付箋・線・メモ**: 文字を選ぶと、線（黄・ピンク・緑・青）・📝 メモ・📌 付箋・🔤 訳すのボタンが出る。🔖 で一覧を開き、押すとその場所へ飛ぶ。コードの中で言葉を選んだとき（ダブルクリック・長押し）は、ボタンではなく言葉の説明が出る
- **練習問題**: 章の最後にある。答えを入力して「回答」を押すと、⭕ / ❌ と答え・解説が出る（押すまで答えは出ない）。本棚のカードに、その本の正答率（問題ごとに、画面を開いて最初に答えた結果）が出る。「今勉強中」のカードには、問題ごとの結果が ●（正解）×（まちがい）○（まだ）で章ごとに並ぶ（「クリア」で ● × を消せる。答えの履歴は残る）。入れた答えは毎回残り、問題の下の「これまでの答え」を開くと新しい順に見られる（問題ごとに30回まで）
- **🔊 音声**: 英文の箱（IELTS の教科書）の ▶ で、ブラウザの読み上げが英文を読む。「ゆっくり」で遅く、「スクリプトを見る」で文字が出て、読んでいる行に色が付く
- **単語帳**（IELTS の教科書）: 話題の一覧（まとまりごとのカード、語数とチェックの数つき）から話題を選ぶと、20語ずつのページで出る。下のページ番号と「次の話題へ」で進み、次に開くと前に見ていた所から出る。わからない単語の ○ でチェックし、「✓ 見直す」で全部の話題からチェックした単語だけを出す。「意味を隠す」で自分でテスト（押すと出る）、検索、🔊 で発音。チェックは `textbooks-words-<教科書>`、見ていた所は `textbooks-words-view-<教科書>` に保存
- **コード**: 「コピー」ボタンで写せる
- **数式**: `math` を付けた教科書（統計・機械学習）は、`$…$` の式を [KaTeX](https://katex.org/) で表示する（そのときだけ cdnjs から読み込む）
- **🔤 訳す**: 英語の単語や文を、日本語に訳す（[スマート農業News](https://github.com/yusuke1090/smart-agri-news) の `translate.js` を読み込んで使う）

付箋・線・メモと、読んでいた所と、練習問題の結果は、見ているブラウザの `localStorage` に保存する（`textbooks-notes`、`textbooks-pos-<教科書>`、`textbooks-quiz-<教科書>`、答えの履歴は `textbooks-quizlog-<教科書>`）。iPhone と PC では別々。
場所は「選んだ文字・前後の文字・だいたいの位置」で覚えるので、本文を直しても、その文字が残っていれば同じ所に付く。

## 教科書を足す

1. `books/<id>/` を作り、章の Markdown と `chapters.json` を置く
2. `books.json` に1つ足す（`id`・`icon`・`group`・`langs`・`title`・`desc`。本棚は `group`（プログラミング・データ・道具・農業・地域）ごとに見出しを付けて、books.json の順に並ぶので、同じ分野の、読む順のところに入れる。あれば `note`（下に出す注意）・`glossary`・`terms`・`math`（数式を使うなら `true`））
3. 手元で見て確かめてから push する

```json
{"id": "soil", "icon": "🌱", "langs": ["ja"], "title": {"ja": "土の教科書"}, "desc": {"ja": "土の成り立ち、肥料、土壌診断"}}
```

### 章の書き方

- 見出しは `#`（章の題名）・`##`（目次に出る小見出し）・`###`・`####`
- 章の最初に「この章でわかること」のような見出しと箇条書きは書かない（目次やまとめと重なる）。導入の文は `#` のすぐ下に書く
- 段落、箇条書き（2文字下げで入れ子）、番号付きの手順（途中に図をはさんでも `4.` から続けられる）、表（縦線は `\|`）、引用（`>`、注意書き）、**太字**、リンク、`コード`、`---`（区切り）
- 1行だけの画像 `![説明](images/名前.svg)` は図になり、「図 章-番号 説明」が付く。動画（mp4・webm・YouTube の URL）も同じ書き方
- コードは ```` ```cpp ```` ・ ```` ```python ```` ・ ```` ```bash ```` など。```` ```cpp run ```` はそのままビルドできるプログラム、```` ```python run ```` は Pico Studio で試せる MicroPython（コードの見出しは言葉の名前だけ）
- 練習問題は章の最後に `## 練習問題`（英語は `## Exercises`）と ```` ```quiz ```` で書く。1問は `Q: 問題`・`A: 答え | 別の書き方 | …`（最初のものを答えとして見せる）・`E: 解説`。コードを見せるときは `Q:` の下に `| コードの行` を並べる。答え合わせでは、全角・半角、大文字・小文字、カタカナ・ひらがな、空白・記号、文の終わりの「です」、英語の the・a と複数の s のちがいは見ない。答えが数なら、入力の最初の数で比べる（`280` に「280日」も正解）。答えが短い言葉か数になる問題にする
- 単語帳は ```` ```words ```` で書く。`## まとまり`・`# 話題` の行と、1行に `単語 | 品詞 | 意味 | 例文`。読む画面が、話題の一覧と 20語ずつのページ・チェック・見直す・意味を隠す・検索・発音の付いた単語帳にする（操作の欄は上に固定される）
- 英語の読み上げは ```` ```listen ```` で書く。1行目に `# 題`、そのあとに英文を1行ずつ。`Woman: …` のように「名前: 文」で書くと、名前ごとに声（足りなければ声の高さ）を変える。🔊 の「▶ 再生」でブラウザの読み上げ（speechSynthesis、イギリスの声を優先）が読み、「ゆっくり」で遅くできる。スクリプトは「スクリプトを見る」を押すまで隠す（```` ```listen show ```` なら最初から見せる）。読んでいる行に色が付く
- 数式（`math: true` の教科書）: 文の中は `$x^2$`、別の行に出すものは `$$…$$` を**1行で**書く。表の中では `|` の代わりに `\lvert` `\rvert`
- 2つの言葉がある教科書は、`ja/` と `en/` に同じファイル名で書き、**見出しの数と順番、図の順番をそろえる**（切り替えるときに見出しの番号で場所を合わせるため）。`python3 tools/check_langs.py [id]` で、見出し・図の順番と練習問題の数と、英語版に日本語が残っていないかを確かめる
- 英語版のコードは日本語版と同じにし、コメントと表示する文字だけを訳す（コードの言葉の説明は日本語版のコードから選ぶ）
- 英語の図: 図を直したら `python3 tools/translate_figures.py <id> --init` で新しい文字を `figures-en.json` に足して英語を書き、`python3 tools/translate_figures.py <id>` で `images/en/` を作り直す。英語版の Markdown は `images/en/名前.svg` を使う
